课件零件陈列

零件库中“还没有在很多小节里用”的零件，每个放在 1280×720 画布里，按真实课件的分区：右上讲师框、正文区 y 262–632、红色斜纹是字幕区。点“下一步”看分步揭示。

已在课件里使用的零件（手绘框、流程、对照、2×2、集合、记录贴纸、题卡、阶梯、结论条、开篇地图、涂鸦小结）直接看 1.2 节 与 第 0 章。用法与制作流程见 parts.md。示例内容取自现有课件，均为教学示意。

漫画开场

.p-comic .p-panel .p-cap .p-bubble .p-avatar

需要冲突感的开场，每节最多一页。三格，角色只有“我们”（深色）和 AI（柔和紫），最后一格留下问题。

Prompt ↔ 回复

.p-prompt .p-seg .p-reply.is-missing [data-key]

讲 Prompt 和“确认计划”。四段固定配色：目标 goal、上下文 ctx、约束 limit、完成标准 done；回复每句贴对应颜色，缺失的一段用虚线并给出追问。

切到实操

.p-handoff .p-handoff-card .p-env .p-watch

每次切去真实环境之前。列出环境，给 3 条“边看边找”；切回来时在同一张清单上打勾（给 li 加 is-done / is-miss）。

代码讲解

.p-walk .p-src .p-ln .p-band[data-only] .p-notes

讲一段代码。只高亮当前讲的行（data-only），右侧批注一条一句、不复述代码，最后一条落在副作用上。代码框保持工整。

diff 对比

.p-walk .p-src .p-ln.add/.del .p-brace[data-only] .p-notes

讲一次改动、讲验收范围。第一步先看文件名和增删行数，再逐块看，左侧括号标出当前块；右侧只写这处改动的意图。

正反对照 + 证据清单

.p-claim .p-checks li.is-no

讲验收、讲“凭什么相信”。左边是 Agent 的原话，右边是检查清单；有证据绿勾，没有红叉并写“还没看”。

权衡矩阵

.p-matrix [data-mk=fit|over|lack] .is-key .p-legend

“什么时候用哪个”。行写具体情境，不写抽象优缺点；● 刚好、○ 过大、✕ 不够；最后一列写判断依据。

带解读的操作记录

.p-rec .p-cell .p-why .is-fail

讲工具调用、讲一次执行。三栏：动作 / 结果 / 这个结果能说明什么；失败行用闸门色，写明“不能当作什么”。

可见 / 不可见 + 错误推断

.p-set .p-item.is-unread .p-item.is-wrong

讲边界、范围、“有但没读到”。两个集合并排，最后给出一条“依据不足”的错误推断。1.2 的 p10-context 是不带错误推断的版本。

练习任务卡

.p-task .p-box

课堂练习。四格：输入、任务、产出、验收；验收用通过色。1.1 p07、1.6 p35 适用。

原文链接

.p-refs b a

值得直接打开的外部原文：放在正文最下面一行，和本页最后一步一起出现，讲师录制时点开展示。<b> 是分组标签，每个链接自动带 ↗，新标签打开。链接固定到具体版本（如完整提交哈希），不要指向会变的 main。课件里不手写，在页面数据里写 refs，由播放器渲染。导航用的大按钮是另一个零件 .p-links。
