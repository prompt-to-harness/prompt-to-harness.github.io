# 1.2 节视觉迁移样板

[打开 demo](index.html) · [原版课件](../../courseware/ch01/lessons/02-agent/index.html) · [视觉参考](../visual-system/index.html)

可直接打开 `index.html`，或使用仓库服务访问 <http://127.0.0.1:8841/demos/courseware-1.2/>。

## 操作

- 点击画面、→、空格：显示下一步，本页结束后翻页。
- ←：退一步；从第一页内步骤退回上一页最后一步。
- 顶部目录：跳页；URL 的 `#p=3&s=2` 可定位到页和步骤。
- T / 完整阅读：显示全部 13 页及逐步讲述提示；返回演示保留步骤。
- S / 安全区：检查字幕位置；录制视图隐藏控制栏与备注，Esc 退出。
- 右上角为讲师叠加占位，demo 不采集摄像头。

## 内容范围与对应

以[深蓝平台交付版大纲](../../docs/course-outline.md)约束范围，以[共同内部大纲](../../docs/outline/course-outline-internal.md)第 1.2 节补齐细节。沿用欢迎语任务，13 页共 42 个呈现步骤，总时长仍暂估 15 分钟，待试讲；增加页面不增加教学范围。

| Demo 页 | 原课件 | 呈现变化 |
| --- | --- | --- |
| 1–3 | P09、P11 | 问题开场与五节点执行循环 |
| 4–6 | P09–P11 | 术语对应任务、仓库与上下文对照、请求与结果记录 |

欢迎语片段是合成教学示例，不是实操通过证据。正式授课需替换或对照 1.1 真实记录。原版备注中的 8 条陈述材料尚待核对；本 demo 仅用两条代表性题目演示交互，不冒充原题，也不替代完整课堂练习。产品与外链资料沿用原课件定位，本次未重新核验。行业路标的延伸方向放在逐步讲述中。

## 文件与后续迁移

- `lesson.js`：标题、图示、步骤、讲述提示、来源和段落归属。
- `player.js`：分步推进、回退、URL、阅读与录制视图。
- `visual.js`、`styles.css`：从视觉参考提取的 SVG 图形和样式；遵循[视觉规范](../../docs/production/visual-design-system.md)。
- `assets/`：本地字体子集与许可证，播放不请求外网。标题为站酷快乐体、封面为长仓体，来自 Google Fonts 对应 OFL 字体；正文为与正式课件同源的 Noto Sans CJK SC。代码使用系统等宽字体。

新增文案需重建字体子集。字体字集来自本目录 HTML、JS、CSS；正文使用与现有课件相同的 fontTools 子集流程，标题与封面通过 Google Fonts CSS `text` 子集接口获取后转为 WOFF2。许可证保留在 `assets/`。

样板位于独立目录，尚未接入正式 `courseware/shared/app.js` 或讲述者窗口同步。认可后可将播放器的“页 + 步骤”状态与样式组件逐项迁入 shared，并将逐步讲述映射到正式讲稿。13 页与全部步骤已在 Chrome 检查；实际授课节奏和摄像头合成未测。
