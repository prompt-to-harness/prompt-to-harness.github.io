# 1.1 课前环境检查单

在独立练习仓库 （从 course-starter 创建的自己的项目） 中填写。此文件是检查模板，不代表这些环境或模型已经通过测试。

## 基本记录

- 日期、平台与系统版本：待填写。
- 练习仓库路径、分支、初始 commit：待填写。
- 初始工作树状态及已有改动归属：待填写。
- Codex 版本、使用的 profile / 提供商名称：待填写。

## 模型实际接入验证

课程主用 MiniMax M3 必检。GPT-6 Astra、Claude Opus 5、Claude Fable 5 仅做名称介绍时不要求学员接入；若教师实际演示，须在相应工具与授权配置中逐一验证，不默认它们都能在同一 Codex 配置中直接切换。

1. 使用已确认的教学 profile / 提供商和授权；不在文档、Prompt 或截图中粘贴密钥。
2. 在实际教学客户端发起最小请求，例如“只回复：环境连接检查完成”，确认获得有效响应且没有认证、余额、限流或协议错误。失败时保留脱敏错误，标记待补做。
3. 将配置的 model ID 与提供商响应或请求记录中的模型标识对照。模型在回答中自称是谁、选择列表里出现名称，都不能单独证明真实模型身份。代理服务有映射时记录映射依据；无法核实时标为身份未核实。
4. 完成最小只读工具任务：“只读取 setup-check/index.html，原样返回 h1#welcome-message 的文字，不修改任何文件。”核对真实工具返回与文件内容，然后查看 Git diff 确认无写入。只有文本回复不能证明编码工具链兼容。
5. 记录日期、工具版本、profile / 提供商、预期 model ID、实际模型证据、结果与错误。不要将某个工具中调用成功推及其他客户端或账号。
