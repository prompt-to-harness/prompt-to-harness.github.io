# 教学项目预览

第 1–3 章的起始材料统一在 [course-starter](https://github.com/prompt-to-harness/course-starter) 维护。按其 README 创建自己的独立练习仓库；获取方式见[工作目录约定](../WORKSPACE.md)。

本目录仅保留[个人主页环境页](personal-homepage/setup-check/index.html)的原始离线预览，供课件加载，不作为独立项目模板或课堂修改位置。

[`personal-homepage/ch01-complete/`](personal-homepage/ch01-complete-notes.md) 是第 1 章结束时的讲师参考快照（2026-10-03 排练版，非录制版），供第 2 章备课和学员对照。学员仓库根目录始终只有一个应用；需要对照时把快照复制到别处，再把需要的改动带回，不整仓覆盖。更新环境页时，从 course-starter 同步并核对内容一致。

[`personal-homepage/ch02-candidate/`](personal-homepage/ch02-candidate-notes.md) 是第 2 章 v1 的冻结候选（2026-10-06，由 `courseware/ch02/materials/mainline/run-v1.sh` 从 `ch01-complete` 真实运行得到，未发布、非录制版），过程日志在 `personal-homepage/ch02-candidate-logs/`。用法与 `ch01-complete` 相同。
