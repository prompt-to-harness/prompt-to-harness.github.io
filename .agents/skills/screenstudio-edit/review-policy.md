# 课程录屏剪辑与审阅基线

2026-10-25 讲师确认。适用于本课程，之后用户明确指定的例外优先；具体数值和每次改动仍写任务私有计划，不混成所有项目的通用产品默认。

- 只剪不补录：删重复、口误、失误尝试和明显口水词，保持自然紧凑；保留理解所需的换气、阅读和操作停顿。
- 人像尽量固定右上角，大小稳定，尽量不遮挡内容；仅人像按录制预览方向做水平镜像，屏幕文字不翻转。画面放大时人像不跟着缩小。
- 屏幕平时固定，不随鼠标移动。局部放大主要帮助读清小字，仅对非常重要的判断少量做强调；倍率、目标和进出时机由画面需要决定，不按点击次数触发。
- 放大前先让观众知道对象，固定在目标供阅读，讲完回全景；保留文件名、行号、轮次等判断依据。概念图、地图、循环图优先保持整体关系。
- 鼠标适度放大、点击轻提示，无装饰转场或背景音乐。这一版不做字幕，后续如需字幕再单独确认。文字可读性优先，已验证的样片规格为 1080p、60 fps。
- 每次删除都记录原范围、内容、理由、类型、保留替代段和校对状态；删除秒数、比例及成片接缝由脚本计算。不能只交剪后视频而丢失剪辑依据。
- 每次放大都记录阅读／强调用途、具体目标、原因、范围、倍率和目标点，区分已配置、已渲染与人工确认；审阅页能看出哪里有强调、为什么做。
- 用原片区间条、成片接缝条和可点击事件清单联合审阅；支持原音回听。示例未覆盖的内容不是删除，暂停空档不是删去的媒体，各独立示例不是可合并相加的最终版本。
- 保留原项目、剪辑计划和最终工作项目；工作副本尽量用 APFS clone，临时样片在 review 完成后按用户授权清理，不无限保存完整副本。
- 一节统一剪辑时，默认交付一个完整工作项目、一个连续 MP4 和一套全节审阅资料，不按示例或讲述段落拆成多个项目。段落导航是成片定位入口，不改变连续视频；只有用户明确要求分开发布时才拆分。

两份 Skill 共用本基线：转写流程提供可定位的候选与语义判断，剪辑流程记录实际执行结果；未听音就写未听音，不把 ASR 时间精度当成人工校对精度。
