# 课程录屏剪辑与审阅基线

2026-10-25 讲师确认。适用于本课程，之后用户明确指定的例外优先；具体数值和每次改动仍写任务私有计划，不混成所有项目的通用产品默认。

- 只剪不补录：删重复、口误、失误尝试和明显口水词，保持自然紧凑；保留理解所需的换气、阅读和操作停顿。
- 人像尽量固定右上角，大小稳定，尽量不遮挡内容；仅人像按录制预览方向做水平镜像，屏幕文字不翻转。画面放大时人像不跟着缩小。
- 屏幕平时固定，不随鼠标移动。局部放大主要帮助读清小字，仅对非常重要的判断少量做强调；倍率、目标和进出时机由画面需要决定，不按点击次数触发。
- 放大前先让观众知道对象，固定在目标供阅读，讲完回全景；保留文件名、行号、轮次等判断依据。概念图、地图、循环图优先保持整体关系。
- 鼠标适度放大、点击轻提示，无装饰转场或背景音乐。这一版不做字幕，后续如需字幕再单独确认。文字可读性优先，默认 MP4、1080p、30 fps、Studio 压缩（2026-10-25 经帧率对照后确认）；游戏或大量动画演示确需更顺滑时再选 60 fps。历史 60 fps 样片保留为对照，不能误称为 30 fps。
- 每次删除都记录原范围、内容、理由、类型、保留替代段和校对状态；删除秒数、比例及成片接缝由脚本计算。不能只交剪后视频而丢失剪辑依据。
- 每次放大都记录阅读／强调用途、具体目标、原因、范围、倍率和目标点，区分已配置、已渲染与人工确认；审阅页能看出哪里有强调、为什么做。
- 用原片区间条、成片接缝条和可点击事件清单联合审阅；支持原音回听。示例未覆盖的内容不是删除，暂停空档不是删去的媒体，各独立示例不是可合并相加的最终版本。
- 保留原项目、剪辑计划和最终工作项目；工作副本尽量用 APFS clone，临时样片在 review 完成后按用户授权清理，不无限保存完整副本。
- 一节统一剪辑时，默认交付一个完整工作项目、一个连续 MP4 和一套全节审阅资料，不按示例或讲述段落拆成多个项目。段落导航是成片定位入口，不改变连续视频；只有用户明确要求分开发布时才拆分。
- 多份原始录制共同组成一节时，允许分别保留可编辑工作项目、分别经 Screen Studio 原生导出，再无重编码拼接成一个连续 MP4，并提供统一审阅入口（2026-11-01 讲师确认）。同类任务无需重复询问；这不适用于把独立示例拼成整节。拼接前核对各部分规格与编码兼容性，拼接后验证总时长、音轨、声画衔接及连接处，并记录各源项目到成片的时间偏移。无法无重编码拼接时说明具体限制，再讨论替代方式。

两份 Skill 共用本基线：转写流程提供可定位的候选与语义判断，剪辑流程记录实际执行结果；未听音就写未听音，不把 ASR 时间精度当成人工校对精度。

## 制作文件存放

2026-11-01 讲师确认：本机课程录屏统一保存在公开仓库旁的私有制作目录 `../prompt-to-harness/录屏/<课次>/`，按用途分为 `交付/`、`剪辑项目/`、`转写/`、`审阅与制作记录/`。交付放当前采用的连续成片与交付说明；剪辑项目放对应可编辑工作副本；转写保留原稿、润色稿、音轨、时间戳与索引；审阅与制作记录按批次保留剪辑计划、审阅页、校验、过程文件和历史版本。原始录制保留在原位置，可在 `原始录制入口/` 建链接；链接不算素材备份。

后续转写和剪辑直接写入该制作目录，`lab-runs/` 只保留可重建缓存、临时实验和迁移兼容入口。每节入口说明当前采用哪个版本及未核对项，不能仅凭文件名含“final”判断。迁移时校验文件完整性，修复活动队列及审阅媒体路径；历史绝对路径可通过兼容链接保留。不自动删除历史版本，不把本机归档说成已配置跨盘或云端备份。其他机器先定位讲师指定的私有制作根目录，不创建带有他人用户名的路径。

制作根目录独立作为私有 Git 仓库，只跟踪脚本、策略和说明；录屏、工程、转写音轨、交付包及运行产物不提交，不将制作逻辑继续堆入 `ai-coding-resources`。对外剪辑确认默认精简为根目录 README、每节一份连续 MP4 和一份 Markdown 剪辑说明，直接按“课次 + 成片时间 + 修改建议”收反馈；完整事件记录留内部，不默认生成 PDF、反馈表或审阅网页。发布材料待剪辑确认后补。复用已有采用版与剪辑记录生成批次，不重复转写、转码或手抄多套清单。
