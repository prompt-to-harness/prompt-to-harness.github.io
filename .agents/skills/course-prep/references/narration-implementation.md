# 讲述页 HTML 实现维护

按编号读取完整正文：从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`；合并去重，已读且未变的不重读，缺号或截断时补取并核对结束标记。 纯实现与生成修改读 ED-011；影响内容用途补 ED-003，教学对应补 ED-017；写改屏幕文字补 ED-001、ED-012、ED-014，口播补 ED-002、ED-007、ED-010，操作提示补 ED-013。

仅在修改讲述页布局、交互、保存、评论、模板或构建时读取。输入是现有讲述内容及明确的页面修改要求；不据此修改 Discussion 或重新安排教学知识。具体讲法变化另按 [讲述设计](narration-html.md)处理。

## 源映射的历史排障例

- 2026-11-03：lessonkit 要求同页 `script.json` 数组长度与 PPT 的 `steps` 数量一致。原来只有一个 PPT 状态，讲解切到 HTML 后分成六段时，不要直接拆成六个脚本数组项，否则构建报 `steps 与 script 条数不一致`。保持一个 PPT 脚本项，在项内按 HTML 实际按钮顺序分段写操作提示与口播；材料页的锚点不是 PPT 的新增动画步骤。第三节 ppatterns 与 workflow-patterns.html 为已用案例。

这是一种历史构建器的约束，当前课按实际源和生成工具核对，不能据此把每个 HTML 锚点扩成 PPT 状态。

## HTML 模板与维护

### 当前参照与示例边界

本方法与通用模板共同定义新布局。旧课程 [3.2 对照页](../../../../courseware/ch03/lessons/02-rules/speaker.html#unit-1) 只作取材实例，不作为新规范的完整示范，不因模板升级自动迁移。可复制起步包为 [narration-template](../assets/narration-template/README.md)，预览入口为 [index.html](../assets/narration-template/index.html)。新建讲述页先读取起步包 README，复用骨架、样式与交互，按已有内容源生成数据；不要逐章重新实现目录。实际课程页承载当前课程内容；独立示例便于跨机器、跨项目查看与移植。两者都不决定新课的内容、环节数或步骤数。

独立示例展示同一小节中的多个部分，包含设计与口播并存、仅有设计、旧字段和占位状态，以及分步 PPT、操作/口播交替、同一材料多次定位、Prompt 复制及条件备用。文字为模板示意，不是已试跑的案例，不预填现场成功结果；示例没有课程的编辑／评论后端。移植到已有课件时，接回本课唯一内容源、保存与评论机制。只读取代码不等于实际检查过页面。

### 当前布局与交互

新建和改版时使用起步包作为共同的页面结构与交互基准。课程实例用于查找可复用做法。已有页面可通过适配保留编辑和评论，交付前按下列规则核对可见结构、字段顺序与操作行为。

- **连续阅读与目录**：右侧整节按真实顺序连续滚动，导航不替换正文。目录沿用现有部分、环节和场景，不按动作增加层级；默认只显示前两级。文字导航负责定位，独立按钮负责折叠，键盘同样可用。滚动跟随只更新当前标记，不强制改变左侧滚动或展开状态。点击、深链、刷新、前进后退保留稳定定位；被动滚动不添加历史记录。
- **目录调宽**：左目录与正文之间必须有可见的横向拖拽分隔线，支持鼠标／触控拖动、键盘左右键调宽、Home／End 到边界及双击恢复默认。按页面记住宽度，刷新后恢复；存储不可用时仍可调宽。设置最小目录宽度和正文保留宽度，窗口缩小即时限制，避免窄屏横向溢出。调宽只更新布局，不重建口播或评论节点，不重置目录折叠与滚动。直接复用起步包实现。
- **场景、讲解段与时序**：内容模型按 [讲述设计](narration-html.md#讲述设计的单元与完成程度)。场景可含多个讲解段，段内按操作与讲述真实顺序渲染；正常操作常显。静态画面只定位；边做边讲明确时机；讲完后做的动作放在稿件之后。共同操作、材料和定位只维护一次。
- **设计与成稿并存**：讲述设计就近可折叠；仅有设计时便于直接审阅，成稿后默认收起。正式逐字稿连续显示，未成稿与占位维持原状态，不把设计冒充台词。旧 points 先标为原讲述要点，不因出现 script 而丢弃，也不未经判断转为 design。
- **紧凑层级**：场景与段落用标题和间距组织，讲解段不再套大卡片。操作用浅绿区域与编号，口播用浅色阅读区；画面定位为紧凑次级行。精确样式由模板统一维护，展开后不恢复成多层框和大留白。
- **材料与折叠**：Prompt/命令/输入材料的名称、用途、复制入口可见，长原文默认折叠，显示与复制同一原文；材料定位与当前观察点常显。PPT/截图预览按需展开并加载。条件备用路线就近折叠，触发条件常显。录前准备与当场动作分开，正常路线必做动作、现场/预存身份和证据限制不得隐藏。
- **小节 PPT 总览**：保留目录中的总览入口，展示总页数及页—讲述段、内容、展开关系；0 页、待定和拟制分别说明。正式页链接使用实际定位器，不用旧同号页替代未制页。
- **保留内容与能力**：沿用原稿、已保存修改、稳定 ID、材料入口、源坐标与评论。一次渲染并挂载原节点，导航只定位，不 cloneNode 或另存口播。旧字段与新段同时出现时不得无声覆盖，提示作者核对重复。未知字段类型或重复映射应显式报错。
- **随内容调整**：数量和宽度按讲法确定；窄屏可读可操作。旧课按本轮授权和影响范围适配，不为符合模板重做所有课程。布局整理不顺手改教学内容。

### PPT 可见定位与数据接入

统一使用 `P节号-实际页码-步骤`，如 `P3.2-01-01`。页码按整个小节正式播放器的实际顺序连续计算，各部分不重置；页码与步骤从 01 起。引用整页、未指定状态时显示 `P3.2-01`，不要猜测步骤；链接进入该页第一步。具体步骤显示完整编号并直达对应状态。播放器阅读模式显示整页编号，演示模式显示当前步骤；用共用定位器的 `bindPlayer()` 同步工具栏和页脚，章节适配代码不重复实现算法。

用起步包 `ppt-location.js` 的 `createPptLocator({section, pages, url})` 生成标签和链接。`pages` 来自实际正式播放数组，排除历史稿和材料；步骤在数据中从 0 起，显示时加 1。保留内部 scene ID、URL 锚点、源稿坐标及评论映射；显示编号不是稳定主键。讲述页与播放器使用同一页序，插页后自动更新，不能手工维护两份编号。

页面结构固定职责而非内容数量：环节概览说明已有安排，场景内的讲解段保留当前设计，并按时序呈现画面定位、操作、材料与连续口播。缺稿保留待补，纯占位不扩写。新章填数据即可复用目录、Prompt 复制和定位；编辑与评论须通过本课适配器接回唯一内容源，起步包本身不提供保存后端。字段和可复制接入代码见 [起步包说明](../assets/narration-template/README.md)。

### 模板怎样持续优化

模板是随备课推进持续改进的参照。讲师新反馈优先；在已授权的修改范围内，发现共性布局或交互问题，修改本文件对应规则及独立模板示例，并在需要时更新 SKILL.md 的模板入口。Skill 及模板资产的修改仍须符合仓库的讲师授权要求；使用模板本身不等于授权修改 Skill。

课程内容的局部变化留在本课；可迁移的布局与交互改进才归入模板。更换实际课程参照时，同步 SKILL.md 与本文件的入口，移除失效的模板指令；专属 Skill 引用这里，不另维护一份通用规范。

已有课件按本轮授权和影响范围更新，记录尚未同步部分，不因模板更新重做全部课件。只改说明时不宣称模板资产或页面已同步；下一轮实际改版时核对当前规则与示例差异，再更新受影响文件。

### 本机编辑接入与启动

本仓库所有已有逐字稿的正式讲述页必须接入 `courseware/shared/script-editor.js`，沿用原节点和唯一稿源。新页、改版和复制模板时均须完成接入；纯 Discussion 入口或无稿占位不补造口播。适配器按原稿空行拆段，保留 `scene/step/part` 或 `screen/part` 坐标，操作提示与切换提示不可编辑。保存、冲突对照、草稿恢复及撤销复用公共编辑器，不另写简化版本。

本地课件统一用 `make serve` 或 `sh tools/edit-courseware.sh` 启动编辑服务；需要后台时加 `--background`。不得用普通 `python -m http.server` 交付本机讲述页。启动必须验证 `/__script/ping` 的有效响应，端口占用或编辑接口不可用应报错，不降级为只读成功。公开站点、直接打开文件和局域网设备保持只读。

### 改版后怎样检查

先以固定数据验证连续跨场景阅读、设计与成稿共存、操作/口播交替、仅设计与占位；再用原始旧数据核对字段、旧锚点及适配器节点没有丢失。样例须包含同一材料两次定位、分步 PPT、动态等待/返回与条件备用。

实际浏览器检查默认两级目录、独立导航与折叠、键盘操作、深链、刷新、前进后退；被动滚动不增加历史，左侧状态不被重置。实拖目录分隔线并测试键盘、上下限、刷新记忆、双击复位及窄屏再回桌面；核对口播原节点与目录状态保留。核对复制的换行与标点，展开原文和预览检查紧凑度及按需加载。桌面和窄屏检查长文本、表格与预览不撑破页面。PPT 总览的页序、步骤和来源入口逐项核对。

运行 `uv run courseware/tools/check-script-editing.py`，通过真实编辑服务检查全部正式讲述页；实际保存测试使用隔离副本，不改讲师原稿。验证编辑、写回、刷新、撤销、冲突及只读边界；`file://` 布局测试不能替代这些检查。

编辑和评论通过原节点适配验证坐标、事件及导航间状态；只有接入真实后端时才能验证保存、刷新持久化、撤销与评论读写。没有后端的固定样例明确标注未验证。测试不改变原稿，临时编辑应恢复。具体命令沿用当前项目工具，不把已做静态检查报告为实际页面验收。

模板检查不替代课程内容核对、出声试读或试讲。分别报告已检查项、缺口与受影响的未同步部分。仅修改 HTML 布局时按本文核对；任务进入整段录制验收，或同时调整 PPT、口播和演示顺序时，再读取 [recording-alignment-workflow.md](recording-alignment-workflow.md)。
