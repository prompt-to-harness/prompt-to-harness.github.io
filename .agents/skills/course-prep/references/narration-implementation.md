# 讲述页 HTML 实现维护

按编号读取完整正文：从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`；合并去重，已读且未变的不重读，缺号或截断时补取并核对结束标记。 纯实现与生成修改读 ED-011；影响内容用途补 ED-003，教学对应补 ED-017；写改屏幕文字补 ED-001、ED-012、ED-014，口播补 ED-002、ED-007、ED-010，操作提示补 ED-013。

仅在修改讲述页布局、交互、保存、评论、模板或构建时读取。输入是现有讲述内容及明确的页面修改要求；不据此修改 Discussion 或重新安排教学知识。具体讲法变化另按 [讲述设计](narration-html.md)处理。

## 源映射的历史排障例

- 2026-11-03：lessonkit 要求同页 `script.json` 数组长度与 PPT 的 `steps` 数量一致。原来只有一个 PPT 状态，讲解切到 HTML 后分成六段时，不要直接拆成六个脚本数组项，否则构建报 `steps 与 script 条数不一致`。保持一个 PPT 脚本项，在项内按 HTML 实际按钮顺序分段写操作提示与口播；材料页的锚点不是 PPT 的新增动画步骤。第三节 ppatterns 与 workflow-patterns.html 为已用案例。

这是一种历史构建器的约束，当前课按实际源和生成工具核对，不能据此把每个 HTML 锚点扩成 PPT 状态。

## HTML 模板与维护

### 当前参照与示例边界

本方法与通用模板共同定义新布局。[3.2.1 当前讲述页](../../../../courseware/ch03/lessons/02-rules/speaker.html#f04) 提供两种视图、环节设计和对象提示的实际参照；只提炼通用关系与样式，不复制该课的页 ID、分支或内容数量。现有课程页不因模板升级自动迁移。可复制起步包为 [narration-template](../assets/narration-template/README.md)，预览入口为 [index.html](../assets/narration-template/index.html)。新建讲述页先读取起步包 README，复用骨架、样式与交互，按已有内容源生成数据；不要逐章重新实现目录。实际课程页承载当前课程内容；独立示例便于跨机器、跨项目查看与移植。两者都不决定新课的内容、环节数或步骤数。

独立示例展示同一小节中的多个部分，包含设计与口播并存、仅有设计、旧字段和占位状态，以及分步 PPT、操作/口播交替、同一材料多次定位、PPT 中的 Prompt 展示与复制、无需口播的操作页和补充页、条件备用。文字为模板示意，不是已试跑的案例，不预填现场成功结果；示例没有课程的编辑／评论后端。移植到已有课件时，接回本课唯一内容源、保存与评论机制。只读取代码不等于实际检查过页面。

### 当前布局与交互

新建和改版时使用起步包作为共同的页面结构与交互基准。课程实例用于查找可复用做法。已有页面可通过适配保留编辑和评论，交付前按下列规则核对可见结构、字段顺序与操作行为。

- **连续阅读与目录**：右侧整节按真实顺序连续滚动，导航不替换正文。目录沿用现有部分、环节和场景，不按动作增加层级；默认只显示前两级。文字导航负责定位，独立按钮负责折叠，键盘同样可用。滚动跟随只更新当前标记，不强制改变左侧滚动或展开状态。点击、深链、刷新、前进后退保留稳定定位；被动滚动不添加历史记录。
- **目录调宽**：左目录与正文之间必须有可见的横向拖拽分隔线，支持鼠标／触控拖动、键盘左右键调宽、Home／End 到边界及双击恢复默认。按页面记住宽度，刷新后恢复；存储不可用时仍可调宽。设置最小目录宽度和正文保留宽度，窗口缩小即时限制，避免窄屏横向溢出。调宽只更新布局，不重建口播或评论节点，不重置目录折叠与滚动。直接复用起步包实现。
- **场景、讲解段与时序**：内容模型按 [讲述设计](narration-html.md#讲述设计的单元与完成程度)。场景可含多个讲解段，段内按操作与讲述真实顺序渲染；正常操作常显。静态画面只定位；边做边讲明确时机；讲完后做的动作放在稿件之后。共同操作、材料和定位只维护一次。
- **两种视图**：顶部统一切换“讲述安排／画面与口播”，保持当前环节及目录状态，URL 记录模式；深链、刷新及前进后退可恢复对应模式与位置。导航仅定位，正文及编辑节点一次挂载。讲述安排按完整环节集中显示解释、承接、材料与 Prompt 入口；画面与口播按时序连续显示。具体内容分工见[两种视图](narration-html.md#两种视图的内容分工)。
- **完成程度**：已有口播的页面默认进入画面与口播；只有设计时默认进入讲述安排，显式深链优先。只有设计、缺稿和占位在两种视图均可定位，必要时以简短状态及切换入口呈现，不因过滤而消失。旧 points 标为原讲述要点，不因有 script 而丢弃，也不未经判断转成新设计。
- **紧凑层级与对象提示**：环节用标题和间距组织，段内重复标题弱化，避免层层套卡片。操作及定位合成轻量提示条，以文字明确 PPT、网页、终端、Inspect 或其他实际对象，辅以浅色底和左侧色线，不能只靠颜色辨别。口播使用较大字号、较疏行距连续阅读；无动作介入的连续口播合并显示，保留原节点和编辑坐标。样式数值统一在模板 CSS 维护。
- **材料与 Prompt**：讲述安排集中列本环节材料与 Prompt 的名称、用途和入口；画面与口播在使用处显示对象、具体定位、必要动作及链接。Prompt 全文和复制功能由 PPT 承载，使用同一输入源，迁移后不再在讲述页折叠全文。旧输入尚未接好 PPT 入口时保留兼容内容并标明待迁移，不能直接删掉唯一原文。
- **按需折叠**：PPT/截图预览按需展开并加载；条件备用路线就近折叠，触发条件常显。录前准备与当场动作分开。正常路线必做动作、现场/预存身份、证据限制与未完成状态不得隐藏。移走 Prompt 全文不等于取消这些折叠用途。
- **小节 PPT 总览**：保留目录中的总览入口，展示收录总页数、页的用途、对应环节或支撑位置、展示安排及是否需口播。主讲、操作和补充页均计入总数；不展示的补充页和只供复制的操作页可以没有口播关联，显示“无需口播”，与“逐字稿待补”区别。0 页、待定和拟制分别说明。正式页链接使用实际定位器，不用旧同号页代替未制页。
- **保留内容与能力**：沿用原稿、已保存修改、稳定 ID、材料入口、源坐标与评论。一次渲染并挂载原节点，导航只定位，不 cloneNode 或另存口播。旧字段与新段同时出现时不得无声覆盖，提示作者核对重复。未知字段类型或重复映射应显式报错。
- **随内容调整**：数量和宽度按讲法确定；窄屏可读可操作。旧课按本轮授权和影响范围适配，不为符合模板重做所有课程。布局整理不顺手改教学内容。

### PPT 可见定位与数据接入

统一使用 `P节号-实际页码-步骤`，如 `P3.2-01-01`。页码按整个小节正式播放器的实际顺序连续计算，各部分不重置；页码与步骤从 01 起。引用整页、未指定状态时显示 `P3.2-01`，不要猜测步骤；链接进入该页第一步。具体步骤显示完整编号并直达对应状态。播放器阅读模式显示整页编号，演示模式显示当前步骤；用共用定位器的 `bindPlayer()` 同步工具栏和页脚，章节适配代码不重复实现算法。

用起步包 `ppt-location.js` 的 `createPptLocator({section, pages, url})` 生成标签和链接。`pages` 来自实际正式播放数组，排除历史稿和材料；步骤在数据中从 0 起，显示时加 1。保留内部 scene ID、URL 锚点、源稿坐标及评论映射；显示编号不是稳定主键。讲述页与播放器使用同一页序，插页后自动更新，不能手工维护两份编号。

页面结构固定职责而非内容数量：讲述安排集中呈现环节设计和材料与 Prompt 入口，画面与口播按时序呈现对象提示与连续口播。缺稿保留待补，纯占位不扩写。新章填数据即可复用目录、模式切换、对象提示和 PPT 定位；编辑与评论须通过本课适配器接回唯一内容源，起步包本身不提供保存后端。字段和可复制接入代码见 [起步包说明](../assets/narration-template/README.md)。

### 材料与 Inspect AI 接入

接收阶段二确定的运行、消息位置、观察范围与主讲停留顺序。运行日志按[材料方法](materials.md#运行日志统一采用-inspect-ai)导入 Inspect AI，保留来源对应及原文上下文。将已定消息或输出接成稳定定位，展开目标内容并滚动到可见位置，高亮对应文字、字段或代码。若内容无法导入或证据缺失，返回材料准备与讲述设计处理受影响片段。

主讲导航实现已定停留顺序，同一判断需比较的内容同时可见，逐项讲解的内容按设计推进。完整日志可查，补充材料按已定用途接入。刷新、重复进入和前后切换应保持目标定位可用，不能依靠此前手动展开的偶然状态。

从讲述页及实际使用的 PPT 入口分别点入，逐处核对目标记录、文字高亮、必要上下文和返回后的继续位置。检查当前录制视口下是否可读、是否被固定栏或浮层遮挡，覆盖本轮使用的主讲停留。保留来源身份与已知缺口，不能用接口成功或隐藏 DOM 存在证明可见证据已到位。

请求与命令的显示、复制及播放器路线由[PPT 接入方法](ppt-implementation.md#任务输入与主讲导航)维护，讲述页引用同一输入源的名称、用途和 PPT 入口。这里验证接入能力，逐段语义及整节顺序在阶段四综合核对。

### 随内容深化逐段迁移

讲师授权深化已有内容时，以指定的完整讲解环节为范围，按阶段三共用规范同时整理讲述安排、对象提示与口播呈现；3a 只负责本轮反馈和接续。单纯纠错、标点或局部措辞修改不自动扩大为结构迁移。

1. 核对当前唯一稿源、讲师最新修改、材料和 Prompt 的去处、稳定 ID、旧深链与评论坐标。读取历史字段时先判断职责，保留有用的设计和事实边界。
2. 在当前环节映射两种视图及真实时序；Prompt 全文接到 PPT 并验证显示和复制后，再撤下讲述页的旧折叠块。无口播 PPT 页明确登记用途和展示安排。
3. 允许同一小节新旧结构并存，未处理部分继续沿用原呈现。公共样式和渲染改动限定到已迁移区域或适配器，避免其他章节一起重排；不要按模板字段批量重建课程源。
4. 逐句核对原内容去处，检查受影响的前后承接、两种模式、链接、编辑与评论。迁移范围和未处理范围随本轮交付说明，不另建迁移日志。既有有效检查可复用，按新增影响复验。

### 模板怎样持续优化

模板是随备课推进持续改进的参照。讲师新反馈优先；在已授权的修改范围内，发现共性布局或交互问题，修改本文件对应规则及独立模板示例，并在需要时更新 SKILL.md 的模板入口。Skill 及模板资产的修改仍须符合仓库的讲师授权要求；使用模板本身不等于授权修改 Skill。

课程内容的局部变化留在本课；可迁移的布局与交互改进才归入模板。更换实际课程参照时，同步 SKILL.md 与本文件的入口，移除失效的模板指令；专属 Skill 引用这里，不另维护一份通用规范。

已有课件按本轮授权和影响范围更新，记录尚未同步部分，不因模板更新重做全部课件。只改说明时不宣称模板资产或页面已同步；下一轮实际改版时核对当前规则与示例差异，再更新受影响文件。

### 本机编辑接入与启动

本仓库所有已有逐字稿的正式讲述页必须接入 `courseware/shared/script-editor.js`，沿用原节点和唯一稿源。新页、改版和复制模板时均须完成接入；纯 Discussion 入口或无稿占位不补造口播。适配器按原稿空行拆段，保留 `scene/step/part` 或 `screen/part` 坐标，操作提示与切换提示不可编辑。保存、冲突对照、草稿恢复及撤销复用公共编辑器，不另写简化版本。

本地课件统一用 `make serve` 或 `sh tools/edit-courseware.sh` 启动编辑服务；需要后台时加 `--background`。不得用普通 `python -m http.server` 交付本机讲述页。启动必须验证 `/__script/ping` 的有效响应，端口占用或编辑接口不可用应报错，不降级为只读成功。公开站点、直接打开文件和局域网设备保持只读。

### 改版后怎样检查

先以固定数据验证两种模式与切换定位、连续跨场景阅读、设计与成稿共存、操作/口播交替、仅设计与占位；再用原始旧数据核对字段、旧锚点及适配器节点没有丢失。样例须包含同一材料两次定位、分步 PPT、动态等待/返回与条件备用。

实际浏览器检查默认两级目录、独立导航与折叠、键盘操作、深链、刷新、前进后退；被动滚动不增加历史，左侧状态不被重置。实拖目录分隔线并测试键盘、上下限、刷新记忆、双击复位及窄屏再回桌面；核对口播原节点与目录状态保留。从讲述页入口到 PPT 核对 Prompt 全文与复制的换行、标点一致，确认新结构的讲述页不重复展示全文。展开条件备用和预览检查紧凑度及按需加载。桌面和窄屏检查长文本、表格与预览不撑破页面。PPT 总览的收录页序、步骤、主讲路线、操作页与补充页用途、来源入口逐项核对；明确无需口播的页不报缺稿，跳过补充页仍可接续。

运行 `uv run courseware/tools/check-script-editing.py`，通过真实编辑服务检查全部正式讲述页；实际保存测试使用隔离副本，不改讲师原稿。验证编辑、写回、刷新、撤销、冲突及只读边界；`file://` 布局测试不能替代这些检查。

编辑和评论通过原节点适配验证坐标、事件及导航间状态；只有接入真实后端时才能验证保存、刷新持久化、撤销与评论读写。没有后端的固定样例明确标注未验证。测试不改变原稿，临时编辑应恢复。具体命令沿用当前项目工具，不把已做静态检查报告为实际页面验收。

模板检查不替代课程内容核对、出声试读或试讲。分别报告已检查项、缺口与受影响的未同步部分。仅修改 HTML 布局时按本文核对；任务进入整段录制验收，或同时调整 PPT、口播和演示顺序时，再读取 [recording-alignment-workflow.md](recording-alignment-workflow.md)。
