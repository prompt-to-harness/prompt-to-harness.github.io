# PPT 实现与接入

按编号读取完整正文：从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`；合并去重，已读且未变的不重读，缺号或截断时补取并核对结束标记。跨项目使用见 [PPT 入口的读取约定](ppt.md#编辑规则读取)。 修改生成源读 ED-011；影响教学对应补 ED-017，材料分工补 ED-003，操作提示补 ED-013，来源标注补 ED-018。纯定位源文件不默认加载内容设计规则。

开始修改源文件、生成页面或处理链接与交互时读取；具体设计由[信息方法](ppt-information.md)和[视觉方法](ppt-visual.md)负责。这里只定位实现、接入与复用条件，不另定页型或教学流程。

## 定位源与可复用资源

先找到本课生成入口、页面数据、样式、图片与绘图辅助函数。已有图形可局部调整、组合或重画，按当前表达选择；采用简便实现时也要核对是否能承载所需视觉。可以复用文件轮廓、人物、气泡等底层绘制能力，不必复用原布局。零件不合适时可自行实现可编辑 SVG、HTML 等，不指定必装绘图 Skill。

| 实际需要 | 定向查阅 |
| --- | --- |
| 画布、字体、颜色与覆盖区 | 构图前按[视觉方法](ppt-visual.md#内容组矩形与留白)取得本项目参数；不要以旧 CSS 固定值反推制作边界 |
| 稳定页 ID、口播源、生成与播放器约定 | 本仓库查[工程约定](../../../../docs/agents/courseware-workflow.md)，其他项目查实际构建器 |
| 复用现成 HTML/CSS 零件 | 查[零件目录](../../../../docs/production/parts.md#零件目录)及当前代码，仅选需要的零件；跨项目用[包内参照](../assets/course-reference/docs/production/parts.md) |
| 特定字段或旧实现故障 | 定位[历史实现资料](../assets/course-reference/docs/production/lesson-authoring-playbook.md)或[排障记录](ppt-background.md)的相关段落，不加载旧制作流程作为现行要求 |

若当前源混有不应参考的其他候选，可提取不含布局答案的通用绘图函数或使用原版 SVG；明确输入边界，避免把可复用能力和候选设计一起排除。

## 生成与接入

每小节一个完整 PPT 入口，节内部分和单页深链均定位同一套内容，不维护分部分版与完整版的平行副本；未制作部分在讲述线标注状态，不用历史页面代替。沿用本课生成源、播放器及唯一口播源，修改源后重新生成页面。字体、颜色、字号、安全区按项目视觉规范；本课程以 `docs/production/` 为准，独立分发时使用[包内视觉规范](../assets/course-reference/docs/production/visual-design-system.md)；[历史实现资料](../assets/course-reference/docs/production/lesson-authoring-playbook.md)仅供查询播放器字段，不提供另一套制作流程。编辑规则仍引用原处，不在 Skill 另定一套。

同时核对当前讲述设计与实际 PPT：比较对象与关系是否可见，每次展开是否带来新信息。同步实际 PPT 页与状态、对应口播和讲述线中的操作提示，共同材料与动作只在原处维护。使用稳定 ID 关联，讲师可见页码和标题从实际页序取得，增删页后核对受影响提示。联合优化任务可以综合调整画面和稿件；只改 PPT 时保留有效口播，需要改变内容设计则回到对应源处理。

**操作入口在这里一并完成**：逐项对照讲述线的打开、定位、展开和返回动作，让实际需要的 PPT 页提供对应材料入口。必用入口按讲师需要常显，其余可放操作菜单；来源链接与课程操作入口各有职责，不能互相代替。长材料直接定位到所讲标题、字段或步骤，入口名称与实际目标一致。逐字稿写材料名称与定位，链接维护在本课既有材料源，不手工复制多份 URL。

流程和关系按设计、代码或原记录核对；图中数量及引用可溯源。使用项目已有实现能力，确有指定工具约定时按其适用范围执行，缺失或失败时说明并采用可编辑替代。外部图和来源按[材料方法](materials.md#参考资料)及项目引用规则处理。

有实际页面后按[检查与修正](ppt-review.md)分别复看视觉、信息逻辑及技术接入。保存截图和产生通过记录不能替代实际查看；课程具体参数、代码能力与历史工具状态按当前环境确认。
