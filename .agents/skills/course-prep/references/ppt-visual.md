# PPT 视觉表达与构图

按编号读取完整正文：从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`；合并去重，已读且未变的不重读，缺号或截断时补取并核对结束标记。跨项目使用见 [PPT 入口的读取约定](ppt.md#编辑规则读取)。 图示与画面关系读 ED-008；只改不影响关系的颜色、线条或间距时按项目视觉参数核对，不默认展开解释逻辑规则。修改屏幕文字补 ED-001、ED-012、ED-014；涉及真实结果补 ED-020，来源补 ED-018；改变解释关系转信息方法。

新制、重排或优化视觉时读取本文。新制或实质重排时，与[信息组织](ppt-information.md)共同设计；纯视觉调整沿用有效信息与推进，发现对象、关系或取舍变化时再补读信息方法。初步布局形成后，继续结合新布局完善形象、关系、强调和整体观感。布局可以重建，视觉表达也可以重新设计，不以恢复旧图形为目标。

## 从内容寻找视觉表达

先看本页有哪些对象、动作、关系，以及希望观众先注意什么。可以从以下问题寻找表达，不必逐项使用一种图形：

| 画面需要 | 可尝试的思路与例子 | 怎样判断是否合适 |
| --- | --- | --- |
| 让对象和场景直观 | 人物与原话组成提问场景；文件轮廓承载名称与内容；几张纸叠放表示一批材料，前面一张展示可读实例；“多份”与“多种”分别用数量和名称或特征表达 | 是否容易认出谁在做什么、处理什么；图形与文字是否共同表达，而非互不相关地摆放 |
| 表达包含与选取 | 外框、文件夹轮廓、底色或距离划出整体，突出当前选中的部分 | 是否看得出局部属于哪里；分组已清楚时可以减少重复内框 |
| 表达顺序与交接 | 编号便于定位步骤；排列形成阅读顺序；箭头进一步表达动作、对象的交接或流转 | 是否真的有方向含义；不要把并列或语义对应误画成因果 |
| 让对应容易寻找 | 相关对象靠近、同类字段对齐，同色标注或引线连接两端 | 两端能否直接对照；已经紧邻对齐时，连线可以省去 |
| 表现变化与结果 | 复用同一对象，通过数量、位置、状态或局部高亮展示变化 | 是否看得出改了什么；示意数量与真实数量分清，准确值用文字交代 |

文字读得懂以后，仍可考虑如何让画面更直观、更有场景感。例如，把“用户反复提出要求”写在框里能交代事实；人物、气泡与接收要求的文件组合，则可把话语归属和处理过程同时呈现。两种方案怎样选，结合本页主题、占幅、观看体验及邻页节奏判断，不要求每个名词都画成图标。

人物、气泡、文件只是例子，可采用符合当前内容的其他形象。也可通过姿态、线条和色彩改善亲切感与观看体验，不要求每个风格细节传递一条新知识。保留事实与关系的准确性，留意无关细节是否争抢注意力。

初步布局完成后，可看还有哪些对象只靠读字才能识别、哪些关系需要来回寻找、哪些区域显得平淡或拥挤，再尝试合适的形象、边界、色彩或标注。视觉调整若能承担部分文字的解释，也可以回头缩短文字。新增元素的数量不作为完成标准。

## 按视觉问题选择样例

遇到对应难点时，在决定表达前查看相关样例的实际画面和展开；制作后可以并排比较。选择相同的表达问题，不必选择相同题材。样例中的页数、对象和步骤不照搬。

| 当前难点 | 可打开的样例 | 重点观察 |
| --- | --- | --- |
| 画面只有文字框，缺少对象和场景 | [p03：人物与气泡](../assets/course-reference/guide.html#p03) | 人物、话语、动作和结果怎样组成场景，而非给每段文字贴图标 |
| 多份材料与一个实例难以同时表达 | [pfind：原话与材料](../assets/course-reference/guide.html#pfind) | 叠放表示一批材料，前层保留可读实例；颜色与连线建立具体对应 |
| 重点不突出或比例不直观 | [p01：比例与标注](../assets/course-reference/guide.html#p01) | 先让证据可见，再用比例和局部标注引导注意 |
| 两个方案看起来像两段说明 | [p02：同屏比较](../assets/course-reference/guide.html#p02) | 同一比较基准下，怎样让差异直接出现在对象和关系中 |

逐步观察、误做与迁移说明的唯一源是 [ppt-examples.json](ppt-examples.json)，说明页在上述入口查看。若样例不可访问，采用本项目可打开的同类成品并说明缺口。样例提供思路，不据此锁定图形形式。

## 内容组、矩形与留白

构图前读取项目视觉参数。本仓库用[视觉规范的画布分区](../../../../docs/production/visual-design-system.md#2-画布与分区1280720)及[视觉基调](../../../../docs/production/visual-design-system.md#3-视觉基调)；第三章采用该文件的完整矩形与讲师覆盖层规则。跨项目才查[包内快照](../assets/course-reference/docs/production/visual-design-system.md)，并核对目标项目约定。历史页型展示用于取材，不限定新页面组合。

区分可用矩形、实际内容组和组内元素。可用范围不要求填满；本课程常规页把实际内容组水平、垂直居中，左右和上下留白均衡。组内可以左对齐，图文提问也可共同构成主体，不把整体居中做成每行文字居中。

内容上下拥挤而左右空旷时，可一起调整占幅、字号与组织方式。相关内容靠近，组间留出明显距离；同级元素沿共同对齐线组织，不必等宽等高。边框和颜色会改变重心，字体会改变占幅，需一起看。放大主体时留意对象与连线是否被拉散。

构图可采用开放分组、分支、汇合、对照、图文组合等形式；连续查看邻页，既保持视觉语言，也让布局适应不同关系。有疑问时可用同份内容尝试两种小样，比较实际效果，无需每页都制作多方案。

## 关系与视觉层次一起安排

从“第一眼看哪里，随后看哪里”选择位置、大小、字重、颜色、深浅与线条。具体字体、字号、语义色沿用视觉规范。同级同作用内容保持一致，代码、终端、diff 和表格证据保持工整；概念线框可沿用轻微手绘风格。

| 关系或问题 | 可尝试的表达 |
| --- | --- |
| 同一对象的多个版本 | 同构小图或前后图并排，共用尺度与比较维度，突出实际差异 |
| 输入变成输出、条件决定分支、检查后重做 | 让关键输入、动作、结果与条件可见；箭头指向明确的对象或路径，回线说明由谁判断、回到哪里及何时停止 |
| 多条支路同时进行后汇总 | 用独立支路及汇总点表达，避免一摞卡片掩盖并行关系 |
| 数量、比例或集合差异 | 需要精确比较时用共同基线、长度或直接数值，避免只靠字号和任意面积暗示；精确查值可用表格；比较前核对单位、分母、条件与尺度是否一致 |
| 多处同时争抢注意力 | 减弱辅助文字与边界，突出当前对象；保留比较仍需要的背景信息 |
| 要强调原文中的具体证据 | 就近使用括号、下划线、圈选或引线；标注指到具体词、值或范围 |

方块与连线可以一起排：先试阅读方向，为回路和标签留空间，再调整节点大小与距离。直接交接可用短线，回路可沿主体外侧走弧线；路径拥挤时可以移动对象，不必把所有问题交给折线绕行。同一画面中的箭头含义应能分辨，必要时补简短标签。

参考 pfind，对应项较多时可以突出当前一组，其他组保留但降低显著度。稳定的语义色帮助认出对象；颜色之外也用名称、位置或形状保持可辨识性。去杂乱和建立重点分别考虑，相关方法依据与适用边界见[背景来源 S3–S7](ppt-background.md#方法来源与适用边界)。

形成可查看的片段后，进入[视觉检查](ppt-review.md#视觉检查)，并核对[信息逻辑](ppt-review.md#信息逻辑检查)是否仍成立。具体制作和素材复用见[实现与接入](ppt-implementation.md)。
