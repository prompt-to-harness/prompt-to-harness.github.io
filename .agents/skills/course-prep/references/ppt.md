# PPT 制作与验收入口

PPT 帮助学生看懂当前问题、对象和关系，并形成直观、协调、有表现力的画面。本页负责选择工作入口和判断完成；具体方法按当前工作读取，不需要一次通读所有配套文件。

## 执行路径

先定位本次要处理的页与状态、当前讲述线或已有口播、真实材料、可编辑源及讲师要求。页数、逐页职责与关键教学递进沿用已定讲述设计；修改已有课件时从现状继续。需要改变教学安排时回到对应内容源，按授权处理。

| 当前工作 | 现在读取 | 怎样继续 |
| --- | --- | --- |
| 新制页面，或实质调整文字、布局、图示与展开 | [信息组织与展示推进](ppt-information.md)和[视觉表达与构图](ppt-visual.md) | 两者一起参与设计。形成初步布局后继续完善视觉表达，用实际画面反查信息取舍；不是先把文字框定死再贴图 |
| 只优化已有页面的视觉 | [视觉表达与构图](ppt-visual.md)及本页内容 | 沿用有效信息与推进；若布局暴露关系或取舍问题，再读信息方法处理 |
| 只改措辞、数值或局部内容 | [信息组织](ppt-information.md#内容与画面联合设计)及对应原始材料 | 按实际影响复看该页；文字占幅或关系表达变化时转入视觉方法 |
| 修复制、链接、展开实现或播放器接入 | [实现与接入](ppt-implementation.md) | 先定位源和复用条件，只查相关实现资料；不启动整套教学设计 |
| 审查已有 PPT | [检查与修正](ppt-review.md) | 分别检查视觉与信息逻辑，技术可用性另行核验；发现问题后回到对应方法 |

开始实现前读[实现与接入](ppt-implementation.md)，识别画布、素材和播放器限制；涉及画布范围的约束在构图前确认。首个可查看片段及交付前按[检查与修正](ppt-review.md)复看，局部修改检查受影响范围。纯链接、复制或播放器修复只进入[技术与接入核验](ppt-review.md#技术与接入核验)，出现画面或含义变化时再扩展检查。完整制作覆盖信息与视觉两个职责，修链接等小任务不因此扩大范围。

方法可以往返：内容过密可能要精简，也可能要换构图；形象与标注能承载信息时，文字可以随之缩短。工作结果仍写入既有 PPT 源和授权涉及的讲述线，不新增独立分镜或阶段审批。

## 编辑规则读取

只改标点读 ED-001；只改屏幕措辞读 ED-001、ED-012、ED-014，核对原意与受影响画面即可，不必加载整份信息方法。数值修改同时核对原始材料，涉及运行结论补 ED-020。其他任务的编号由上表对应方法直接列出，不返回公共任务表选择。

从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`，取得完整正文；多入口编号合并去重，已完整读取且未变化的不重读。缺号或超限按报错处理，分批补取；输出须有 `ED-READ-COMPLETE` 且编号齐全，工具提示截断时仍须补读。规则中的依赖按当前判断展开。完整约定见[编辑规范](../../../../docs/production/editorial-checklist.md#按编号读取)。

跨项目使用包内同源脚本 `scripts/read-editorial-rules.py`，显式指定目标项目规则源：`python3 <Skill目录>/scripts/read-editorial-rules.py --source <规则文件> ED-编号 ...`。目标项目采用本包课程规则时，规则文件为 `assets/course-reference/docs/production/editorial-checklist.md`；该文件是带日期的分发快照。在本课程仓库始终使用当前仓库源；跨项目先核对当地约定，缺少同编号规则时说明映射缺口，不能把失败提取当成已经读取。

## 共同原则

- **继承内容，检验呈现。** 保留关键对象、条件、依据、事实边界与讲师决定；具体文案、形象和布局可结合实际效果调整。不把保留信息理解成保留全部文字，也不把优化理解成保留全部原图形。
- **简约与表现力一起考虑。** 减少冗余和寻找信息的负担，同时设计对象、场景、关系和重点的呈现。可以重构布局，再结合新布局补充或重做视觉表达；原图形不是必须保留的清单。
- **方法提供思路，规范界定边界。** 人物、文件、边框、编号、箭头与颜色都是可选表达，不设数量或固定页型。事实准确、授权范围、可读性及本项目已定视觉参数仍需遵守。
- **按问题取得上下文。** 信息方法引用相关证据与推进样例；视觉方法引用构图和形象样例；实现资料只在用到时展开。方法依据与历史故障按需查[背景资料](ppt-background.md)，不要让过时页型、工具或历史状态覆盖当前任务。

## 完成标准

交付可打开的实际页面及可编辑源，按[阶段三制作交接](preparation.md#阶段三制作与交接)接回讲述线，并分别说明：

1. **视觉**：对象和场景是否直观，主体、重点、比例、颜色、字体、线条与留白是否协调，画面是否具备适合本页内容的表现力。
2. **信息逻辑**：必要对象、关系、条件与依据是否准确可见，阅读与展开是否自然，是否支持对应讲述。
3. **技术与接入**：相关展示状态、链接、复制、切换及生成源是否实际核验，尚有什么缺口。

前两部分均看实际成品；技术通过不代替表达检查。具体检查与修正思路在 [PPT 检查](ppt-review.md)。作者自查、讲师审阅与试讲分别报告，不能从一次自查推断学生已经学懂。
