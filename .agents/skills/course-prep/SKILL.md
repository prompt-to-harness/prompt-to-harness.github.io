# 全课备课

## 指导职责的唯一来源

本课程的备课流程、教学组织、讲述设计、PPT、逐字稿及验收方法统一在本 Skill 及 references/ 维护。章节 Skill 只定位本章内容源和实现入口，不重复通用方法。仓库大纲与 Discussion 提供教学内容，docs/production/ 提供编辑判据、视觉参数和实现资料；它们不另定备课流程、固定页型、阶段审批或必装绘图 Skill。历史方法与分发快照不作为本仓库的并行指导。

## 先确定任务与阶段

整体路线是**内容设计 → 讲述设计 → 课件制作 → 逐段协作改稿 → 检查、定稿与交接**。先根据讲师当前问题、指定材料与最新决定，定位本轮的章、节、部分和工作范围。新备课沿路线推进；已有成果从当前问题继续，保留有效设计、原稿与讲师修改。只要求某阶段或局部修改时交付到该范围；完整备课已获授权时按准备程度持续推进，不增加阶段审批。只讨论时在对话交付，不据此写文件。

<a id="discussion-与讲述页的分界"></a>
<a id="discussion讲述页与-ppt-的职责"></a>

Discussion 决定讲什么、为什么讲、讲多深，以及知识、材料和教学递进；讲述线落实如何借眼前画面解释、指哪里、何时展开或切换，并确定 PPT 逐页安排；PPT 呈现学生需要看见的对象、证据和关系。Discussion 也会选画面和动作，但不维护每次点击与展示状态。具体对照例子见 [Discussion 与讲述页的分工](references/discussion.md#discussion-与-html-的职责及修改方式)。

| 阶段 | 当前解决的问题与产出 | 继续的依据 |
| --- | --- | --- |
| 1. 内容设计 | 围绕学习目标核对官方资料和原始案例，确定各节分工、收获、知识深度、讲解顺序与选材；写入同一份有效 Discussion，以章、节和部分编号定位。 | 目标、任务、选材、证据与演示安排足以支持讲述设计；影响关键结论或演示方式的缺口已处理。按 Discussion 的完成标准说明可推进范围。 |
| 2. 讲述设计 | 从 Discussion 展开具体解释，明确观察什么、凭什么判断、每次展开或切换新增什么。交付本节讲述线，包含解释安排、材料定位、操作时序及 PPT 收录总页数、页序、各页用途与展示安排。 | 当前范围的讲法、依据与切换明确，影响讲法的材料缺口已处理，逐页安排可供制作；不要求逐字稿写齐，其余缺口保持工作稿状态。 |
| 3. 课件制作 | 根据讲述线制作正式 PPT、可照读口播及操作入口，回写制作调整。讲述页两种视图、逐段组织、画面与口播对应、材料与 Prompt 入口、样式及渐进迁移统一使用本阶段的[共用制作规范](references/preparation.md#阶段三制作与交接)。 | 实际画面、可照读口播与操作入口落实已定讲述设计，完成本轮制作自查并回写调整；按[制作交接](references/preparation.md#阶段三制作与交接)说明可继续协作改稿或进入综合核对的范围。 |
| 3a. 逐段协作改稿 | 讲师指定当前部分并手改、口述或批注；Agent 接续最新稿，按阶段三的共用规范修改、逐句回比并交回。讲师继续反馈当前部分或转到下一部分，逐轮深化。 | 本轮反馈已处理，实质变化与待判断项清楚，入口可打开。分别说明 Agent 已处理、讲师已审阅及仍待审阅的范围。详见[逐段协作改稿](references/spoken-script.md#逐段协作改稿)。 |
| 4. 检查、定稿与交接 | 顺着 PPT、讲述页与真实演示逐段核对、连读、修正，交付修正后的成果及可打开入口。备课完成时交齐授课所需成果，包括可用的录制讲稿与操作入口，并检查授课画面和教学安排是否适合学生。讲师确认后再启动学生独立使用材料的制作，边界见 [学生材料交接说明](../../../docs/production/student-materials-handoff.md)。 | 当前版本的本轮主讲范围已综合核对，发现的问题已修正并复验，实际授课入口可用；按[录制核对](references/recording-alignment-workflow.md)说明遗留项与接续位置，分别报告制作自查、综合核对、出声试读、讲师审阅及试讲。 |

准备与设计可以往返：先把主题展开为待讲清的关系或判断，再预看原文、对象与记录，对影响讲法的未知项做最小预跑；按观察修订选材与解释，不用预设结论筛选结果。先把画面、内容和承接讲通，再展开缺少的新逐字稿。已有材料足够或只是局部修改时，不重跑整套准备。详细操作与检查进入“按任务读取方法”对应入口。

## 各阶段的设计层面与完成标准

逐段协作改稿沿用阶段三的产物和制作规范，单独维护讲师与 Agent 的反馈、回比和接续流程；发现涉及教学取舍的变更时回到对应阶段。进入专项方法前，按本轮范围检查下表涉及的设计层面。每格说明该阶段应形成的决定或可核对成果，完成时应能说明决定了什么、依据在哪里、下一阶段如何接续。决定沿用 Discussion 与讲述线的现有位置保存，按需引用材料和实际产物。局部任务核对受影响的层面及前后衔接。

| 设计层面 | 阶段一 · 内容设计 | 阶段二 · 讲述设计 | 阶段三 · 课件制作 | 阶段四 · 检查、定稿与交接 |
| --- | --- | --- | --- | --- |
| 学习目标与知识取舍 | 学生需要理解、判断或完成什么，前置知识、范围与深度明确，关键知识有依据。 | 观察、解释、推导与归纳逐步建立目标理解，所需前提有交代。 | 文案、图示和口播准确承载已定解释，保留判断依据。 | 对照实际讲授核对目标是否兑现，检查跳步、遗漏和越界。 |
| 项目、任务与 Prompt | 明确真实项目起点、任务要求、实验条件与完成依据。正式演示、学生复用任务及需要明确结果或比较条件的实验采用四要素 Prompt，快速探查可用简短请求，适用判断见[任务与实验设计](references/materials.md#任务与实验设计)。保存实际发送原文。沿用历史案例时明确原始请求与当前任务的差异及其影响。 | 安排任务介绍、请求展示与发送，以及历史案例和本次结果的承接，明确学生在何处取得完整输入。 | 展示与复制引用已定请求稿源，执行入口可用，口播准确解释任务条件。 | 核对显示、复制、实际发送的请求及其结果归属，确认案例条件支持当前讲法。 |
| 材料、证据与用途 | 明确每份材料支持的判断与用途，运行日志统一用 Inspect AI 展示，核实来源、条件、展示可行性及证据缺口，具体方法见[材料形态](references/materials.md#按教学用途选择材料形态)。 | 选定原句、代码、输出或画面的具体位置，安排必要上下文、观察顺序和据此判断的讲法。 | 实现可读的证据、准确定位与高亮，呈现所需上下文及材料身份。 | 从真实授课入口进入，检查证据可见、可读且与口播对应，结论符合证据范围。 |
| 教学顺序与跨节承接 | 章首导入、节内递进、跨节问题与任务的提出和兑现位置明确，项目接续起点一致。 | 落实转场、回扣、暂停思考及返回主线的位置，说明各段怎样增加理解。 | PPT、口播和讲述线共同实现承接，任务与材料引用一致。 | 连读本节首尾与相邻节，检查前置知识、作品状态和提出的问题能否接续。 |
| 画面与讲述组织 | 按教学用途选择作品、原文、演示、图解等呈现方式，明确各自承担的解释作用。 | 确定逐页安排、主讲停留、切换与口播要点。补充页标明支撑哪段讲述及是否录制展示，允许收录后跳过。 | 完成正式画面、可照读口播、操作提示、视觉层级和交互，制作调整回写讲述线。 | 按实际顺序逐段核对画面、讲述与动作，检查主讲路线及补充材料的归属。 |
| 演示环境与使用方式 | 确定现场或预存演示、所需环境和使用方式，通过必要预跑核实可行性，明确等待与异常时的教学安排。 | 写清启动、切换、等待、恢复和结束的时序，明确讲师所需入口与准备条件。 | 命令、服务、查看器和讲述页具备所需功能，实际安装版本与操作说明一致。 | 使用实际录制环境和入口走通所需操作，核对等待、后续交互及恢复，报告验证范围与遗留项。 |

发现问题时回到首次应作出决定的阶段处理，再核对受影响的下游。例如材料用途在阶段一定，证据停留位置在阶段二定，跳转和高亮在阶段三实现。若日志打开后看不到证据，先核对讲述设计是否明确了位置与观察范围，再判断需要补设计还是修实现。阶段四负责发现问题、修正后复验并确认当前成果的完成状态。

## 所有任务共用的判断

以下四项原则适用于所有任务，后列编号用于展开相应判断，不构成每次必读清单。详细 ED 按具体任务入口选取。统一从仓库根目录执行 `python3 tools/read-editorial-rules.py ED-编号 ...`，提取完整正文（含处理、例子与检查）；合并编号去重，已完整读取且未变化的不重读。缺号或超限时处理报错并分批补读，确认输出结束标记；跨项目的脚本与规则源定位见 [PPT 读取约定](references/ppt.md#编辑规则读取)；完整约定见[按编号读取](../../../docs/production/editorial-checklist.md#按编号读取)。

- **以学习结果取舍内容。** 从当前有效设计中明确学生需要理解或完成什么，再选择知识、案例和操作。每段材料应支持其中一项理解；案例涉及的其他专业能力按需要取舍，不因它有价值或能演示就展开教授。对应 ED-006、ED-021。
- **保留解释的依据与过程。** 具体对象、必要前提、判断依据和承接共同支撑理解。精简、润色或图解时保留这些关系；发现关系不成立，回到内容设计处理。对应 ED-002、ED-004、ED-008。
- **各产物承担各自职责。** 已定目标与范围沿用内容源，画面呈现关系，口播解释判断，备课记录保存取舍与状态；同步需要保持含义一致。局部改动保留其余有效内容及讲师修改。对应 ED-003、ED-011、ED-017。
- **结论以实际证据为限。** 区分原文事实、教学假设与实际运行；未知结果按观察方法准备。分别说明作者自查、技术检查、讲师审阅与试讲状态。对应 ED-015、ED-020。

这些判断用于选择、制作和检查，不需要逐段复制到交付物中。规则冲突时先遵循讲师当前明确要求，并按项目内容依据处理。

## 按任务读取方法

先按**本轮维护的产物**选择下表入口。优先看用户指定文件或页面及实际用途，不仅凭“画面”“讲述”等词或 `.html` 扩展名选方法；`screen-plan.json` 等源文件按它服务的产物归类。尚无目标产物时，讨论知识、顺序与选材默认进入 Discussion；明确要落实各画面的讲法、切换和逐页安排时进入讲述设计。仍有会改变交付物的歧义时，先问一个关键问题。

| 当前任务 | 首先读取 | 何时扩展读取 |
| --- | --- | --- |
| 小改动快路径：局部措辞、版式或口播润色 | [小改动快路径](#小改动快路径) | 涉及教学决定、事实、数字、画面顺序或演示动作时，进入受影响产物的方法 |
| 跨章巡检：比较各章共用入口、术语、状态与衔接 | [跨章巡检](references/recording-alignment-workflow.md#跨章巡检) | 发现需要修订的问题后，按授权范围进入对应产物的方法 |
| 讨论知识安排、选材或维护 Discussion | [Discussion 方法](references/discussion.md#执行路径) | 需要核实材料或预跑时读材料方法；提到画面和动作不自动进入 HTML 方法 |
| 维护讲述页的讲法、切换与 PPT 逐页安排 | [讲述设计](references/narration-html.md#执行路径) | 改页面实现时读 HTML 方法；新写或润色口播时读逐字稿方法 |
| 修改讲述页的布局、交互、保存、评论或构建 | [HTML 实现维护](references/narration-implementation.md) | 涉及教学讲法变化时再读讲述设计方法 |
| 制作、修改或审查 PPT 与图示 | [PPT 制作与验收](references/ppt.md#执行路径) | 视觉规范、样例和实现资料按该方法的对应环节读取；口播也在修改范围内时读逐字稿方法 |
| 批量成稿后与讲师逐部分改稿 | [逐段协作改稿](references/spoken-script.md#逐段协作改稿) | 制作与渐进迁移引用阶段三共用规范；本流程负责反馈接续与逐句回比手稿 |
| 新写、润色或审查逐字稿 | [逐字稿方法](references/spoken-script.md) | 需要改变画面或讲述安排时读对应方法 |
| 准备资料、证据或演示预跑 | [材料方法](references/materials.md#执行路径) | 结果返回当前维护的产物；不因准备完成而自动开始下游制作 |
| 整段录制验收，或同时调整 PPT、口播和演示顺序 | [录制核对与复验](references/recording-alignment-workflow.md) | 发现问题后读受影响产物的方法 |
| 跨阶段协调、新环境起步、定位目录、整理历史入口或交接 | [共用备课方法](references/preparation.md#阶段入口与产物位置) | 按问题读对应小节；新环境读“新环境的起步与质量校准”，交接读“交给其他窗口”；局部制作无需通读 |
| 修改本 Skill 的架构、方法或样例 | [行为验证与反馈维护](references/behavior-validation.md) | 先取得讲师明确授权；设计自动验收系统时才另读 [系统方案](references/recording-gates-proposal.md) |

跨产物任务分别加载受影响的方法；只读另一产物作参考，不触发它的维护流程或修改授权。先取当前任务的方法与必要材料，再按问题展开细节、样例和历史依据，不预先读取表内全部文档。已读且未变化的文件无需重复读取，相关方法更新后重读受影响部分。

在本课程仓库按当前方法列出的编号使用同一脚本，改后按适用条目核对。PPT 的任务分流与具体 ED 编号在 [PPT 入口](references/ppt.md#编辑规则读取)及对应方法就近提供。涉及实现与构建时读取 [工程约定](../../../docs/agents/courseware-workflow.md)。新旧决定按 [内容依据](../../../docs/agents/sources-of-truth.md)处理，讲师当前明确要求优先，不用旧文档覆盖新决定；其他项目使用自己的内容源与约定。

## 小改动快路径

适用于一页或几页的措辞、局部版式或口播润色，沿用当前教学决定、事实、数字、画面顺序和演示动作。执行时按目标选相应方法和适用 ED 条目，只读本次改动所需部分。

1. 定位唯一编辑源。Discussion 的措辞在当前 Discussion 改，讲述和口播在该节实际源改，PPT 局部版式在课件源改。受影响的生成物按项目入口重新生成。
2. 复验改动和直接衔接。改口播就连读前后段，涉及画面就打开受影响的页面及展示状态；确认原有依据、指向和承接仍成立。
3. 按产物运行覆盖该源的检查，核对报错和相关提示；推送前按仓库约定运行全量检查。交付时给出改动位置、实际检查与遗留项。当场改完且无遗留的日常修改随对话交付，正式留痕按仓库约定。

发现需要改事实、数字、教学推导、逐页安排或演示动作时，进入对应产物的方法，按实际影响核对 Discussion、讲述线与 PPT。

## 执行与交付

### 课程结构、产物职责与维护入口

<a id="课程结构产物职责与维护入口"></a>

备课设计维护 Discussion 与讲述线两层，并持续维护对应 PPT。每章一套有效内容设计，每小节一个讲述页和完整 PPT 入口；节内部分在同一入口定位。“一套”不限制底层物理文件数，已有章节沿用实际内容源，不为统一文件名另建副本。操作与口播沿用唯一源；PPT 分镜就是讲述线中的逐页安排。

提前准备事项写入 Discussion，网页、日志、运行记录与实操按讲述需要接入对应步骤，证据和预跑记录归本课材料目录。小节 README、LOG 和旧制作记录只供查阅；旧 `STORYBOARD.md` 只读取材，独有有效内容先接入当前 Discussion 或讲述线，不新建或同步独立分镜。

动手前确认目标产物、修改源和适用方法一致，修改源后生成必要页面。接续 Discussion 时读取对应条目、所属部分思路与小节目标和深度，必要时回看章级分工，不只取孤立一行；讲述线用编号和原文链接回指依据。目录与编号细节在需要定位、新建或交接时查 [产物位置](references/preparation.md#阶段入口与产物位置)。整理历史入口、合并页面或处理模板时查 [历史与模板边界](references/preparation.md#历史与模板边界)，保留原文、已保存修改、评论坐标和材料定位。

### 跨阶段继承与检验

前一阶段确定的学习目标、知识范围、事实依据、关键教学递进和讲师明确要求是下一阶段的约束。具体讲法与画面继续用实际材料检验，不机械转译上游文字。发现问题或更好的表达时说明理由与影响，在授权范围内更新对应内容源；涉及目标、范围、关键结论或讲师明确要求的变化时先对齐。教学递进与展示方便的点击顺序分别判断。

同步保持目标、范围和教学决定一致，不要求文字、表格或步骤逐项复制。教学决定写回 Discussion；操作、材料定位、画面映射与口播措辞在对应源处理。只读另一产物作参考不触发其维护流程；仅修改一方时指出对另一方的实际影响，授权覆盖时分别修改，否则列为待同步，无影响时不为同步而改动。多产物协调有疑问时查 [按产物协调工作](references/preparation.md#按产物协调工作)。

### 完成与交接

- **保留实际准备状态。** 讲述页接入已有画面安排、讲法、材料与承接时，保留工作稿、待讨论和占位，标明口播或 PPT 待补。接入已有内容不等于完成阶段 2，也不自动允许提前扩写台词。具体接入读 [尚未成稿的部分](references/narration-html.md#尚未成稿的部分怎样接入)。
- **检查与任务范围一致。** 完成前按当前产物的方法检查，局部修改核对受影响的前后衔接；整段录制核对按上表入口执行。实际画面、内容关系与技术可用性分别核验，不以生成文件或技术通过代替表达检查。
- **给出可接续的结果。** 交付当前阶段、有效设计、实际产物与可编辑源的入口、检查结果及未完成项。阶段 2 直接列明 PPT 总页数及逐页对应；只完成内容设计时给 Discussion 的具体位置。不能只报阶段名称或泛称设计文档。跨窗口交接读 [交给其他窗口](references/preparation.md#交给其他窗口)，按本轮范围列全完成与未完成部分。
- **决定与日常检查分开保存。** 需要沿用的教学决定写回对应内容源，日常进度、自查与构建结果随对话交付。录制视图沿用有效讲述线和唯一口播源，作为授课准备的一部分。学生独立使用材料以确认后的教学内容为依据，另行确定用途、格式、阅读组织和发布范围；不默认交出 Discussion、讲述线或完整口播，也不默认采用现有阅读模式。

### 方法维护

通用方法由本 Skill 及 references 维护，专属 Skill 单向引用；使用通用方法无需安装或读取 harness-prep。历史案例的产品、页数、编号和局部授权不推广为全课要求，实际课页与独立样例不固化为通用模板。

修改 Skill 须有讲师明确授权。反馈先判断属于课程决定、共用判断、环节方法、样例还是工具问题，再按 [唯一更新位置表](references/preparation.md#新经验的唯一更新位置)修改原处。反复出现问题时，区分是否取得指导、是否进入执行、检查能否识别偏差，按 [行为验证方法](references/behavior-validation.md)核对效果，不只追加提醒。修改后检查入口与相关引用；交接提醒后续会话读取更新，不假设运行中的会话自动重载。
