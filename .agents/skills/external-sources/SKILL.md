---
name: external-sources
description: 给一章找外部佐证（官方文章、研究报告、KOL 在 X 上的帖子）：在章设计阶段从讲透问题出发批量调研、核实原文、截图、做版式样稿，交讲师挑选后写进章文件，再往下流到分镜和页面；也可用于给某一节或某几页补。讲师说“找点外部材料”“加个 backup”“有没有官方文章或推文可以引”“这一章开头怎么引入”时使用；可以一次批量做一整章。
---

规则的唯一来源是 `docs/production/external-sources.md`（用在哪、选材标准、截图还是重画、文件放哪、截图工具）。本 skill 不复制规则，只规定顺序。

1. **从讲透问题出发**。读章文件（已迁移的章是 `courseware/<章>/README.md`）的讲透问题和章文件里已有的“外部佐证”表；按问题逐条列出要找佐证的位置，再加章首引入一处，每处写一句“这里要证明或引出什么”。不从现有页面出发：分镜和课件已经有了也一样，先定章文件里的表。只补某一节或某几页时，也先写清它们对应哪个讲透问题。
2. **先查已有的**。读 `courseware/<章>/materials/external/README.md` 总索引，按主题查已有素材，再读 `docs/research/` 里相关的报告；已登记的不重复找，标“不用”的不再推荐，除非理由已经不成立。
3. **批量调研**。每个位置找两三条候选，来源按规则文件的优先级排列；位置多时用子代理并行，每个子代理负责几个位置，要求返回链接、作者、日期、要点和核实状态。每条候选都要打开原文核对；WebFetch 打不开的（403、需要 JS）用内置浏览器读。X 帖子在浏览器里打开原帖核对原话和日期。
4. **写候选池**。新建或更新 `docs/research/reports/<标题>.md` 与 `docs/research/notes/<标题>/`（格式见 `docs/research/README.md`，并在索引表加一行）：报告按位置列候选和推荐理由，笔记逐条写来源、要点、核实状态，以及和课件现有说法的出入。发现课件里的说法与原文不一致，单独列出来，不顺手改课件。
5. **截候选图**。只给推荐的候选截图，用 `courseware/tools/capture-source.py` 存到 `courseware/<章>/materials/external/<主题>/`（主题划分和迁移规则见规则文件“文件放在哪里”），文件名写成 `<来源>-<主题>.png`；每张截完都要打开看一遍（有没有浮层、裁切、空白过多），不合格的调参数重截。每一张都在章目录的总登记表里加一行，状态写“候选”，并附重新截取的命令。站点要人工验证时用 `--headed`，等讲师过验证；不要绕过验证码。
6. **交讲师挑选**。按讲透问题列出候选：每条写用法、建议的形式（证据页：帖子、证据页：图表、重画、现场打开原网页，见规则文件“放图的版式”），附截图路径和原文链接，给出推荐。截图能读清的用截图；要重画的，用 `courseware/tools/redraw.py` 同时出课程手绘版和 Excalidraw 版；截图也能用但重画可能更好的，三版并排。推荐上屏的候选先做版式样稿：打开本地课件页，在浏览器里按建议的形式渲染再截图，不改课件文件；样稿要带上画面最下一行的原文链接，看字能不能读、连链接行在内会不会超出版面，结论写进登记表。讲师回复之前，不改章文件以外的分镜和页面。
7. **写回章文件，再往下流**（讲师确认后）。先把选定的材料写进章文件的“外部佐证”表（问题、材料、形式、拟用在哪节），登记表改状态；然后按“只从上往下改”的顺序更新节表和分镜，最后做页面：采用的截图移到小节的 `external/`；构建时内联的重画 SVG 与图元保留在章内主题目录（见规则文件），页面按选定的形式做，出处在画面上可见；原文链接写进 `refs` 并保持 `kind="live"`（默认值），让链接显示在画面上、录制时能点开，不要写成 `read`（`read` 放映时隐藏）。要重画的，按视觉设计规范画；来源行、必要署名与制作信息的分层遵守规则文件“来源标注”，不另写重复的出处行。不用的图删掉，登记表里保留这一行和理由。改页面时同时按 `lesson-polish` 的顺序检查。
8. 跑 `make check`（证据页没有画面上的原文链接会报错）。汇报时分开说哪些已核实原文、哪些只是二手，哪些截了图、哪些没截；不写“教学效果已验证”。
