## 示例与实录的界限

可先制作并明确标为教学示例：虚构身份和项目资料、分类与权限情境题、完整条件的链接题、Prompt 澄清对话、人工植入错误及示意 Diff、首页草图和文件树示意。

必须实际核验：CLI 与模型可用性、权限配置行为、真实工具调用、首页生成与浏览器运行结果、构建结果、实际 Diff 和检查点对应提交。示例不计为这些项目通过。

## 后续需要确认的决定

1. 示范首页的身份与内容、项目数量、链接和按钮行为、视觉要求；技术栈已确定为 React + TypeScript + Vite，无需重选。
2. 实际录制平台、CLI 版本和模型接入路径；不得默认尚未实测的接入可用。
3. 分类与权限题是否采用现有自编草案，或有指定原题需要对齐。
4. 统一分发基线待冻结；正式应用沿用当前课件的根目录文件范围。

## 素材索引与准备顺序

当前讲稿引用 M01–M12、V01–V06，交付包中尚缺与这些编号一一对应的当前版附件索引。应补“编号、真实文件路径、服务页码、示例/实录/待核验状态”，避免把旧版材料地图视作附件已齐。

建议顺序：确认 Brief 与示例内容 → 补完整 Prompt → 冻结环境并跑通 → 从同一轮执行提取证据包 → 对齐题卡、模板和素材索引。
