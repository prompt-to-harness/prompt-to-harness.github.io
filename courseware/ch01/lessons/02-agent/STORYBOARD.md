## 呈现约定

- 六个学习段落拆成短页，每页最多五个呈现状态；点击下一步或方向键推进，回退可恢复上一步。
- 阅读模式展示完整证据和答案；演示模式先提问后揭晓，末步恢复全亮。减少动态效果时取消过渡。
- 沿用共享播放器与讲稿数据结构，仅为带 `steps` 的课件启用步骤导航。局部样式和画布缩放仅加载于 1.2。
- 画布 1280×720，正文 y=262–632；标题避开右上角 300×225 讲师区域；y=640–680 留字幕，底部六段章节条。
- 纸色、语义色、本地站酷快乐体 / 长仓体 / Noto Sans SC / JetBrains Mono 遵循视觉规范。证据用直线和印刷体；概念框及箭头轻微手绘。

## 素材与事实边界

- 原欢迎语来自 `starters/personal-homepage/setup-check/index.html`。请求、返回、Diff 和结果画面均标注为教学示意，不能作为 Codex 实操通过证据。
- 八张卡依据原 P11 备课草案重排，保留“待与 M06 原题核对”标记，不宣称原题已核验。学员需对照 1.1 本人记录补证据。
- 不推断隐藏思考，不给固定 token 数，不将每个工具调用都描述为必须逐次弹窗确认。
- `pretty-mermaid` 保存并渲染逻辑源；`archscribe` 按相同节点和连接生成手绘校样与 Excalidraw。正式课件使用适配正文区和分步交互的内联 SVG，逐项核对拓扑。
- 15 分钟为编排预算；静态字数估算与浏览器检查不等于课堂试讲或学习效果验证。
