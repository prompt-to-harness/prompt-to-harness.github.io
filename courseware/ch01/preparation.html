首次任务与验收

继续使用课前准备取得的本地练习项目，把首次欢迎语修改请求发给 Codex CLI，只把 h1#welcome-message 改为“你好，欢迎来到 Vibe Coding 课堂！”。先复述、计划、确认，再修改；不改其他内容、布局、文件，不安装、不发布。

刷新同一份项目的页面，核对文字与布局，再检查完整 diff 和 git status。有问题就记录具体差异，限定范围修正后再检查；没有实际修正时如实写明。课件里的故障例子单独标为写法练习。

保存首次欢迎语修改记录

完成修改后，由自己整理环境状态、目标复述、小计划、人工确认、前后截图、diff、审查结论和实际修正记录，保存到 docs/evidence/CH01_ENVIRONMENT_AND_FIRST_LOOP.md。这份记录另行整理，不属于刚才授权 Codex 修改欢迎语的范围；若要请 Codex 写记录，先单独说明允许写入的文件。
