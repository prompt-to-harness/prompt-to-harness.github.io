第 1 章 · Prompt

课前准备与排障

开课前，按这一页取得练习项目、装好 Codex CLI。页面里的命令都在终端（命令行窗口）里运行。第 1.1 节只改一个现成的 HTML 页面；用 React + TypeScript + Vite 搭建个人主页，要到第 1.5 节。

取得练习项目

课程模板是 course-starter 仓库，里面有项目说明、欢迎语任务卡和环境记录单。先按项目说明，用模板创建你自己的仓库，再克隆到本地，不要放进课程仓库里面。下面以课程仓库旁边的 projects/personal-homepage/ 为例：在课程仓库根目录打开终端，把“你自己的仓库地址”换成实际地址后运行：

git clone 你自己的仓库地址 ../projects/personal-homepage
cd ../projects/personal-homepage
git rev-parse --show-toplevel
git rev-parse HEAD
git status --short

后三行依次确认：当前在练习项目的根目录；当前提交的完整编号（SHA）；有没有未提交的改动。目标目录已经存在时，不要覆盖里面的内容，换一个新目录名。把课程模板的版本和你自己仓库的提交编号写进环境记录单。

刚创建的项目里还没有 package.json，也没有正式的个人主页，这是正常的。写个人主页任务（1.4）时要用的材料在项目根目录的 PROJECT_BRIEF.md 与 PLACEHOLDER_CONTENT.md，工具版本说明见 docs/setup/TOOLCHAIN.md。

安装 Codex CLI 并登录

按官方 Codex CLI 安装说明选择你的系统安装。然后在练习项目目录里运行 codex 启动它，登录课程所用模型服务的账号，确认它能读取练习文件，并看清哪些操作需要你批准。

课程主要使用 MiniMax M3 模型。安装 Codex CLI 和登录模型服务是两步，分别确认。截图或录屏时不要露出密钥。

Node.js 与 npm 在创建个人主页（1.5）之前装好，版本以 docs/setup/TOOLCHAIN.md 为准。1.1 只改一个 HTML 文件，用不到 Node；不要为了绕开环境问题提前创建 React 项目。

记录环境与起点

在练习项目根目录的终端里运行：

git --version
codex --version
codex --help
pwd
git rev-parse --show-toplevel
git branch --show-current
git rev-parse HEAD
git status --short

把输出的版本、目录、分支、提交编号和改动状态填进环境记录单。看到不认识的改动时，先保留、弄清来源，不要直接清空。Node/npm 还没装好，就记为“待补做”。

在浏览器里查看练习页

用浏览器直接打开练习项目里的 setup-check/index.html 就够了。如果想在 1.1 的课件页面里嵌入查看，再在 projects/personal-homepage/ 根目录另开一个终端运行：

python3 -m http.server 4174 --bind 127.0.0.1

然后打开环境检查页。这条命令在本机 4174 端口启动一个本地网页服务；只开一个，确保浏览器里看的和 Codex 改的是同一份文件。

第一次任务与检查

按 1.1 的任务请求，只把 h1#welcome-message 改成“你好，欢迎来到 Vibe Coding 课堂！”。先让 Codex 复述目标和计划，你确认后再改；不改其他内容、布局和文件，不安装依赖，不发布。

改完刷新浏览器，看文字和布局；再用 diff 和 git status 看改动范围。发现问题就限定范围让它修，修完再检查一遍。没有发现问题，就如实记为“本轮通过”。

遇到问题时

  • Codex CLI 用不了：可以先用图形界面入口完成同一个任务，记为临时通过；最晚在 1.3 节（工具与权限）结束前补上 CLI。
  • 登录失败或模型不可用：记下报错（去掉密钥等敏感信息），先看课程视频，恢复后再补做。
  • Node 没装好：不影响 1.1，创建个人主页（1.5）之前补齐。
  • 页面没变化：检查打开的文件路径、网页服务是在哪个目录启动的，再刷新；不要去改别的文件，让页面“看起来对了”。
  • CLI 一直没装好：可以继续看 Prompt 相关的内容，需要 CLI 的实操先暂停。只看视频，或者用其他 AI 工具完成，都不算 CLI 这一步通过。

保存第一次协作记录

按环境记录单，把环境、Codex 复述的目标、小计划、你的确认、修改前后截图、diff、检查和修正过程整理成 docs/evidence/CH01_ENVIRONMENT_AND_FIRST_LOOP.md。写这份记录是另一项任务，要单独确认，不要和欢迎语修改混在一起。

这份记录后面还会用到：1.2 用它拆开 Agent 的执行过程，1.3 补上 CLI 与权限的记录，1.4 在它的基础上写清任务，1.5 才真正创建个人主页。
