## P07 05 · 三个项目与路线

[对应课件](index.html#p07)

第 0 章 · 访谈 05 / 08 · 预算 240 秒

### 串场与回答提纲

串场提问：这门课会带大家做哪些项目，为什么这样安排？

讲师 A 先介绍场景：第 1–3 章从个人主页起步，发布到 GitHub Pages，再做记忆翻牌和“60 秒躲避与收集”小游戏，体验反馈、调试与插件实践。

讲师 A 接着介绍：第 4–6 章在 JSON Crack 中做 JSON Diff，比较两份 JSON 并显示差异。第 7–9 章在 dependency-cruiser 中完成快照身份与新鲜度判定核心，用固定输入判断代码地图快照是否适用。

讲师 B 补充安排理由：从较小的可见产品，走到已有代码库中的明确规则，再到可重复的协作环境。Prompt 负责写清任务，Vibe Coding 通过实际结果持续反馈；SDD 把规格与验收放进仓库，Harness 将上下文、工具、验证与人工决策组织起来。后面继续保留前面学到的能力。

讲师 B 范围说明：三个仓库互不依赖，不继承前一项目的代码或会话；第三项目只做限定的数据层任务，不承诺开发完整的新 CLI 或可视化平台。

转场：看完路线，我们再具体回答，课程结束时大家能带走什么。

### 回答顺序

A 讲三个项目约 2 分钟，B 讲递进与范围约 2 分钟。两人可补充各自最看重的一个阶段。

### 课程依据

深蓝平台交付版与共同内部大纲的三个项目、四层能力与最低门禁；本页不展示尚未完成的项目截图。

## P08 06 · 成果与独立能力

[对应课件](index.html#p08)

第 0 章 · 访谈 06 / 08 · 预算 180 秒

### 串场与回答提纲

串场提问：学完以后，大家能带走什么，又能独立完成什么？

讲师 B 从成果回答：个人主页成果包包括可访问的页面、游戏与交付证据；JSON Diff 成果包包括规格、功能实现、测试与变更记录；Harness 成果包包括判定核心、工程环境资产与前后评测证据。三份成果分别验收。

讲师 A 从能力回答：收到模糊需求时，能指出需要人决定的问题；能把目标拆成可验证的小任务；能读懂关键修改、运行相关检查，并判断接受、修正还是回退。

讲师 A 说明迁移：结课后的挑战会从固定课程基线开启新会话，接收没在正课实现过的小需求，完成澄清、拆分、一个任务的实现与验证。评价看行为和证据，不要求复刻讲师的聊天内容。

转场：这些目标对初学者有什么要求，遇到看不懂的地方又该怎么办？

### 回答顺序

B 先答成果，A 补充可独立完成的任务，各约 90 秒。

### 承诺边界

作品与能力都是课程目标，需实际完成验收。避免就业保证、效率倍数或看完视频就能独立开发任意项目的承诺。

讲师 A 补充自己的入门建议：〔建议待填〕。课程主要使用 Codex CLI，安装与账号路径在第 1 章按核验后的资料操作。

讲师 B 从卡点回答：先保留完整报错与复现条件，把任务缩小到相关文件或函数。可以让 AI 解释，但要回到源码、运行结果和测试核对。无法解释或验证的改动，先暂停、拆小或回退。

讲师 B 补充自己的处理办法：〔建议待填〕。随后引出最后一问：跟课时怎样练，才会把这些方法变成自己的能力？
