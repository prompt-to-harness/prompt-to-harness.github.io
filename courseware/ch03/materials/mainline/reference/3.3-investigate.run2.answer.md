## 关键发现：牌堆里根本没有重复的牌

`src/components/MemoryGame.tsx:4-17` 的 `CARD_FACES` 是 **12 个互不相同的词**，`createDeck()`（`src/components/MemoryGame.tsx:41-45`）只做 `map` + `shuffle`，`shuffle` 只改变顺序、不复制元素。

```
faces: 12, unique: 12, duplicates: []
```

所以整副牌里任意两张牌的 `face` 都不相等 → `src/components/MemoryGame.tsx:107` 的 `first.face === second.face` **永远为假** → 配对分支是死代码。

- `setMoves`（`src/components/MemoryGame.tsx:116`）**一次都不会执行**，步数永远是 0。

- 代价：改动最大（基本重写组件），当前阶段收益不匹配，除非打算继续加提示/计分等功能。
