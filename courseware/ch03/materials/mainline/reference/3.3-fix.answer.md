## 需要你在浏览器里复验的场景

`npm run dev` 打开页面，建议按顺序过这 6 条：

1. **核心复现**：新一局 → 翻两张不同的牌 → 等 900ms 翻回 → 步数应为 **1**。
2. **配对计数**：翻两张相同的牌 → 步数 **+1**（从 1 变 2），"剩余"减 1。
3. **不重复计数**：连开 3 个回合（2 个不匹配 + 1 个匹配）→ 步数应为 **3**，"剩余"为 5/6。确认没出现一步加 2。
4. **可通关**：一直翻到全部配对完 → 应出现胜利提示，"剩余 0 / 6 对"，且**步数 ≥ 6**。这是验证 id 唯一性最有效的一条：如果 id 有重复，会出现卡片异常或配对错乱。
5. **胜利提示的数字对不对**：确认"用了 N 步"里的 N 和统计栏步数一致（这是我在调查里标的 H8 风险点，React 批处理理论上是新值，但值得实测一次）。
6. **重新开始**：点"重新开始"→ 步数归 0、"剩余"回 6/6、焦点落到第一张牌。顺手清一下 `localStorage` 里的 `memory-game-best-moves` 再看"最佳"，避免旧数据干扰判断。
