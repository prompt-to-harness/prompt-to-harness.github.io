## 暂不选入与后续准备

- 不选全量 npm 输出、heredoc 排障、后台进程反复中断：不直接支持本轮两节的学习判断。
- 不选全部视觉微调；优先保留翻牌正反面这一处有明确证据的例子。
- 不做两游戏耗时、token 或模型优劣排名；任务和范围不等价。
- 不把原始 Skill 全文搬进公开课件，不把整份私有日志直接发布；正式取材时再截最小片段并去敏。
- 不把隐藏配对信息通关或保持无敌跑满计时包装成自然试玩。
- Plugin 安装、发现、生效及停用，讲师真人试玩、主页集成与发布均未由本轮覆盖，另补证据。
