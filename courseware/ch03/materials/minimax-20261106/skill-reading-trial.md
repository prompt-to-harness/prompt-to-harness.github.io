### 技术选择

**分类**：2D、网格/卡牌类、回合制点击交互 → 按 game-studio 默认走 **Phaser** 路径。

> 一个诚实的说明：此体量用纯 DOM/CSS 也能实现且更轻。但按 plugin 默认规则选 Phaser；若你倾向零依赖，唯一值得翻转的决定就是这一项，其余设计不变。

### 玩法中的具体决定

- **牌组**：N 对相同牌面（默认 4×4 = 8 对），Fisher–Yates 洗牌后成对铺开，保证必然有解。
- **核心循环**：翻第一张 → 翻第二张 → 比对 → 分支：
  - **匹配**：两张牌保持翻开并标记为"已解"，播放轻微高亮动效；
  - **不匹配**：停顿约 800ms 让玩家看清 → 翻回背面；**该期间锁定输入**。

### 素材安排

**本游戏不需要 sprite-pipeline**。sprite-pipeline 面向"动画条带"流程（种子帧 → 整条生成 → 归一化锚点），静态卡牌无动画条，用不上且会引入不必要的复杂度。

- **牌背**：程序化生成（Phaser Graphics 绘制几何纹样 → 烘焙为纹理），零外部资源、可换色。
- **牌面**：以 Unicode 符号 / 图标字形（♠♥♣♦ 或 emoji）为主，配 CSS/Phaser 文字渲染，零资源体积。

### 检查安排

**截图必做**（canvas 游戏 DOM 断言不足）：背面初始态、翻开态、错配翻回瞬间、匹配高亮、胜利面板、桌面 1440×900 与移动 390×844 两档视口。
