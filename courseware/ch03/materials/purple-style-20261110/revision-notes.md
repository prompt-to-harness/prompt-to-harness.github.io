## 二、标注约定的落地方式

- `〔原作值〕`：逐项对应 `source-game/styles.css`、`index.html`、`src/*.js` 中可直接读到的数值与行为，例如色值、圆角、阴影、模糊半径、动效时长、缓动曲线、断点、浮层焦点行为。
- `〔迁移建议〕`：只出现在三类位置——原作行为在新玩法下可能失效处（状态色的瞬时/持续之分）、原作结构属玩法专属处（网格列数与列宽、主舞台形态）、原作未涉及但视觉体系需要补齐处（危险/奖励/玩家的语义区分、颜色不得为唯一状态通道）。

- **断点行为未验证**：≤520px 下工具栏纵向拉伸、操作按钮均分仅见于 CSS 声明与 `screenshot-mobile.png` 的静态结果，未做多尺寸实机回归。
- **对比度未量化**：焦点环 `#56d6c6` 叠加在主色实心按钮上、次级文字 `#a3abcf` 叠加在玻璃面板上的对比度数值未计算，未做 WCAG 认证判断。
- **色值未二次取样**：所有色值照抄源码声明，未用取色器对截图采样；斜纹 45°/6px、渐变角度等按源码记录，未逐像素核对渲染结果。
- **渐变角度范围是归纳值**：「92°–165°」沿用初稿的总结，本次只核对到实例（92°、140°、150°、160°、165°），未系统枚举全部渐变声明，范围边界可能不准。

- **语义色规则缺少量化阈值**：「色相明确分离」「至少一项冗余线索」是方向性表述，没有可自动校验的数值门槛。
- **元数据格式未校验**：`name` / `description` 的 frontmatter 写法沿用初稿，本项目内没有 Skill 规范校验器可供比对。
- **结构核对范围**：仅核对了行数、章节层级、表格列数、无代码围栏 / 无 HTML 标签 / 无 CSS 声明，未逐个色值回读比对（按要求未反复启动校验）。
