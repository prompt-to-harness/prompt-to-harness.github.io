## 实现要点（依据 SKILL.md + references/source-visual.css）

1. **页面底**：左上 `#2a3170` / 右上 `#3b2a63` 双光晕 + 160° `#0c1022→#171e3d` 渐变，`background-attachment: fixed`（§2 〔原作值〕）。
2. **材质层级**：统计块与主行动面板用玻璃（`rgba(255,255,255,0.07)` + 1px `rgba(255,255,255,0.14)` + blur 10px + 圆角 13/16px + 阴影阶梯）；预览占位用斜纹纹理（45° 白 8% 6px 交替 + 140° `#4b5bd6→#8b5cf6` + 内高光），再叠 55% 压暗以免抢主按钮的主角位（§2、§3）。
3. **控件反馈**：主按钮 140° `#7c8cff→#9a6bff` + `0 8px 20px rgba(124,140,255,.32)`，hover 只提亮度 1.08，active 下沉 1px 缩放 0.99/0.12s；音效开关关闭态＝透明度 + 删除线（不换第二种主色），焦点环 3px `#56d6c6` + 2px 偏移仅 `:focus-visible`（§4）。主色只出现在主按钮，统计数值用文字-主，语义色只挂图标并配形状+文字冗余（§1、§5）。
