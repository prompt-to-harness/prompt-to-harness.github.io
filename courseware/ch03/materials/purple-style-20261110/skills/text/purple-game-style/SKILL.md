# 紫色网页小游戏视觉风格

本风格提炼自一份已完成的紫色记忆翻牌游戏，约束的是视觉语言：色彩角色、材质、层级、反馈、节奏；玩法结构（关卡、计分口径、盘面、文案）由新游戏自行决定。适用单页网页小游戏与轻量互动工具，桌面优先、兼容移动、不依赖框架；不适用于写实材质或高对比认证的严肃业务界面。它是一套基调而非模板：结构可变，但色彩角色与层级语义必须自洽（同一屏里主色只应有一个主角）。

标注约定：`〔原作值〕` 来自该作品源码与截图，可直接沿用；`〔迁移建议〕` 是从原作推导的做法，不是硬性规定，换玩法时可调整。

## 1. 色彩角色

〔原作值〕先定义语义 token 再在组件里引用，不要在组件里散写色值。

| 角色 | 值 | 承担什么 |
|---|---|---|
| 底色 | `#0c1022` → `#171e3d` | 页面底层渐变，由深到浅 |
| 光晕 | `#2a3170` / `#3b2a63` | 左上偏蓝、右上偏紫的两团径向光 |
| 主色 | `#7c8cff`（第二停靠点 `#9a6bff`） | 靛紫：当前主行动、当前选中项 |
| 焦点色 | `#56d6c6` | 青绿：键盘焦点环专用 |
| 成功/奖励 | `#4ade80` | 达成、正确、奖励 |
| 危险 | `#fb7185` | 错误、危险、失败 |
| 文字-主 | `#eef1ff` | 正文与数值 |
| 文字-次 | `#a3abcf` | 标签、副标题、说明 |

〔原作值〕玻璃层：面板填充 `rgba(255,255,255,0.07)`；次级按钮底 `rgba(255,255,255,0.12)`；面板描边 `rgba(255,255,255,0.14)`；凹槽底 `rgba(0,0,0,0.28)`。

角色规则〔建议，但与原作实现一致〕：页面底永远是深蓝紫，内容靠半透明白提亮而不是实色块；主色只给「当前唯一的主行动」或「当前选中的选项」，避免同屏多个主色实心块互相抢戏；焦点色保留给焦点环——用主色会被按钮自身填充吃掉。

〔原作值〕渐变方向集中在 92°–165°（左上→右下）以形成统一光照方向；需要区分层级时改角度或改色相差，不要改方向。

## 2. 背景、材质与层级

〔原作值〕页面底为三层叠加：左上 1100×620 径向光晕 `#2a3170`、右上 900×600 径向光晕 `#3b2a63`、再叠 160° 线性渐变 `#0c1022`→`#171e3d`；底色固定，不随页面滚动。

〔原作值〕三种材质：

- **玻璃面板**（工具栏、统计块）：`rgba(255,255,255,0.07)` 填充 + 1px `rgba(255,255,255,0.14)` 描边 + 10px 背景模糊 + 16px 圆角 + 阴影 `0 18px 40px rgba(0,0,0,0.35)`；浮层面板改用有色玻璃，165° 渐变 `rgba(42,49,112,0.96)`→`rgba(30,24,60,0.96)`，比页面底更亮更饱和，读作「浮出」。
- **实体表面**（卡牌正面、可交互块）：近白渐变 `rgba(255,255,255,0.96)`→`rgba(226,230,255,0.9)` + 1px `rgba(255,255,255,0.55)` 描边，与玻璃面板相反，读作「实体被照亮」。
- **斜纹纹理**（卡背、占位块、封面）：45° 白色 8% 实线 6px 与透明 6px 交替，叠在 140° 渐变 `#4b5bd6`→`#8b5cf6` 上；描边 `rgba(255,255,255,0.22)`，顶边加一道 `rgba(255,255,255,0.28)` 内高光，得到微妙的倒角错觉。

〔原作值〕层级四级，从后到前：页面底 → 玻璃面板层（工具栏、统计块）→ 交互实层（主按钮、选中项、实体表面）→ 浮层（结算/说明，遮罩 `rgba(6,9,22,0.72)` + 6px 背景模糊）。

〔迁移建议〕层级靠「亮度 + 模糊度 + 不透明度」三重叠加表达，而不是堆叠多层阴影；越上层越亮、越不透明、描边越明显；遮罩层永远压得住下层内容。

## 3. 形状与节奏

| 项目 | 原作值 | 说明 |
|---|---|---|
| 圆角 | 5 / 9 / 11 / 13 / 16 / 22px；实体表面 8–13px | 小标签 → 分段项 → 按钮 → 统计块 → 面板 → 浮层面板 |
| 阴影阶梯 | `0 4px 12px` → `0 6px 16px` → `0 8px 20px` → `0 18px 40px rgba(0,0,0,0.35)` | 选中 → 实体表面 → 主按钮 → 浮层 |
| 间距与宽度 | 区块 12–20px、控件组 12px、面板内边距 12px 14px、密集方块 6–12px（均随视口变化）；内容最大宽度 960px 居中、横向页边距 12–24px | 后两项为〔迁移建议〕：只保留「单列居中 + 窄屏可拉伸」的关系，不要求网格列数与列宽 |

## 4. 控件与反馈

| 控件 | 常态 | hover | active | 选中 / 开启 |
|---|---|---|---|---|
| 主按钮 | 140° 渐变 `#7c8cff`→`#9a6bff`，白字，阴影 `0 8px 20px rgba(124,140,255,0.32)` | 亮度提到 1.08（不换色） | 下沉 1px 并缩放到 0.99，0.12s | — |
| 次级按钮 | `rgba(255,255,255,0.12)` 底 + 1px `rgba(255,255,255,0.14)` 描边 | 底色提到 `rgba(255,255,255,0.18)` | 同上 | — |
| 分段控件 | 外槽 `rgba(0,0,0,0.28)`，项字色 `#a3abcf` | 字色转 `#eef1ff` | — | 主色渐变底 + 白字 + `0 4px 12px rgba(124,140,255,0.35)` 外发光 |
| 状态开关（音效一类） | 同次级按钮 | 同上 | 同上 | 关闭态：透明度 0.5 + 删除线，不换另一种主色 |

〔原作值〕常规过渡 0.18s ease，按钮按下 0.12s ease；焦点环 3px 实线 `#56d6c6` + 2px 偏移，仅键盘可见焦点时出现，鼠标点击不亮圈。

- 正文与数值用 `#eef1ff`，次级色 `#a3abcf` 只承载辅助信息，关键数值提为主色或文字-主。〔原作值〕
- 语义状态要有可编程语义（开关用 aria-pressed 一类），颜色不能是唯一的状态通道。〔迁移建议〕

## 5. 危险、奖励与玩家的语义配色

〔原作值〕原作只有成功绿 `#4ade80` 与危险玫红 `#fb7185`，且只做一次性反馈：配对成功转绿（面色 `rgba(219,255,231,0.95)`→`rgba(180,245,205,0.9)`，描边绿 + 2px 外发光 `rgba(74,222,128,0.55)`，前景元素降到 0.62 透明度）；配错转粉（面色 `rgba(255,226,232,0.95)`→`rgba(255,205,214,0.9)`，描边玫红）并抖动 0.42s。

〔迁移建议〕新玩法常把语义持续挂在元素上，因此状态色要分两类用：

- **瞬时反馈**：改面色 + 2px 描边或外发光 + 一次短抖动，随后回到常态；适合对错判定、命中反馈。
- **持续语义**：稳定的填充色 / 描边 / 图标，不闪烁、不抖动；适合障碍物、奖励物、玩家单位、锁定区域。

〔迁移建议〕语义配色允许按新玩法重新选择，但必须满足：危险与奖励在色相上明确分离（玫红对绿、或玫红对暖金），不要只靠明度区分；玩家单位用中性亮色或主色 `#7c8cff` 家族，与危险/奖励不同色；三者同屏时除颜色外至少再给一项冗余信息（形状、图标或文字标签）；持续存在的危险物靠稳定颜色与形状表达存在感，不用抖动。

〔原作值〕中间态（翻开但未配对）只加一圈主色描边 `rgba(124,140,255,0.75)`，不改面色——这让「暂时性」与「已解决」在视觉上分得开。

## 6. 动效与排版

〔原作值〕时长档：微反馈 0.12s / 常规 0.18s / 抖动 0.42s / 结构性变换 0.45s / 浮层淡入 0.22s / 浮层入场 0.3s。缓动：位移与颜色用 ease；浮层入场用带回弹的 `cubic-bezier(0.2,0.9,0.3,1.2)`；结构性变换用 `cubic-bezier(0.4,0.15,0.2,1)`。必须提供 `prefers-reduced-motion` 降级：动画与过渡时长归零、迭代次数为 1。

〔迁移建议〕若新玩法需要翻面或旋转类三维变换：元素上的动画只要带位移或缩放就会覆盖元素自身的静态旋转，必须在每个关键帧重复写出该旋转角度。

〔原作值〕字体栈：-apple-system、BlinkMacSystemFont、Segoe UI、PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans SC、通用无衬线。标题用渐变文字，92°，`#fff` 10% → `#b9c2ff` 60% → `#7ce7d8` 100%，字号 1.7–2.4rem，字距 0.5px；副标题 0.85–0.95rem 用 `#a3abcf`；统计数值 1–1.25rem、字重 650、等宽数字（tabular-nums）；标签 0.74rem、字距 0.5px。〔迁移建议〕计时、分数一类会跳动的数字必须用等宽数字，避免刷新时左右抖动。

## 7. 版式骨架（结构可替换）

〔原作值〕骨架关系：标题（居中 + 副标题）→ 工具栏（左设置组、右主行动）→ 数据条（若干等宽统计块，上标签下数值）→ 主舞台（居中）→ 页脚提示。工具栏横向排列、允许换行、间距 12px；数据条为等宽网格、间距 10px；≤520px 时工具栏改纵向拉伸、操作按钮均分。

〔迁移建议〕新玩法可以把主舞台换成网格、列表、画布或堆叠卡牌；只继承「居中 + 固定最大宽度 + 窄屏自适应」的关系，不继承原作的列数、列宽与牌阵形状。

## 8. 结算浮层

〔原作值〕遮罩 `rgba(6,9,22,0.72)` + 6px 背景模糊；面板为 165° 有色玻璃 `rgba(42,49,112,0.96)`→`rgba(30,24,60,0.96)`，1px `rgba(255,255,255,0.14)` 描边，圆角 22px，阴影 `0 18px 40px rgba(0,0,0,0.35)`，宽度上限约 420px。内容节奏：一个图标 → 标题（1.45rem）→ 说明（次级色，行高 1.7，关键数字提为主色）→ 一行按钮（主行动 + 次行动）。浮层行为：打开时焦点移到主行动按钮，关闭时焦点归还触发它的按钮，Esc 关闭，Tab 在面板内循环。

## 9. 复用检查清单

- [ ] 底色双光晕且固定；面板用半透明玻璃；主色只出现在当前主行动/选中项；焦点环 3px `#56d6c6` + 2px 偏移且仅键盘可见时出现；hover 靠亮度不换色；三态反馈齐全；危险/奖励/玩家可区分且不只靠颜色传达语义；瞬时反馈与持续语义表现不同；数字用等宽数字；浮层有焦点陷阱、Esc 关闭与焦点归还；提供动效降级；已替换玩法专属内容（牌阵、图案、统计口径、文案）。
