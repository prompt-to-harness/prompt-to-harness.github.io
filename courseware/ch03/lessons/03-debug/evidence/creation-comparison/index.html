## 快速上手

1. 复制整个 `templates/` 目录到新游戏目录，改名为 `index.html` + `styles.css` + `src/` 即可。
2. 打开 `index.html`，把 `<!-- ===== 场地：唯一需要替换的区域 ===== -->` 标记之间换成你的玩法 DOM。
3. 在你的玩法脚本里 `import { shell } from './shell.js'`，用 `shell` 更新 HUD：

```js
import { shell } from './shell.js';

shell.setStat('moves', '3'); // 更新「步数」
shell.setStat('pairs', '2/8'); // 更新「配对」
shell.setStat('time', '0:12'); // 更新「用时」
shell.setStat('best', '9 步 · 0:01'); // 更新「最佳」
shell.startTimer(); // 从此刻开始计时
shell.stopTimer();
shell.showResult({ // 弹结算浮层
emoji: '🎉',
title: '全部配对完成！',
lines: ['本局用时 <strong>0:03</strong>，共 <strong>9</strong> 步。'],
primary: { label: '再玩一局', onClick: () => shell.newGame() },
secondary: { label: '查看牌面', onClick: () => shell.hideResult() },
});
shell.sfx.match();
```

4. 起服务器（任意静态服务器均可）：

```bash
cd <新游戏目录>
python3 -m http.server 8000 # → http://127.0.0.1:8000/
```

## 落地步骤

1. 复制 `assets/purple-theme.css` 到新项目（作为基础样式表，与项目自己的样式表一起加载）。**不要修改这个文件**——它是跨项目共享的基线。
2. 按下面的「页面骨架」搭外壳：标题区 → 工具条 → 数据块 → 游戏主体 → 页脚；结算用浮层。
3. 游戏主体的布局自己写（棋盘、关卡网格、战场……），只复用主题提供的类名。
4. 如果新游戏确实有「牌面翻转」，再引入 `assets/card-flip.css`，并读 `references/card-game.md`。
5. 起本地服务：`node scripts/serve.cjs [目录] [端口]`。**不要直接双击 `index.html`**（见「实现约束」第 1 条）。

## 工作流

1. **复制资源**：把 `assets/css/` 下需要的文件拷进项目（三个 css 可独立引入；`stat-cards.css` 与 `result-overlay.css` 依赖 `purple-theme.css` 的令牌）。需要数据卡渲染/浮层行为时再拷 `assets/js/purple-ui-kit.js`。
2. **上主题**：`<body class="pg-body">`（或给容器加 `.pg-surface`）。标题用 `.pg-title`，副标题 `.pg-subtitle`。
3. **摆 HUD**：按下面的布局规则选容器形态——`.pg-stats--row`（回合制顶部横排）、`.pg-stats--rail`（实时侧边竖排）、`.pg-stats--inline`（实时底部横条）、`.pg-chip`（高频刷新的浮动读数）。
4. **接结算**：用 `ResultOverlay` 或静态 `.pg-overlay` 结构，`open({ emoji, title, text, rows, actions })`。
5. **核对令牌**：颜色/圆角/阴影一律引用 `--pg-*`，不要写死十六进制。令牌表与用法见 `references/tokens.md`。
