# Purple Game UI

一套可复用的紫色小游戏视觉系统。三个资源各自独立，也可以单独取用：

| 资源 | 文件 | 作用 |
|---|---|---|
| **主题** | `assets/css/purple-theme.css` | 令牌（`--pg-*`）、背景、标题、按钮、分段控件、焦点环、动效降级 |
| **数据卡** | `assets/css/stat-cards.css` | HUD 读数卡（顶部横排 / 侧边 rail / 底部横条 / 紧凑 chip） |
| **结算浮层** | `assets/css/result-overlay.css` | 结算面板：遮罩、图标、标题、明细行、按钮区 |

附加：`assets/js/purple-ui-kit.js`（数据卡渲染 + 浮层焦点管理）、`assets/html/components.html`（静态标记片段）、`assets/preview.html`（可视化预览）。

## 工作流

1. **复制资源**：把 `assets/css/` 下需要的文件拷进项目（三个 css 可独立引入；`stat-cards.css` 与 `result-overlay.css` 依赖 `purple-theme.css` 的令牌）。需要数据卡渲染/浮层行为时再拷 `assets/js/purple-ui-kit.js`。
2. **上主题**：`<body class="pg-body">`（或给容器加 `.pg-surface`）。标题用 `.pg-title`，副标题 `.pg-subtitle`。
3. **摆 HUD**：按下面的布局规则选容器形态——`.pg-stats--row`（回合制顶部横排）、`.pg-stats--rail`（实时侧边竖排）、`.pg-stats--inline`（实时底部横条）、`.pg-chip`（高频刷新的浮动读数）。
4. **接结算**：用 `ResultOverlay` 或静态 `.pg-overlay` 结构，`open({ emoji, title, text, rows, actions })`。
5. **核对令牌**：颜色/圆角/阴影一律引用 `--pg-*`，不要写死十六进制。令牌表与用法见 `references/tokens.md`。

## 布局规则（核心）

**如果玩法要求玩家持续观察场地和读数，就让 HUD 靠近场地边缘——具体贴哪条边，按玩法的自然视线落点和操作手决定。**

- 回合制、读数只在操作后变化 → HUD 在场地上方一条横排（视线切换成本被回合节奏摊薄）。
- 实时、读数持续变化 → HUD 贴场地左/右竖向 rail 或底部横条，别单独占据屏幕一端。
- 只有一两个数值需要真盯着（血量、剩余时间）→ 做成 `.pg-chip` 贴在场边缘，其余统计退到边栏。
- HUD 不得覆盖场地的可交互元素；数值变化用 `tabular-nums`，每秒刷新也不能让布局抖。

按玩法选边、网格实现示例、验收清单见 `references/layout.md`。

## 用法片段

HTML（数据卡 + 浮层）：

```html
<link rel="stylesheet" href="css/purple-theme.css">
<link rel="stylesheet" href="css/stat-cards.css">
<link rel="stylesheet" href="css/result-overlay.css">

<div class="pg-stats pg-stats--rail">
  <div class="pg-stat">
    <span class="pg-stat__label">生命</span>
    <span class="pg-stat__value">3</span>
  </div>
</div>
```

JS（渲染 + 浮层）：

```js
import { renderStats, updateStats, ResultOverlay } from './purple-ui-kit.js';

const stats = renderStats(document.getElementById('hud'), [
  { key: 'hp',   label: '生命', value: 3,  state: 'good' },
  { key: 'time', label: '用时', value: '0:00' },
]);
updateStats(stats, { hp: 2, time: '0:12' });   // 值变化时自动播放一次高亮脉冲

const overlay = new ResultOverlay(document.getElementById('overlay'));
overlay.open({
  emoji: '🎉',
  title: '全部配对完成！',
  text: '本局用时 0:03，共 9 步。',
  rows: [{ label: '用时', value: '0:03' }, { label: '最佳成绩', value: '9 步 · 0:01', state: 'good' }],
  actions: [{ label: '再玩一局', primary: true, onClick: () => overlay.close() }],
});
```

## 约束

- 类名与变量一律 `--pg-` / `.pg-` 前缀，避免与宿主项目冲突。
- 焦点环（3px `--pg-accent-3`）不要删；结算浮层必须能 `Esc` 关闭、Tab 焦点循环、关闭后焦点归位（`ResultOverlay` 已实现）。
- 颜色不能单独传达含义，配上文字或形状变化。
- 不要给宿主页面全局加 `backdrop-filter` / 重置样式，除非项目本身就是新页面。
- 想先看效果：起一个静态服务器打开 `assets/preview.html`（ES Modules 需要 http，`file://` 会被 CORS 拦截）。

## 游戏事件的声音反馈

开发可交互小游戏时，沿用现有布局与视觉组件，并接入 `assets/js/purple-sound.js` 的声音反馈；若任务明确要求无声，则不接入。这个独立 ES Module 不依赖页面结构或 `purple-ui-kit.js`，不要为接入声音改变 HUD 位置、浮层用途或玩法效果。

- 复制该文件到项目，导入 `sfx`、`setSoundEnabled`、`isSoundEnabled`。音效库来自整页版的声音实现及其躲避游戏中的事件扩展。
- 按实际游戏事件接线：确认开始可用 `sfx.tick()`，收集成功用 `sfx.pickup()`，受伤用 `sfx.hurt()`；胜利用 `sfx.win()`，失败可用 `sfx.mismatch()`。翻牌和配对仍可用 `flip()`、`match()`。只为游戏实际存在的事件接线，每次事件调用一次，不在绘制循环或持续按键中重复播放。
- 用明确的音效开关调用 `setSoundEnabled(value)`，用 `isSoundEnabled()`同步状态。首次播放应来自玩家的开始或其他真实操作；浏览器没有音频能力时，游戏仍须可玩。
- 保留原有可见反馈：声音补充收集、受伤和按钮反馈，不替代闪光、数值变化、浮层等视觉信息，也不规定场地布局。
- 验证开始、收集、受伤等已接线事件能发声，静音后这些事件不再发声；同时复查原有布局、开场/结算浮层和玩法反馈。

/**
 * 用 WebAudio 现场合成音效，不依赖任何外部音频文件。
 * 浏览器要求用户先有交互才允许播放 AudioContext，这里做惰性创建。
 */

let ctx = null;
let enabled = true;

export function setSoundEnabled(value) {
  enabled = Boolean(value);
}

export function isSoundEnabled() {
  return enabled;
}

function getContext() {
  if (!enabled) return null;
  if (ctx === null) {
    const Ctor = window.AudioContext || window.webkitAudioContext;
    if (!Ctor) return null;
    try {
      ctx = new Ctor();
    } catch {
      ctx = null;
    }
  }
  if (ctx && ctx.state === 'suspended') ctx.resume().catch(() => {});
  return ctx;
}

/** 播放一个音符。 */
function tone(freq, duration, { type = 'sine', delay = 0, gain = 0.15 } = {}) {
  const audio = getContext();
  if (!audio) return;
  const start = audio.currentTime + delay;
  const osc = audio.createOscillator();
  const vol = audio.createGain();
  osc.type = type;
  osc.frequency.setValueAtTime(freq, start);
  vol.gain.setValueAtTime(0.0001, start);
  vol.gain.exponentialRampToValueAtTime(gain, start + 0.015);
  vol.gain.exponentialRampToValueAtTime(0.0001, start + duration);
  osc.connect(vol).connect(audio.destination);
  osc.start(start);
  osc.stop(start + duration + 0.02);
}

export const sfx = {
  flip() {
    tone(520, 0.07, { type: 'triangle', gain: 0.09 });
  },
  match() {
    tone(660, 0.12, { type: 'sine', gain: 0.13 });
    tone(990, 0.16, { type: 'sine', delay: 0.08, gain: 0.11 });
  },
  mismatch() {
    tone(196, 0.2, { type: 'sawtooth', gain: 0.07 });
  },
  win() {
    [523, 659, 784, 1047].forEach((freq, i) => {
      tone(freq, 0.26, { type: 'triangle', delay: i * 0.11, gain: 0.13 });
    });
  },
  /** 收集到宝石 */
  pickup() {
    tone(880, 0.08, { type: 'triangle', gain: 0.11 });
    tone(1320, 0.12, { type: 'sine', delay: 0.07, gain: 0.1 });
  },
  /** 撞到障碍，扣血 */
  hurt() {
    tone(150, 0.26, { type: 'sawtooth', gain: 0.11 });
    tone(98, 0.3, { type: 'square', delay: 0.05, gain: 0.08 });
  },
  /** 开局倒数提示 */
  tick() {
    tone(720, 0.05, { type: 'sine', gain: 0.08 });
  },
};

const canvas = document.getElementById('arena');

function update(dt) {
  if (state.phase !== 'playing') return;

  state.elapsed += dt;
  state.timeLeft = Math.max(0, ROUND_TIME - state.elapsed);

  const p = state.player;
  let dx = 0;
  let dy = 0;
  if (keys.has('left')) dx -= 1;
  if (keys.has('right')) dx += 1;
  if (keys.has('up')) dy -= 1;
  if (keys.has('down')) dy += 1;
  if (dx !== 0 || dy !== 0) {
    const len = Math.hypot(dx, dy);
    p.x += (dx / len) * PLAYER_SPEED * dt;
    p.y += (dy / len) * PLAYER_SPEED * dt;
  }
  p.x = Math.min(W - PLAYER_R, Math.max(PLAYER_R, p.x));
  p.y = Math.min(H - PLAYER_R, Math.max(PLAYER_R, p.y));
  if (p.invuln > 0) p.invuln -= dt * 1000;

  const ramp = 1 + Math.min(0.8, state.elapsed / 60);
  if (state.elapsed >= state.nextObstacleAt && state.obstacles.length < 9) {
    spawnObstacle();
    state.nextObstacleAt = state.elapsed + 8;
  }
  for (const o of state.obstacles) {
    o.x += o.vx * ramp * dt;
    o.y += o.vy * ramp * dt;
    o.rot += o.spin * dt;
    if (o.x - o.r < 0) { o.x = o.r; o.vx = Math.abs(o.vx); }
    if (o.x + o.r > W) { o.x = W - o.r; o.vx = -Math.abs(o.vx); }
    if (o.y - o.r < 0) { o.y = o.r; o.vy = Math.abs(o.vy); }
    if (o.y + o.r > H) { o.y = H - o.r; o.vy = -Math.abs(o.vy); }
  }

  if (state.elapsed >= state.nextGemAt && state.gems.length < 6) {
    spawnGem();
    state.nextGemAt = state.elapsed + 1.4;
  }
  for (let i = state.gems.length - 1; i >= 0; i--) {
    const g = state.gems[i];
    g.phase += dt * 3;
    if (Math.hypot(g.x - p.x, g.y - p.y) < g.r + PLAYER_R - 3) {
      state.gems.splice(i, 1);
      state.score += g.value;
      shell.setStat('score', String(state.score));
      shell.sfx.pickup();
    }
  }

  if (p.invuln <= 0) {
    for (const o of state.obstacles) {
      if (Math.hypot(o.x - p.x, o.y - p.y) < o.r + PLAYER_R - 4) {
        state.lives -= 1;
        shell.setStat('lives', hearts(state.lives));
        shell.sfx.hurt();
        p.invuln = INVULN_MS;
        const ax = p.x - o.x;
        const ay = p.y - o.y;
        const len = Math.hypot(ax, ay) || 1;
        p.x = Math.min(W - PLAYER_R, Math.max(PLAYER_R, p.x + (ax / len) * 46));
        p.y = Math.min(H - PLAYER_R, Math.max(PLAYER_R, p.y + (ay / len) * 46));
        if (state.lives <= 0) { endRound('lose'); return; }
        break;
      }
    }
  }

  shell.setStat('time', String(Math.ceil(state.timeLeft)));
  if (state.timeLeft <= 0) endRound('win');
}

function draw() {
  ctx.clearRect(0, 0, W, H);

  const bg = ctx.createLinearGradient(0, 0, 0, H);
  bg.addColorStop(0, 'rgba(124,140,255,0.16)');
  bg.addColorStop(1, 'rgba(154,107,255,0.10)');
  ctx.fillStyle = bg;
  ctx.fillRect(0, 0, W, H);

  ctx.strokeStyle = 'rgba(255,255,255,0.06)';
  ctx.lineWidth = 1;
  for (let x = 0; x <= W; x += 40) {
    ctx.beginPath(); ctx.moveTo(x + 0.5, 0); ctx.lineTo(x + 0.5, H); ctx.stroke();
  }
  for (let y = 0; y <= H; y += 40) {
    ctx.beginPath(); ctx.moveTo(0, y + 0.5); ctx.lineTo(W, y + 0.5); ctx.stroke();
  }

  for (const g of state.gems) {
    const s = 1 + Math.sin(g.phase) * 0.12;
    ctx.save();
    ctx.translate(g.x, g.y);
    ctx.rotate(Math.PI / 4);
    ctx.scale(s, s);
    ctx.shadowColor = 'rgba(86,214,198,0.9)';
    ctx.shadowBlur = 14;
    ctx.fillStyle = '#56d6c6';
    ctx.fillRect(-g.r * 0.7, -g.r * 0.7, g.r * 1.4, g.r * 1.4);
    ctx.shadowBlur = 0;
    ctx.fillStyle = 'rgba(255,255,255,0.55)';
    ctx.fillRect(-g.r * 0.35, -g.r * 0.35, g.r * 0.6, g.r * 0.6);
    ctx.restore();
  }

  for (const o of state.obstacles) {
    ctx.save();
    ctx.translate(o.x, o.y);
    ctx.rotate(o.rot);
    ctx.shadowColor = 'rgba(154,107,255,0.8)';
    ctx.shadowBlur = 16;
    const g = ctx.createLinearGradient(-o.r, -o.r, o.r, o.r);
    g.addColorStop(0, '#8b5cf6');
    g.addColorStop(1, '#4b5bd6');
    ctx.fillStyle = g;
    ctx.fillRect(-o.r, -o.r, o.r * 2, o.r * 2);
    ctx.shadowBlur = 0;
    ctx.strokeStyle = 'rgba(255,255,255,0.35)';
    ctx.lineWidth = 2;
    ctx.strokeRect(-o.r, -o.r, o.r * 2, o.r * 2);
    ctx.restore();
  }

  const p = state.player;
  if (p.invuln <= 0 || Math.floor(p.invuln / 100) % 2 === 0) {
    ctx.save();
    ctx.shadowColor = 'rgba(86,214,198,0.95)';
    ctx.shadowBlur = 18;
    const pg = ctx.createRadialGradient(p.x - 4, p.y - 5, 2, p.x, p.y, PLAYER_R);
    pg.addColorStop(0, '#ffffff');
    pg.addColorStop(0.4, '#7ce7d8');

    ctx.fill();
    ctx.shadowBlur = 0;
    ctx.fillStyle = '#14213d';
    ctx.beginPath();
    ctx.arc(p.x - 4.5, p.y - 2, 2.4, 0, Math.PI * 2);
    ctx.arc(p.x + 4.5, p.y - 2, 2.4, 0, Math.PI * 2);
    ctx.fill();
    ctx.restore();
  }
}

function update(dt) {
  state.time -= dt;
  if (state.time <= 0) {
    state.time = 0;
    updateHud();
    endRound('time');
    return;
  }

  const p = state.player;
  let dx = (keys.has('right') ? 1 : 0) - (keys.has('left') ? 1 : 0);
  let dy = (keys.has('down') ? 1 : 0) - (keys.has('up') ? 1 : 0);
  if (dx || dy) {
    const len = Math.hypot(dx, dy);
    dx = dx / len; dy = dy / len;
    p.x += dx * PLAYER_SPEED * dt;
    p.y += dy * PLAYER_SPEED * dt;

  p.x = Math.max(p.r, Math.min(W - p.r, p.x));

    const o = state.obstacles[i];
    o.x += o.vx * dt; o.y += o.vy * dt; o.angle += o.spin * dt;
    if (o.x < o.r || o.x > W - o.r) { o.vx *= -1; o.x = Math.max(o.r, Math.min(W - o.r, o.x)); }
    if (o.y < o.r || o.y > H - o.r) { o.vy *= -1; o.y = Math.max(o.r, Math.min(H - o.r, o.y)); }

    if (p.invuln <= 0 && Math.hypot(o.x - p.x, o.y - p.y) < o.r * 0.72 + p.r * 0.72) {
      state.hp -= 1;
      p.invuln = INVULN;
      state.shake = 0.35;
      state.obstacles.splice(i, 1);
      burst(p.x, p.y, C.bad, 16);
      floater('-1 生命', p.x, p.y, 'bad');
      flashField('hurt');
      sfx.hurt();
      updateHud();
      if (state.hp <= 0) {
        state.hp = 0;
        updateHud();
        endRound('hp');
        return;
      }
    }
  }

  // 障碍逐渐变多（单一难度、固定节奏）
  const targetObstacles = 3 + Math.floor((ROUND_TIME - state.time) / 10);
  if (state.obstacles.length < targetObstacles && Math.random() < dt * 1.6) spawnObstacle();

  // 晶体
  for (let i = state.gems.length - 1; i >= 0; i--) {
    const g = state.gems[i];
    g.spin += dt * 1.6;
    const age = (ROUND_TIME - state.time) - g.born;
    if (age >= GEM_LIFE) {
      state.gems.splice(i, 1);
      continue;
    }
    if (Math.hypot(g.x - p.x, g.y - p.y) < g.r + p.r * 0.8) {
      state.gems.splice(i, 1);
      state.score += 1;
      burst(g.x, g.y, C.accent3, 14);
      floater('+1', g.x, g.y, 'good');
      flashField('pickup');
      sfx.pickup();
      updateHud();
    }
  }
  if (Math.random() < dt * 0.9) spawnGem();

  // 粒子
  for (let i = state.particles.length - 1; i >= 0; i--) {
    const q = state.particles[i];
    q.x += q.vx * dt; q.y += q.vy * dt;
    q.vx *= 0.94; q.vy *= 0.94;
    q.life -= dt;
    if (q.life <= 0) state.particles.splice(i, 1);
  }

  if (state.shake > 0) state.shake = Math.max(0, state.shake - dt);

  // 时间读数整秒刷新，避免布局抖动
  if (Math.ceil(state.time) !== Math.ceil(state.time + dt)) updateHud();
}

function draw() {
  ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
  ctx.clearRect(0, 0, W, H);
  ctx.save();
  if (state.shake > 0) {
    const s = state.shake * 12;
    ctx.translate((Math.random() - 0.5) * s, (Math.random() - 0.5) * s);
  }

  // 网格底纹
  ctx.strokeStyle = 'rgba(255,255,255,0.05)';
  ctx.lineWidth = 1;
  for (let x = 0; x <= W; x += 60) { ctx.beginPath(); ctx.moveTo(x, 0); ctx.lineTo(x, H); ctx.stroke(); }
  for (let y = 0; y <= H; y += 60) { ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(W, y); ctx.stroke(); }

  // 晶体：进度环显示剩余存在时间
  const nowAge = ROUND_TIME - state.time;
  for (const g of state.gems) {
    const remain = Math.max(0, 1 - (nowAge - g.born) / GEM_LIFE);
    const pulse = 1 + Math.sin(nowAge * 4 + g.spin) * 0.06;
    ctx.save();
    ctx.translate(g.x, g.y);
    ctx.scale(pulse, pulse);
    // 环
    ctx.lineWidth = 4;
    ctx.strokeStyle = 'rgba(255,255,255,0.14)';
    ctx.beginPath(); ctx.arc(0, 0, g.r + 8, 0, Math.PI * 2); ctx.stroke();
    ctx.strokeStyle = remain > 0.34 ? C.accent3 : C.warn;
    ctx.lineCap = 'round';
    ctx.beginPath();
    ctx.arc(0, 0, g.r + 8, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * remain);
    ctx.stroke();
    // 菱形本体
    ctx.rotate(g.spin * 0.4);
    const gr = g.r;
    ctx.beginPath();
    ctx.moveTo(0, -gr); ctx.lineTo(gr * 0.72, 0); ctx.lineTo(0, gr); ctx.lineTo(-gr * 0.72, 0);
    ctx.closePath();
    ctx.fillStyle = C.accent3;
    ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,0.65)';
    ctx.lineWidth = 1.6;
    ctx.stroke();
    ctx.restore();
  }

  // 障碍：紫色尖刺
  for (const o of state.obstacles) {
    ctx.save();
    ctx.translate(o.x, o.y);
    ctx.rotate(o.angle);
    ctx.beginPath();
    for (let k = 0; k < 3; k++) {
      const a = (k / 3) * Math.PI * 2 - Math.PI / 2;
      const px = Math.cos(a) * o.r, py = Math.sin(a) * o.r;
      k === 0 ? ctx.moveTo(px, py) : ctx.lineTo(px, py);
    }
    ctx.closePath();
    ctx.fillStyle = C.accent2;
    ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,0.55)';
    ctx.lineWidth = 2;
    ctx.stroke();
    ctx.restore();
  }

  // 玩家
  const p = state.player;
  if (p.invuln <= 0 || Math.floor(nowAge * 12) % 2 === 0) {
    ctx.save();
    ctx.beginPath();
    ctx.arc(p.x, p.y, p.r, 0, Math.PI * 2);
    ctx.fillStyle = C.warn;
    ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,0.8)';
    ctx.lineWidth = 2.5;
    ctx.stroke();
    // 朝向指示
    ctx.beginPath();
    ctx.arc(p.x, p.y, p.r * 0.45, 0, Math.PI * 2);
    ctx.fillStyle = 'rgba(20,14,40,0.55)';
    ctx.fill();
    ctx.restore();
  }

  // 粒子
  for (const q of state.particles) {
    ctx.globalAlpha = Math.max(0, q.life / q.max);
    ctx.fillStyle = q.color;
    ctx.beginPath();
    ctx.arc(q.x, q.y, q.r, 0, Math.PI * 2);
    ctx.fill();
  }
  ctx.globalAlpha = 1;

  ctx.restore();
}
