# 布局建议：HUD（数据卡）与场地的关系

## 核心规则

**如果玩法要求玩家持续观察场地和读数，就让 HUD 靠近场地边缘——具体贴哪条边，按玩法的自然视线落点和操作手决定。**

理由：读数只有在和它所描述的对象同处一个注视区时才是"免费"的。HUD 单独占据屏幕一端（哪怕是顶部），玩家每看一次数值都要移动视线并重新对焦；持续读数的玩法（节奏、物理、实时策略）会把这份代价乘以每帧。

反向的一条同样重要：**HUD 永远不要变成覆盖场地的浮层**，否则会挡住它本该解释的东西。

## 三条判据

1. **同注视区**：HUD 与场地之间不要隔着标题栏、说明文字这类与玩法无关的区块。
2. **贴边而非独立成块**：HUD 沿场地的某一条边排布，视觉上与场地"长在一起"。
3. **按玩法选边**：位置由玩家的视线落点和操作手决定，不由组件的默认样式决定。

## 按玩法选择 HUD 位置

| 玩法类型 | 读数变化频率 | 建议位置 | 容器形态 |
|---|---|---|---|
| 回合制（记忆翻牌、棋类、解谜） | 一次操作后变化 | 场地上方一条独立横排 | `.pg-stats--row` |
| 实时动作（平台跳跃、点击节奏、物理模拟） | 每帧/每秒变化 | 场地左侧或右侧的竖向 rail | `.pg-stats--rail` |
| 实时但以横向扫视为主（消除、接水果、管道） | 持续变化 | 场地底部的一条横条 | `.pg-stats--inline` |
| 双资源竞争（RTS、多资源建造） | 部分高频、部分低频 | 关键数值做成场地边缘浮动 chip，其余进侧栏 | `.pg-chip` + `.pg-stats--rail` |
| 窄屏 / 触屏 | 持续变化 | 贴场地底部（靠近拇指、远离刘海） | `.pg-stats--inline` + `.pg-chip` |

选边的具体依据：

- **操作手**：右手鼠标/右手持机 → 读数放场地右侧或底边；左手 → 左侧或底边。底边对两种手都安全。
- **视线落点**：玩家主要盯着场地哪个角落？读数放在那个角落的对边，这样视线扫过时自然会经过。
- **主数值**：只有一两个数值需要真正盯着（例如血量、剩余时间），就把它们做成 `pg-chip` 贴在场地内边缘；其余统计量退到边栏。
- **回合制的例外**：如果读数只在回合结束时变化（记忆翻牌就是这种），把 HUD 放在场地上方是**正确**的——视线切换成本被回合节奏摊薄了，没必要强行贴边。

## 网格实现示例

顶部横排（回合制）：

```css
.game {
  display: grid;
  gap: clamp(12px, 2vw, 20px);
  grid-template-areas: "hud" "field";
}
.game__hud { grid-area: hud; }
.game__field { grid-area: field; }
```

侧边 rail（实时）：

```css
.game {
  display: grid;
  grid-template-columns: auto minmax(0, 1fr);
  gap: 12px;
  align-items: start;
}
.game__hud { grid-column: 1; }
.game__field { grid-column: 2; }
```

底部横条（实时 / 窄屏）：

```css
.game {
  display: grid;
  grid-template-rows: minmax(0, 1fr) auto;
  gap: 10px;
}
.game__field { grid-row: 1; }
.game__hud { grid-row: 2; }
```

## 稳定性要求

- 读数频繁变化时，数值必须用 `font-variant-numeric: tabular-nums`（`stat-cards.css` 已内置），否则数字宽度抖动会带动布局抖动。
- 实时读数用 `.pg-chip` 而不是大卡片：卡片有 padding 和最小高度，频繁刷新会显得"鼓包"。
- HUD 宽度固定（`minmax(0, 1fr)`），不要让 HUD 的内容宽度反过来影响场地尺寸。
- 窄屏下（`max-width: 520px`）竖向 rail 改为横向排列在场地下方。

## 验收自查

- [ ] 眼睛从场地移到 HUD 再移回，距离不超过一个卡片的高度。
- [ ] HUD 没有遮住场地上的任何可交互元素。
- [ ] 数值每秒变化时，布局不抖动。
- [ ] 手机上 HUD 紧邻场地，且不超出安全区。
- [ ] 关掉声音/动画后信息量不变（`.pg-chip` 不依赖颜色单独传达含义）。
