### 认识 Plugin

从一份 Skill 退到 Game Studio 插件目录，先说清插件组织、提供整套相关能力的作用，再区分整套内容与其中同名的入口 Skill。打开目录和声明原文件，定位身份与内容之间的关系，不逐字段讲语法。用这个对象归纳：Skill 提供任务指导与资源，Plugin 将相关能力组织、分发和管理；插件可包含单份或多份 Skill，也可包含工具接入，具体能力须按实际内容判断。

学习结果延伸到选用：已有工具足够而缺少固定工作方法时，可寻找适用 Skill；需要一组相关指导时，可选用匹配的插件；缺少服务访问能力时，要检查工具连接和授权。三种情境用于迁移判断，Skill 与 Plugin 不是互斥选择，不以数量推断能力强弱。

采用前结合来源、版本、脚本及当前任务范围作基本审查，不把 manifest 的展示标签当成实际权限。用“有试玩 Skill 是否就能操作浏览器”作一次自主判断，并立即提供依据与解析。知道指导和工具的差别，才有条件判断一个插件能帮自己完成什么。
