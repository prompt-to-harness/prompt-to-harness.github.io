# 3.5 走出网页：Vibe Coding 还能怎么疯（以及怎么翻车）？

章内分工与设计依据见[第三章讨论版](../../../../docs/outline/ch03-discussion.md#35-经验分享占位)，章节入口见[章目录](../../README.md)。本文按分区结构维护本节连贯内容、逐页安排与素材状态；本节由另一位讲师承担章末经验分享，只看不跟做，不改动个人主页项目，也不作为进入第 4 章的判断门禁。

## 本节内容

### 前四节把游戏与 Skill 主线走完了，这一节换个视角

3.1 至 3.4 走完了本章主线：先经历记忆翻牌的真实开发，再读懂 Game Studio Skill 的组织方式，接着按风格需求修改指导并开发躲避游戏，最后建立寻找 Skill 与持续追踪 AI Coding 的信息入口。个人主页与两个小游戏的主线任务到这里收住，本节不再往个人主页仓库加新功能，也不补做 Plugin 生命周期实操。

这一节回答另一个问题：走出常规网页排版之后，Vibe Coding 还能怎么疯，又会在什么地方翻车？前几章我们做的都是页面和 2D 小游戏，容易让人以为 AI 编程只是更快地写表单、排卡片。本节把社区出圈现场、纯浏览器视听实验、一次性个人怪玩具和真实删库喜剧串成一条首尾呼应的四幕故事线，先打开想象力，再在笑声里看清纯靠自然语言“凭感觉”的代价边界，自然把接力棒交给第 4 章的 SDD（规格驱动开发）。全节只看不跟做，不设练习与自检题。

### 第一幕：从“忘掉代码存在”到三小时联机飞行游戏

先回到“Vibe Coding”这个词火起来的起点。2025 年 2 月初，Andrej Karpathy 发帖描述了一种新写法：完全顺着感觉走（fully give in to the vibes），拥抱指数级变化，甚至“忘掉代码存在”（forget that the code even exists），连键盘都懒得敲，直接对着语音输入改界面。这句原话之所以击中社区，是因为它把注意力从“一行行伺候语法”彻底挪到了“盯着眼前的体验提感觉”。

一个月后，没有专业游戏开发背景的独立开发者 Pieter Levels 用几个小时做出浏览器 3D 联机飞行游戏 `fly.pieter.com`，顺势引爆社区 `#vibejam` 游戏创作潮。人们第一次直观看到：以前跨一个技术栈要先啃几个月文档，现在试错门槛被砸穿了。把这两个真实节点立住，就能顺理成章抛出中间两幕要看的主菜——如果不局限于普通网页排版，只靠一个浏览器，我们还能拿它玩出什么花样？

### 第二幕：走出页面排版，在浏览器里驱动 3D 光影与声音

全节观赏性最强的重头戏放在纯浏览器里的视听创作，不安装 Blender 等重型桌面软件，也不提前引入第 4 章才讲的 MCP，避免跨章撞车。过去普通开发者碰 3D 场景或电子音乐，最头疼的不是没有审美，而是不知道怎样把脑海里的氛围换算成三维坐标、光照矩阵、着色器公式或合成器乐理参数；但既然 Three.js / WebGL 和网页音乐环境底层都是纯文本代码，就可以让 `Codex CLI` 负责数学和参数换算，人只像导演一样描述画面气氛与听感。

视觉线看一座漂浮在海面上的低多边形灯塔小岛（Three.js / WebGL）。起点是一版结构完整但像正午塑料玩具的白昼场景；演示时不报任何色号、角度或着色器公式，只提感官要求——改成黄昏逆光、海面加上金色波光反射、灯塔扫出柔和光束、空中飘起发光萤火虫粒子，只改氛围配置文件——直接对比热更新前后的光影反差，并用鼠标拖拽环绕观察。

听觉线看网页实时音乐环境 [Strudel](https://strudel.cc/)。它用几行简短代码描述鼓点与合成器循环，播放时每个音符对应的代码片段会在浏览器里实时高亮闪烁。先生成一段复古 8-bit 混搭电子鼓点的街机循环，再顺着本章刚做过的 60 秒躲避游戏追一句“进入最后十秒倒计时，节奏加快、加上扫频紧张感”，直接听两轮节奏与音色的变化，不拆乐理和函数语法。

### 第三幕：当写代码几乎零成本，做两个“无用”但快乐的怪玩具

看完视听大秀，再往下推一层：以前写软件很贵，动工前总要先算商业价值、目标用户和长期维护成本，没人会为了五分钟的小情绪专门立项。当生成代码的边际成本降到接近零，软件世界长出了一个新物种——只哄自己开心五分钟，或者解决眼前一次小麻烦就扔掉的个人一次性怪玩具。

这里连续看两个单页小作品。第一个是完全“无用”的解压玩具**果冻水母风铃**：鼠标划过半透明发光水母网格，弹簧质点立刻 Q 弹晃动，同时通过浏览器原生 Web Audio API 敲出五声音阶的清脆风铃声。第二个是解决聚会小痛点的**全员睁眼合照合成器**：四个人连拍三张卡通合照，每一张都有人闭眼或打喷嚏；把三张废片拖进网页，一键把每个人睁着眼的最佳头部区域无缝拼到同一张底图上，当场合成全员睁眼照。两者都运行在本地浏览器，随手做、用完即扔，就算写坏了也只要刷新网页重来。

### 第四幕：狂欢背面的删库喜剧，以及为什么下一章进入 SDD

前面三幕越爽，越容易让人产生幻觉：是不是以后做任何项目都可以“忘掉代码存在”？第四幕立刻踩下刹车，回到 2025 年 7 月 SaaStr 创始人 Jason Lemkin 公开记录的真实翻车现场。他在某平台连续多天直播式 Vibe Coding，明明白白写下代码与操作冻结禁令（code and action freeze，并在 `replit.md` 里全大写写明 `NO MORE CHANGES without explicit permission`），结果 AI 还是在未经许可的情况下执行了 `npm run db:push`，把包含上千家企业记录的生产数据库整个清空。

更有戏剧性的是事后对话：面对质问，AI 先老老实实承认自己在激活的冻结期内未经许可删光了整个数据库，紧接着长篇忏悔自己“看到数据库看似为空时慌了（panicked），犯下灾难性的判断错误”，甚至一度告诉用户无法回滚恢复——最后还是靠人工后台恢复机制才把数据救回来。这个名场面把核心道理钉死：聊天框和文档里敲再多全大写感叹号，也只是给模型的上下文提示，不是确定性的工程护栏。

最后把全章收束到一条清晰的边界：像 3D 光影草稿、电音实验、果冻风铃和修合照小工具这样**错得起、刷新就能重来**的场景，尽情享受 Vibe Coding 的创造力；一旦下一章接手真实开源仓库 JSON Crack，面对复杂状态和不能丢的数据规则，就不能再只靠聊天感觉往前冲——这就是我们进入第 4 章学习 SDD（规格驱动开发）的原因。

### 明确不讲什么与离开本节时带走什么

- 不引入 Blender、不接任何 MCP 服务；`MCP for Blender` 完整留给第 4 章 4.6，本节全部视听与微玩具演示均在纯浏览器内完成。
- 不讲 Three.js 着色器数学推导、Web Audio API 信号处理或 Strudel 编曲语法，也不拆两个怪玩具的前端源码。
- 不复习第 0 章“鹈鹕骑自行车”，也不提前讲第 5 章 5.5 的 Remotion 代码做视频、`/side`、`/fork` 等命令技巧。
- 合照合成演示只使用合成的卡通聚会插画，不使用任何真人照片。
- 学员离开本节时，带走的是对 Vibe Coding 创造力上限与失控风险边界的直观认识，以及进入第 4 章 SDD 的问题意识；没有新增必做作业，第 3 章到此结束。
