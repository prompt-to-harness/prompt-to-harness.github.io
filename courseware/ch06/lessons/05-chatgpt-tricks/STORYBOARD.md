## 本节内容

5.5 已经分享过一组 Codex CLI 里可带走的招数，并预留了语音、`/app`、桌面版等需核验后再补的项。本节不重复那些招数，也不把编码界面再讲一遍。开场问句里的「ChatGPT app」指的是 ChatGPT 应用本身：网页、桌面和手机。课程术语里，可选的编码图形界面应称 Codex App，不要用「ChatGPT App」代指它。

### 一组可以带走的招数

下列技巧供备课和逐节讨论时挑选。15 分钟里未必能全部深讲，确认并核验后再进入正片；缺失项从本节拿掉，不临场改用未证实的替代操作。与 5.5 预留的桌面版、`/app`、语音演示如有重叠，该项不进 6.5 正片。

**把工作放进「项目」。** 文件、指令和对话可以放进同一个项目里，需要隔离时打开「仅项目记忆」，避免和别的聊天串在一起。适合回答「这件事我想单独做完，不要把别的对话习惯带过来」。官方说明：[ChatGPT 中的项目](https://help.openai.com/zh-hans-cn/articles/10169521-projects-in-chatgpt)。

**从一条回复「在新对话中分支」。** 主线还在，分出去的那条用来试另一条路。这正好呼应 6.3 的钻牛角尖：与其在同一条无效路径上连续加指令，不如把尝试放到新对话里，主线不被带跑。只看「原对话还在、新对话可以另试」，不预写分出去之后的回答。

**桌面版的 Chat Bar。** 用 Option+Space（Windows 上的对应快捷键以录制版本为准）打开 [Chat Bar](https://help.openai.com/en/articles/9295241-how-to-launch-the-chat-bar)，可以直接截图提问。只看「不必先打开完整窗口，也能把眼前的画面问出去」。若录制环境没有桌面版或该入口不可用，该项只留官方说明，不改成未证实的替代手势。

**分清 Chat、Work 和 Codex。** 问答用 Chat，长任务和成品用 Work，写代码用 Codex。只有桌面版 Work 才能用本地文件；云端和本机不要选错。官方说明：[ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)。这里的 Codex 是 ChatGPT 应用里的编码入口，讲解时仍要和课程里的 Codex CLI、Codex App 分清，不要混称为「ChatGPT App」。

**定时任务，以及它的一个课堂「坑」。** 可以按时间运行，也可以按 Gmail、Slack、GitHub 等事件运行；但在项目里创建的任务，访问不到该项目里的文件。适合用来讲「看起来已经安排好了，其实它够不到你以为它能用的材料」。官方说明：[ChatGPT 中的定时任务](https://help.openai.com/zh-hans-cn/articles/10291617-scheduled-tasks-in-chatgpt)。

**临时对话。** 默认不进入历史；处于临时状态时，对话不用于改进模型。开始前还可以选择不带个性化。适合演示「这次只想问完就走，不要留下，也不要带进习惯设定」。官方说明：[Temporary Chat](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt)。

**手机里的 Remote 页。** 可以接着看桌面上的 Codex 任务；它和云端任务不是同一条通路。只点到「能接着看」和「不是同一条通路」，不把手机演示做成另一套编码课。未核验则只留说明。
