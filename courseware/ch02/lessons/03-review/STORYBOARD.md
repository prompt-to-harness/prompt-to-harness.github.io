## p40a 风格参考 Prompt（草稿，2026-10-22）

```text
Goal：把工作经历改成时间线样式：左列日期，右列公司、职位和一句话。
Context：参考 <参考主页地址> 的工作经历区块。打不开就按这段描述：
<两三行描述：左列日期窄、颜色浅；右列加粗公司名，下一行职位>
Constraints：只改工作经历区块的结构和样式，不改文字，不加依赖；
先说计划，等我确认再改。
Done when：我在浏览器里看过、觉得像；你跑 build 成功；文字和 profile.md 一致。
```

给地址是为了让 p40b 有真实的一条可讲：Codex 会不会申请联网、取回了什么，按录制时的记录讲。2026-10-22 讲师机器上用 `curl` 实测两个主页：brittanychiang.com 的 HTML 里有经历的文字（服务端渲染），版式在 CSS 里；miaodx.com 的在线简历页 HTML 里没有正文，只有“浏览器未启用 JavaScript”的提示。Codex 取到的是什么，录制时核对。

**参考主页的选择（2026-10-22 调研，录制前定）**：建议 [brittanychiang.com](https://brittanychiang.com/)。它是流传很广的开发者个人主页，Experience 区块正是“左列日期、右列职位与描述”，一处就能学出效果；作者在源码仓库 [bchiang7/v4](https://github.com/bchiang7/v4) 里写明可以 fork，但要注明出处、不能当成自己的作品，正好讲“参考风格，不照搬”。备选：[jonbarron.info](https://jonbarron.info/)，学术个人主页的常见模板，作者在页面上欢迎复用源码，适合想做学术主页的学员。miaodx.com 的在线简历页靠脚本渲染，适合在 p40b 当“取回的 HTML 里没有正文”的对照，不当主参考。截图：2026-10-22 实测 `codex exec -i` 传图，MiniMax-M3.1-Flash 能读出图里的文字和颜色（见章文件实测记录）；交互界面里怎样贴图，录制前核对。
