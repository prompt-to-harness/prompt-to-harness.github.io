## p41 演示方式

讲师在演示分支或临时副本上执行一次 `git revert`，展示新增的撤回提交，再回到正常分支；不在学员主线上演示。`git restore` 与 `git revert --no-edit HEAD` 已在 Git 2.50.1 实测。

## 产出与验收映射

- 跟做：评审结论（接受 / 缩小 / 拒绝及理由）；homepage-v1 提交；能说出本次回退点及回到它的命令。
- 验收沿用大纲：修改目的与影响面可解释；无无关依赖、整页重写或未说明的行为变化。
