## p40a 风格参考 Prompt（2026-10-22 改为点明用 curl，C2-66）

```text
Goal：把工作经历改成参考主页那样的时间线样式。
Context：参考 https://brittanychiang.com/ 的 Experience 区块。
先用 curl 取这个页面的 HTML 和它引用的 CSS（要联网，会弹申请，我来批准），
告诉我这一块的结构和样式是怎样的，再提计划。
Constraints：只学版式，不照搬代码和文字；只改工作经历区块；不加依赖。
Done when：我在浏览器里看过、觉得像；你跑 build 成功；文字和 profile.md 一致。
```

为什么点明 curl：网页搜索在 MiniMax 下由服务端执行，只返回首屏摘要，内容不进请求记录；ChatGPT 登录下的网页工具能取整页，但也只有文字，看不到版式（见[章文件实测记录](../../LOG.md#实测记录)）。curl 取回原始 HTML 和 CSS，2026-10-22 单独实测时第一条的日期、职位和左右两列的 class 都说对了。参考主页要选服务端直接返回内容的页面，靠脚本渲染的页面（如 miaodx.com 的简历页）curl 取不到正文。旧版 Prompt（给地址加描述、打不开就按描述）见 Git 历史。

**参考主页的选择（2026-10-22 调研，录制前定）**：建议 [brittanychiang.com](https://brittanychiang.com/)。它是流传很广的开发者个人主页，Experience 区块正是“左列日期、右列职位与描述”，一处就能学出效果；作者在源码仓库 [bchiang7/v4](https://github.com/bchiang7/v4) 里写明可以 fork，但要注明出处、不能当成自己的作品，正好讲“参考风格，不照搬”。备选：[jonbarron.info](https://jonbarron.info/)，学术个人主页的常见模板，作者在页面上欢迎复用源码，适合想做学术主页的学员。miaodx.com 的在线简历页靠脚本渲染，适合在 p40b 当“取回的 HTML 里没有正文”的对照，不当主参考。截图：2026-10-22 实测 `codex exec -i` 传图，MiniMax-M3.1-Flash 能读出图里的文字和颜色（见 [LOG 实测记录](../../LOG.md#实测记录)）；交互界面里怎样贴图，录制前核对。

## p40 复现按钮：`git revert` 的演示方式

讲师在演示分支上对 homepage-v1 那次提交执行 `git revert <哈希>`，展示新增的撤回提交，再回到正常分支；不在学员主线上演示。开始前工作区必须干净。2026-10-05 在临时仓库按“代码、记录分两次提交”实测通过；2026-10-19 改为一次提交后，录制前在临时仓库重测一次。
