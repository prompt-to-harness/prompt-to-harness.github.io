## p40a 风格参考 Prompt（2026-10-23 改为参考 Hyperspace、放开版式，C2-72）

```text
Goal：参考 Hyperspace 的风格，把我的主页改出新样子：配色和版式都可以改。
Context：参考 https://html5up.net/uploads/demos/hyperspace/ 。先用 curl 取这个页面的 HTML
和它引用的 CSS（要联网，会弹申请，我来批准），告诉我它的风格是怎样的
（配色、各区块怎么铺、版式），再提计划，等我确认再改。
Constraints：页面上的文字不变，每一句都要能在 profile.md 里找到；不加依赖，
不引入远程字体和图片；改结构时尽量沿用现有组件；正文和背景的对比度要够。
Done when：我在浏览器里看过、觉得像；你跑 build 成功；页脚注明风格参考的出处；
告诉我改了哪些区块、为什么。
```

为什么点明 curl：网页搜索在 MiniMax 下由服务端执行，只返回首屏摘要，内容不进请求记录；ChatGPT 登录下的网页工具能取整页，但也只有文字，看不到版式（见 [LOG.md](../../LOG.md) 实测记录）。curl 取回原始 HTML 和 CSS。

为什么放开版式：2026-10-23 实测（LOG.md），只改颜色时参考页靠大块彩色背景营造的效果搬不过来；放开后前后差别明显，文字约束两次都守住了，代价是 diff 大一个量级、每次 5–6 分钟，并可能多出动画、滚动监听这类行为变化，p40c 要专门看。

为什么选 Hyperspace：四个候选（p40a0）里和我们现在的主页差别最大，CSS 是普通写法、容易对照；CC BY 3.0，改完在页脚注明“风格参考 Hyperspace，HTML5 UP”。备选 brittanychiang.com：它会自己换主色、不照搬，适合讲“参考不等于照搬”。Done when 里的“页脚注明风格参考的出处”是 2026-10-23 加的：排练里不写这一条时，它只在页脚放了姓名，没写出处，而 Hyperspace 是 CC BY 3.0，要求署名。旧版 Prompt（只改工作经历一处、参考 brittanychiang.com）见 Git 历史。

## p40 复现按钮：`git revert` 的演示方式

讲师在演示分支上对 homepage-v1 那次提交执行 `git revert <哈希>`，展示新增的撤回提交，再回到正常分支；不在学员主线上演示。开始前工作区必须干净。2026-10-05 在临时仓库按“代码、记录分两次提交”实测通过；2026-10-19 改为一次提交后，录制前在临时仓库重测一次。
