## p29 本轮 Prompt

```text
Goal：把 profile.md 里的个人信息放进个人主页。
Context：profile.md 在项目根目录，是我写的，分四块；
页面现在只有首屏和占位的项目区；项目卡不跳转，本轮不改。
Constraints：只用 profile.md 里的文字，不补写；
不加链接、依赖；先说计划，等我确认再改。
Done when：我在浏览器里看过页面正常；你跑 build 成功；
页面上的每一句都能在 profile.md 里找到。
```

## 内容已完整时的跟做分支

学员的主页已经有完整的个人信息时，由人确认一条值得补充的事实，写进 `profile.md`，Goal 改为呈现这条新增内容。没有实际补充需求时，在独立练习副本使用课程合成示例：原文“学习笔记：记录课程练习”，补充为“学习笔记：整理三次课程练习的目标、页面截图和修改记录”。这些是虚构练习内容，不当作学员真实经历发布。
