## 实测记录（2026-10-21，各一次运行，原始记录在讲师本机，不提交）

- **经验一**：价格取自 MiniMax 开放平台定价页 `platform.minimax.cn/docs/guides/pricing`（2026-10-21 查阅）：MiniMax-M3.1-Flash 输入 1.00 元、输出 4.00 元、缓存读取 0.10 元，单位元/百万 token；页面没有列缓存写入价格。示例数字来自 2.1 第二步那一问的重跑（8 次请求，claude-tap 汇总 126,466 输入 / 110,501 缓存读取 / 6,995 输出）。按“输入 token 含缓存命中部分”估算，计费口径录制前再核一次。
- **经验二**：起点是 2026-10-20 那次 2.2 改完后的仓库，`codex exec -s read-only` 发“交接 + 继续：360 宽下会不会难看地换行”。11 次请求、约 21 万输入 token（没有浏览器，它写脚本估算字宽）；第 1 次请求 6 项。运行目录 `~/.cache/p2h-lab/2.5-handoff-20261021-151326`。
- **经验三**：同一句问候，`clean-claude.sh --tap -- -p` 与 `clean-codex.sh --tap -- exec`，目录放在课程仓库之外（`~/.cache/p2h-lab/2.5-compare-20261021-150951`）；Claude Code 2.1.304。第一次把目录放在 `lab-runs/` 下，Claude Code 读进了课程仓库根目录的 `AGENTS.md`（请求里写着 “Contents of …/AGENTS.md”），所以对比必须在仓库外做，这一点本身可以讲。
- **隐私**：从另一个 Claude Code 会话里跑脚本时，会继承 `CLAUDE_CODE_USER_EMAIL` 等变量，Claude Code 把邮箱写进了请求。两个 `clean-*.sh` 已在开头清掉继承的 `CLAUDE_CODE_*`（2026-10-21）；录制用讲师自己的终端，截图前仍要检查请求里有没有个人信息。

## 待核实

- **经验一**：录制当天再查一次价格页；缓存命中是否另算、Codex 界面能否直接看到 token 用量，录制前核对。

- **经验三**：Claude Code 读取上级目录 `AGENTS.md` / `CLAUDE.md` 的规则，按录制版本的官方文档核对；数字随版本变化，画面标“一次运行”。
