## 两份教学 diff 的要求

| | A：保持行为 | B：顺带改变行为 |
| --- | --- | --- |
| 结构变化 | 项目卡提取为独立组件 | 同 A |
| 可观察行为 | 与 homepage-v1 一致 | 卡片可点击、可聚焦，有焦点样式 |
| 基于 | 讲师冻结的 homepage-v1 | 同 A |

两份 diff 标注“教学材料”，基于讲师冻结版本，不要求学员在自己项目上复现。

## 产出与验收映射
