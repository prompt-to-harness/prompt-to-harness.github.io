## 待核实

- **经验一**：MiniMax-M3.1-Flash 的输入、缓存命中和输出价格，以录制时的官方价格页为准；缓存命中怎样计费、Codex 界面能否直接看到 token 用量，录制前核对。2.2 的请求记录要按 C2-38 重录，p60 的数字跟着重录结果更新。
- **经验二**：用一段手写交接开新会话，第一次请求里是否原样出现、Codex 会不会据此重新读文件，要实跑一次；不预设它一定照做。
- **经验三**：`tools/clean-claude.sh --tap` 在课程基线（MiniMax Anthropic 兼容接口）下能否被 claude-tap 记录、同一句问候的请求长什么样，要实跑；Claude Code 读 `CLAUDE.md` 的写法按录制版本的官方文档核对。
- 三条候选取自[经验分享候选池](../../../../docs/outline/proposals/2026-10-20-experience-sharing-pool.md)第 2 章一组（token 与缓存可视化、不同 coding agent 的请求对比），交接一条是本章 2.2 的延伸；讲哪三条、谁来讲，由第 2 章最后一节的讲师定。
- 讲师切换的衔接写法（小窗、开场一句）还没有写进 `docs/production/`，见[经验分享提案](../../../../docs/outline/proposals/2026-10-20-last-section-experience-sharing.md)第二节。

- 看懂即可：能说出长会话为什么一轮比一轮贵、什么时候该 `/clear` 或开新会话加交接；知道换一个工具，模型看到的 context 也会不同。不设练习、自检题，不计入第 2 章退出门禁。
