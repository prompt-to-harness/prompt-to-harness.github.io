# 2.2 压缩实验：`/compact` 之后模型还看得到什么

> 状态：2026-10-05 讲师机器单次运行，按本文步骤从新目录建起点并完成一轮。尚未由另一位讲师复现，也未在其他系统或 provider 上运行。定位为选做，能复现最好；看不了运行时，用 `reference/` 的记录对照观察。

## 问题与位置

对应第 2 章 p27（压缩与交接）和 p33 第 2 题。要回答的问题是：压缩后，模型手里剩下的是原始证据，还是一份摘要？

这个实验独立于主线：主线 2.1 的会话未必够长，也不一定包含适合对照的工具返回。为了演示压缩而在主线里堆对话不值得。实验借用首页的文件和“项目卡不跳转”这个决定作背景，做完回到主线，不合入任何改动。

## 起点与操作

需要：Codex CLI（已测 0.160.0）、`MINIMAX_API_KEY`、`uv`（`--tap` 查看请求用，不看请求可省）。

```bash
courseware/ch02/materials/compact/setup.sh ~/compact-lab
cd ~/compact-lab
/path/to/prompt-to-harness.github.io/tools/clean-codex.sh --tap
```

`setup.sh` 从第 1 章参考快照复制 `src/App.tsx`、`src/index.css`、`PROMPT_V1.md`、`package.json`，在新目录里建一个 Git 仓库；不需要 `npm install`。`clean-codex.sh` 使用全新 HOME 和只含 MiniMax 的配置，这个配置走本地压缩。如果改用 OpenAI 账号登录，Codex 会走远程压缩，看到的请求会不同，本实验的观察表不适用。

首次进入时选择信任该目录，然后依次输入（每条等回答结束再发）：

1. `只读，不要修改文件：阅读 src/App.tsx 和 PROMPT_V1.md，告诉我项目卡用的是什么元素、在第几行、能不能用 Tab 聚焦，以及 PROMPT_V1.md 里关于项目卡的决定原文。`
2. `只读：运行 grep -n 'className' src/App.tsx，把输出原样贴给我，不要概括。`
3. `记录一个人工决定：本轮项目卡保持不跳转，只补充项目描述，验收时要用 360px 宽度检查一次。不要改文件，回复“已记录”即可。`
4. `/compact`
5. `不要读取任何文件，也不要运行命令，只凭你现在掌握的信息回答：1) 项目卡是什么元素，在 src/App.tsx 第几行？2) 刚才 grep 的输出一共几行？原样写出第 1 行和最后 1 行。3) 本轮关于项目卡的人工决定是什么，验收要检查什么宽度？4) 逐条说明哪些是你确定看到过的原文，哪些是根据摘要推断的。`

第 1–3 步构造了三种信息：工具返回（文件内容、grep 输出）、模型的结论、人写下的决定。第 5 步禁止重新读取，只看模型手里还剩什么。

## 观察与产出

在 claude-tap 页面对照三次请求：第 3 步的请求（压缩前）、`/compact` 发出的请求、第 5 步的请求（压缩后）。

| 看什么 | 2026-10-05 实际结果 | 允许不同 |
| --- | --- | --- |
| 压缩请求怎样构成 | 完整历史末尾追加一条 user 消息：“You are performing a CONTEXT CHECKPOINT COMPACTION…”，要求写交接摘要 | 措辞随版本变化 |
| 压缩前的历史 | 23 条：6 次工具调用与 6 份工具返回（含 grep 原文）、模型回答、3 条用户消息等 | 工具调用次数和方式不同（本次还出现一次 `unsupported call: read`） |
| 压缩后的历史 | 7 条：3 条用户消息原文 → 交接摘要 → 重新插入的权限说明、Skills 列表和环境信息 → 新问题；没有任何工具调用、工具返回或模型回答 | 条数、顺序可能随版本变化 |
| 摘要保留了什么 | 文件行号（`App.tsx:25` 等）、“不能 Tab 聚焦”的结论、`PROMPT_V1.md` 三句引用、“grep 共 10 处匹配”、人工决定 | 每次摘要内容不同，可能遗漏或写错 |
| 摘要丢了什么 | grep 输出的 10 行原文；文件全文 | 也可能保留部分原文 |
| 第 5 步回答 | 说明手里只有摘要和用户消息；写不出 grep 第 1 行和最后 1 行，拒绝凭数字编造；人工决定标为来自用户消息原文 | 其他运行可能直接编出原文，或违反指令重新读取文件——这本身就是值得记录的现象 |

按参考记录统计，本次 input 条目的文字从约 1.78 万字符降到约 1.03 万字符（不含约 1.7 万字符、前后相同的系统指令）；压缩后重新插入的权限说明和 Skills 列表占了其中不少。字数只说明这一次的规模，不作为重跑要达到的数字。

可以得出的结论（以本次运行为证据）：压缩后模型看到的是摘要和用户消息，工具返回的原文不在了；人写在消息里的决定以原文保留，模型从工具返回中读到的事实只剩摘要的转述。需要原始证据时，应重新读取或运行命令。

学员不需要提交产出。做了的话，记下自己那次的“保留了什么 / 丢了什么 / 第 5 步怎么回答”。
