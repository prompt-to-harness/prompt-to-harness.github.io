# JSON 对比功能需求（草稿）

> 课程合成材料：人物与团队均为虚构。

**提出人**：数据接口组 · 小林
**日期**：2026 年 11 月

## 背景

我们组平时要对比接口改动前后的返回结果，还有配置文件改动前后的内容。现在用 JSON Crack 看结构挺方便，但两份 JSON 只能来回切换着看，很容易漏掉改动。

## 希望做到

1. 在 JSON Crack 里同时放两份 JSON（改之前、改之后），对比之后把不同的地方高亮出来。
2. 数组也要支持。我们的数据里列表很多，比如商品列表、用户列表。
3. 最好能只看变化的部分。大文件里没变的内容太多了，找起来很累。
4. 删掉的字段也要能看出来，不能只显示改之后的样子。
5. 有时候后端把数字改成了字符串，比如 `1` 变成 `"1"`，这种我们也想知道。
6. 数据里可能有内部配置，最好不要上传到别的地方。
7. 文件可能比较大，几千行的那种。
8. 以后 VS Code 插件里也能用就更好了，这次先做网页版。

## 还没想清楚的

- 后端返回的字段顺序有时会变，这算不算改动，组里意见不太一致。
- 列表中间插入一条之后，后面的元素怎么对上，我们也说不好。

## 怎样算做好了

能一眼看出改了哪里，联调的时候少来回翻几次。

开发同学看完可以直接动手做，有问题再说。
