# 4.6「开发者分享会」教学材料（课程合成）

本目录是 4.6 飞书演示用的本地原文。活动、人物与数据均为虚构，人数不是实测报名。本目录不发布到站点。公开仓库只保存这些合成文本，不提交需登录的演示链接、令牌或个人资料。

经讲师核对后，再在讲师指定的课程演示知识库里建立隔离文档。不要覆盖 4.2 的需求笔记，也不要提前创建「评审结论与待办草稿」（那一份在演示时现场创建）。

## 文件

| 本地文件 | 在飞书里建成什么 | 演示用途 |
| --- | --- | --- |
| [活动方案.md](活动方案.md) | 云文档，标题用一级标题；文中「报名意向」建成文档内普通表格，不要建成电子表格 | 搜索、读正文、来源核对；表中 40、25、15 供 AntV 作图，合计 80 |
| [评审补充.md](评审补充.md) | 另一份云文档，标题用一级标题 | 跨文档整理；建议不要写成已通过的决定 |
| [教学评论.md](教学评论.md) | 不是单独文档，把两条评论加到活动方案上 | 评论读取与归类；抽查「答疑时间需要明确」 |
| [分场次报名统计.csv](分场次报名统计.csv) | 单独的电子表格，工作表可命名为「报名统计」 | 电子表格短演示：核对某一场人数，或改一个格子。不要用方案里的普通表格代替 |
| [主题与跟进.csv](主题与跟进.csv) | 单独的多维表格，字段为「主题」「场次」「跟进状态」 | 多维表格短演示：按条件查询，或新增、更新一条 |

## 上传到知识库

用与演示同一套飞书账号，在已经建好的课程演示知识库里操作。4.6 飞书演示改用官方命令行工具、以本人身份登录；配置时默认会新建应用，知识库权限按当时实际要求开通。

1. 在知识库中新建文档，标题定为「开发者分享会 · 活动方案」。把 `活动方案.md` 的正文贴进去（标题不要重复贴两次）。「报名意向」用文档里的插入表格做成普通表格，填入四个主题行（含合计），不要新建电子表格。
2. 再新建一份文档，标题定为「开发者分享会 · 评审补充」，贴入 `评审补充.md` 的正文。
3. 打开活动方案，按 `教学评论.md` 的位置和原文，用演示账号添加两条评论。不要编造其他评论者。
4. 在知识库中新建电子表格，标题定为「开发者分享会 · 分场次报名统计」。按 `分场次报名统计.csv` 建好工作表，保留「场次」「主题」「已报名」「名额」四列和三行数据。也可以先建空表再导入该 csv。
5. 在知识库中新建多维表格，标题定为「开发者分享会 · 主题与跟进」。建立「主题」「场次」「跟进状态」三个字段，写入 csv 里的三条记录。跟进状态建议做成可筛选的选项：提纲已收、待确认分享人、场地已定。
6. 不要在此时创建「评审结论与待办草稿」。建好后，打开实际文档、表格和评论，核对标题、正文、数字和两条评论原文。

抽查时用得上的固定原文：方案里「答疑时长待确认」；评论「答疑时间需要明确」。答疑时长、会后是否公开作品，都还只是待确认或建议，不要改写成已经通过的决定。
