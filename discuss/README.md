## 使用约定

- 结论写到 `docs/` 下的基线文档；本目录保留早期决策缘由，不再作为规范维护。
- 引用讨论时标明“讨论中的表述”，不要写成已对外承诺。
- 2026-09-03 的会议原始转写含合作平台、远程环境与未决产品讨论，保存在私有仓库，未公开。
