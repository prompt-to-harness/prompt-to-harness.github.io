## 只读对照步骤

1. 不在第 1 节原目录继续操作，使用同一基线的独立副本。
2. 在 App 中记录当前项目根目录和权限设置。
3. 在 CLI 中执行路径、状态、起点和版本检查。
4. 只读查看 README 的「项目介绍」，不修改文件、不安装依赖、不启动服务、不访问外部网络。
5. 比较 App 与 CLI 的目录、文件内容和状态结果。
6. 保存命令原文、真实输出和任何权限请求。

## 停止条件

- CLI 打开的目录与 App 不一致；
- 工作区已有无法解释的改动；
- 工具要求超出只读任务的权限；
- 需要安装依赖、启动服务或访问外部网络才能继续；
- 版本、登录状态或权限行为无法核对。

遇到停止条件时保留现场，转到脱敏回放或环境排障；不通过修改源码、换用其他智能体或扩大权限来伪装通过。

## 验收卡

- [ ] App 与 CLI 使用同一项目基线
- [ ] CLI 只读检查留下了真实命令和结果
- [ ] 能解释入口选择与权限选择的区别
- [ ] 能识别安装依赖带来的额外副作用
- [ ] 没有演示危险的全权限或 bypass 配置
- [ ] CLI 不可用时有明确的回放与补做路径
