# 1.3 录制说明与首版材料清单

## 交付定位

- 类型：知识＋操作
- 净视频预算：约 12 分钟，其中 CLI 对照约 2–3 分钟
- 主媒介：HTML 对照＋App 回放＋CLI 只读检查
- 不演示危险的全权限或 bypass 配置

## 画面顺序

| ID | 画面 | 来源标记 | 录制要求 |
| --- | --- | --- | --- |
| 01 | App 记录与入口标签 | 第 1 节真实记录 | 说明入口变化不改变验收 |
| 02 | App/CLI 选择对照 | 教学图解 | 讲证据需要，不宣布某入口普遍更好 |
| 03 | CLI 路径、状态、起点、版本 | 真实试跑 | 与第 1 节使用同一基线 |
| 04 | CLI 只读请求与结果 | 真实试跑 | 不修改、不安装、不启动、不访问外网 |
| 05 | Sandbox/Approval 对照 | 官方定义＋教学图解 | 分开解释执行边界与批准时机 |
| 06 | Prompt 约束与 diff | 示例或真实记录 | 说明文字约束不是技术隔离 |
| 07 | 安装依赖自检题 | 教学题 | 留暂停、解析和补做入口 |
| 08 | 失败路径与 1.4 转场 | 教学图解 | 明确回放不计作 CLI 操作通过 |

## 必须准备

- 第 1 节同一练习副本的路径、分支、起点 commit 和状态记录；
- 实际 `codex --version` 输出及 CLI 入口；
- 实际权限/审批设置和只读请求结果；
- 录制日期、Codex CLI/App 版本、登录方式和必要网络说明；
- 只读任务出现额外权限请求时的脱敏画面或文字记录。

## 验收卡

- [ ] App 与 CLI 指向同一项目基线
- [ ] 只读检查留下了路径、状态、原文和版本证据
- [ ] Sandbox 与 Approval 的解释没有混为“一个权限开关”
- [ ] 没有演示危险的全权限或 bypass 配置
- [ ] 自检题解释安装依赖的写入、网络和脚本副作用
- [ ] CLI 不可用、目录不一致或权限超范围时有继续路径
