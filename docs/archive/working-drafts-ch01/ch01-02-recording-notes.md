# 1.2 录制说明与首版材料清单

## 交付定位

- 类型：机制解释
- 净视频预算：约 10 分钟，暂停和课后补做另计
- 主媒介：HTML 图解＋第 1 节真实记录回放
- 不启动新项目，不在本节修改代码

## 画面顺序

| ID | 画面 | 来源标记 | 录制要求 |
| --- | --- | --- | --- |
| 01 | 第 1 节 Prompt、读取、diff、status | 真实记录或脱敏回放 | 四处证据必须来自同一条因果链 |
| 02 | 执行循环图 | 教学图解 | 箭头标明人、Agent、Tool、Context 的责任 |
| 03 | Agent 三步拆解 | 真实记录 | 不把完成说明当验收结论 |
| 04 | Context 四格卡片 | 教学图解＋文件证据 | 单列尚未取得的信息 |
| 05 | Tool 与结果对照 | 命令/返回结果 | 工具动作和返回文本分列 |
| 06 | Context Window 对照 | 教学图解 | 不宣称固定容量或具体内部机制 |
| 07 | 自检题 | 教学题 | 留出暂停和解析 |
| 08 | 失败卡片与 1.3 转场 | 教学图解 | 指向入口与权限边界 |

## 必须准备

- 第 1 节脱敏 Prompt、原文、回复、diff 和状态记录；
- 一张可读的执行循环图；
- 一张输入/请求/工具动作/工具结果分类图；
- 自检题的题面、解析和常见误解；
- 若使用教学示例，画面上标明“示例”，不说成真实运行结果。

## 验收卡

- [ ] 能从回放中指出一次 Tool 动作和对应结果
- [ ] 能区分 Context 与 Context Window
- [ ] 能解释为什么 Agent 的完成说明不等于验收
- [ ] 能说出三种失败方式
- [ ] 1.3 的入口与权限问题已在结尾明确出现
