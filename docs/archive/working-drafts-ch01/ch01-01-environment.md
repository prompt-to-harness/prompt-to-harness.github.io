## 试录准备

1. 选定课程 fork 与起点提交后，将实际克隆命令和版本填入[学员准备页](../../../courseware/ch01/preparation.html#starter)，替换占位值及未发布提示。只提供源码 ZIP 时须另补已验证的 Git 初始化路径。
2. 按学员准备页从新目录走一遍：克隆、建立分支、核对目录和干净状态、记录起点提交、App 读取及修改 README、检查 diff。
3. 讲师另行验证后续网站任务所需的 Node、包管理器、依赖安装与启动结果，填写上表。学员第一节的 README 练习不以完成网站启动为前提；第五节操作前再完成这些准备。
4. 录制并保存实际 App 入口、权限设置、请求、回复和差异。把操作系统、版本与核验日期写入公开准备页，只列已经试跑的组合。

核心路径的起点应满足：`git status --short` 没有输出，并已记录 `git rev-parse HEAD` 的完整结果。若已有修改，不执行 `git restore`、`git reset` 或删除文件来清理；保留原目录，重新准备一份干净副本。

学员的失败处理、恢复与继续条件统一维护在[准备页](../../../courseware/ch01/preparation.html#help)，试录发现的实际阻断在该页补充。
