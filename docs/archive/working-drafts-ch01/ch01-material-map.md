## 制作决定

第一章仍按六节连续推进，但每节独立交付材料包。统一主线是：

```text
第一次小改动 → 回看执行循环 → 选择入口与权限 → 写清任务 → 受控生成首页 → 判断最小权限
```

第一节已经验证了“问题 → HTML 解释 → App 实操 → HTML 复盘”的基本形式。1.2 和 1.3 已验证机制解释、知识与操作两种讲法；1.4–1.6 已按同一材料包完成首版，1.5 的真实环境和生成结果仍待试跑。

## 每节固定材料包

每个小节进入录制前必须具备以下内容：

1. **目标与边界**：学习目标、输入、产出、非目标、讲解边界。
2. **讲述材料**：HTML 讲义或展示页、逐字稿、术语和命令清单。
3. **操作材料**：起点、Prompt/命令、检查点、参考结果、失败与继续路径。
4. **学习材料**：一个核心自检题、完整解析、常见误解、补做入口。
5. **录制材料**：镜头顺序、必须保留的证据、可剪掉的等待、take 命名约定。
6. **验证记录**：环境版本、实际运行结果、非作者走查结果和未决项。

页面、逐字稿、准备页和录制说明必须同步；真实 Agent 输出、示意内容、脚本重放和人工植入故障要明确标注。

## 进入正式录制的门禁

### 内容门禁

- 本节能用一句话说明“学完会什么”。
- 每个主要讲述点都有可见证据或明确的示例来源。
- 自检题给出判断、依据、常见误解、补救入口和继续条件。
- 本节不会把未决的实现选择讲成已批准规则。

### 操作门禁

- 有可启动的起点和明确检查点。
- Prompt、命令和权限范围已经过人工核对。
- 实际结果、diff、日志或权限画面已保存。
- 失败时保留现场，并有不覆盖学员工作的继续路径。

### 录制门禁

- 逐字稿能对应画面；删去等待不会改变因果关系。
- 非作者能只靠材料找到当前位置、验收结果和下一步。
- 画面中的版本、路径、命令和权限与准备页一致。
- 未通过项标为待实测，不能在旁白中使用“已经验证”的语气。
