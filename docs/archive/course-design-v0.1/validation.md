## 链接检查的已知边界

- **全仓相对链接不等于已全部解析。** `refs/EVIDENCE.md` 等处指向 `refs/geektime/trychen/materials/` 下的路径时，依赖 git submodule；未执行 `git submodule update --init --recursive` 时目录为空，属预期失败，不是文档写错。
- `refs/zhanghe/` 部分讲义引用 `../assets/...` 图片，资产未入库；按内部参考材料处理，不据此宣称外链完整。
- 少量 Markdown 模式（如 `mailto:`、被加粗包围的标识符）可能被朴素链接扫描误报，应人工排除。

## 人工复核方法

从 [逐课总表](course-map.md) 按每课四行相加，检查是否为 90 分钟；对照 [内容地图](content-map.md) 确认深挖没有额外叠加；对照交付计划的裁剪表计算 720 分钟；逐课确认自检不仅有结论，也有理由和继续路径。沿 [总设计入口](README.md) 检查所有导航与 Project 阶段关系。

当前仓库内**没有**可重复执行的结构校验脚本。修改课时、字段或链接后，应按上表方法重新人工核对；若后续增加 `scripts/validate-design.py` 一类工具，在此登记入口与覆盖范围。
