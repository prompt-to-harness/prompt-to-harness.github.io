# 制作、录播支持与验证计划

> 工作流程提案；角色是责任职能，尚未给任何人指派任务。服务、成本、支持环境和最终评分须另行确认，不依据此文自动形成对外承诺。

## 1. 单课制作合同

每课从主问题和可观察学习结果开始，制作四小节提纲、讲师备注、素材定位、演示操作单、学生讲义、自检题及解析、实践起点/检查点/验收、故障与继续入口。实际制作文件名可再定，先保证职责齐全。

PPT 展示图解、对照、局部证据；代码/日志全屏突出相关位置，不长期四分屏挤满信息。讲稿说明为何此时看这些东西。字幕、可读字体、非仅靠颜色传达的状态，以及文本替代是基础；小字终端截图不能代替可读代码。时间戳先用小节 ID，剪辑后再填写真实播放位置，不把预算当成精确时间戳。

真实 Agent 运行、剪辑、脚本重放和人工故障都要标识。保存版本、起点、配置、命令/输入、工具结果、diff 与实际检查。等待可剪掉但注明原始耗时与省略；不为演示“某方法必胜”挑选结果却不说明。公开指令不是完整隐藏系统消息，日志不是模型全部内部思维。

## 2. 录播自检模板

```text
题目 ID / 对应能力：
给定场景与可见证据：
请学员判断什么、用什么解释：
参考结论及足够的依据：
常见答案 A：缺什么；怎样补：
常见答案 B：哪里合理；仍需注意什么：
回看/补做入口（小节 ID + 材料）：
继续条件：
本题不能证明的能力：
```

每个核心小节优先一个判断点；不是所有提问都要求暂停。视频直接进入明确标注的解析，不模拟收到现场回应。学生第一次可观察，再独立重做。新手配提示/半成品，熟手增加变化，共同质量标准相同。

四种状态均有下一步：环境失败→诊断/观看路径；不同实现→验收对照；行为失败→具体条件与检查点；未知阻断→最小复现与求助。观看和固定记录诊断不记作已完成操作，能力状态分别标注。

## 3. 交付证据卡与自评标准

```text
任务/起点版本/环境：
目标、范围、非目标和验收：
采用的代码/资料依据与未知项：
Agent 做了什么；人确认了什么：
变更位置与结果：
实际检查及证据位置：
失败、修正、剩余风险和未验证项：
换到新任务需保留或调整什么：
```

| 维度 | 需要补做 | 可以认为达到本次任务要求 | 可选增强 |
| --- | --- | --- | --- |
| 需求与范围 | 仅说做了一个应用 | 目标、保留行为和非目标明确 | 能解释一处变化的取舍 |
| 上下文 | 地图/结论没有依据 | 关键判断可指回事实，未知项单列 | 找到另一条反例路径 |
| 实现与边界 | 不可运行或无关改动/敏感数据 | 目标行为可运行，范围与权限受控 | 改善维护性且有依据 |
| 验证 | 只有 Agent 的完成说明 | 有相关测试/运行/diff，说明覆盖与遗漏 | 识别并补上一项错误验收 |
| 解释与迁移 | 只能复述步骤 | 能解释决定，并在变化任务中调整 | 比较两种合格方法代价 |

不采用自动模型分数作为唯一评价，不规定暂未协商的正式及格分。不同实现可合格；真实部署还需额外检查。E01–E10 可以是一组短记录，不要求十篇长报告或完整聊天导出。是否收作业、人工评阅、发证另定。

## 4. 环境支持与演示验收

录制时记录：OS、运行时、Agent/模型版本与接入方式、仓库起点、必要网络、权限、费用提示、测试入口。以真实试跑确定最低版本，本文不虚构已经支持的配置。

| 支持层 | 本版安排 | 发布前必须确认 |
| --- | --- | --- |
| 主演示 | Codex CLI 的可复现路径；App 低门槛入口 | 实际安装、登录、读/改/运行/失败反馈、权限行为 |
| 系统差异 | Mac 与 Windows 的说明分开 | 路径、shell、编码、启动、测试与恢复 |
| 模型替代 | 选定可行国内/替代模型工具组合 | 协议/工具调用/编辑/上下文/成本实际可用，不仅测试连接成功 |
| 网络受限 | 下载包、固定数据、必要依赖说明/可行镜像 | 离线可做什么；模型仍需访问时明确说明 |
| 无模型观看 | 脱敏执行回放、固定产物和判断题 | 不当成完成 Agent 操作的替代证明 |

不默认统一远程环境、模型补贴、全部系统/模型兼容。下载镜像或依赖再分发先检查许可和来源。外部 MCP/工具各自核对权限，不宣称一个本地沙箱覆盖一切。

## 5. 制作阶段与放行条件

| 阶段 | 责任角色（待指定） | 产出 | 放行/停止条件 |
| --- | --- | --- | --- |
| G0 总设计审阅 | 课程负责人 | 课序、深度、项目角色、未决清单 | 核心能力有教学与检验位置；不靠群补齐 |
| G1 项目与环境试跑 | 项目作者 + 非作者复核 | 阶段包、检查、错误与恢复记录 | 有可独立启动路径；未通过的组合不列支持 |
| G2 三类样课校准 | 讲师 + 编辑 + 内容复核 | L02 机制、L03 方法、L06 诊断的局部样稿 | 图解与证据相连，解析足够、不过载；不等真实招生反馈 |
| G3 批量制作 | 讲师/项目/编辑并行 | PPT、录屏、讲义、自检、实践包 | 内容事实核验与版权状态清楚 |
| G4 发布前走查 | 非作者 QA + 发布负责人 | 清单、运行证据、勘误入口 | 无危险指引、事实错误与核心学习阻断；材料可找到 |
| G5 发布与维护 | 维护/答疑角色 | 版本说明、FAQ、局部补录 | 按风险处理反馈，不承诺即时响应 |

G2 不等于真实用户验证。已有 L02 对话样课是参考包；本次不上传大体积 PPT/ZIP，不沿用其未重新检查的测试计数，也不将重放当实录。四张软件工程试讲卡保留，不重做成新的必修线。

建议项目试跑、讲述整理、事实核对并行，但必须在起点和验收稳定后录制相关正式过程。账号/成本/平台条件会阻断相应演示或对外承诺，不阻断继续完善总设计。

## 6. 内部检查与发布后观察

内部可检查：逐课课时与字段完整；非作者能启动与恢复；自检有结论/依据/误区/补救；关键图能对应记录；资料来源可核；核心任务通过已定义验收。这些通过不是“学员一定会学会”。

发布后可观察：在哪一课/小节反复出现误解；首次运行的阻断类别；自检前后是否补出正确证据；迁移任务是否需要额外提示；每项问题是否已有可找到的说明。记录样本、环境、跳过/退出与未回复，不虚构完成率目标，也不把视频播放完作为能力达成。

群提问模板：课次/时间点、目标、起点/环境、实际现象、已尝试动作、最小证据（先脱敏）。更新优先级：安全/事实错误立即影响发布放行；核心阻断优先修；解释与体验按版本补充。历史版本和勘误要可追踪。

## 7. 8 课压缩版本：明确少讲什么

保留 L01–L06 的六次 90 分钟。将 L07+L08 合并为 K07（90），L09+L10 合并为 K08（90），总计 720 分钟。少掉的 180 分钟来自删重复、精简供应商操作和减少拓展，不能把必需操作藏到强制“加餐”。

| 原小节 | 原分钟 | 压缩保留 | 取舍 |
| --- | --- | --- | --- |
| 07.1 / 07.2 / 07.3 / 07.4 | 20/25/30/15 | 10/15/15/10 | 留复用原则、一个例子和解析，删多种包装对照 |
| 08.1 / 08.2 / 08.3 / 08.4 | 20/25/30/15 | 10/15/10/5 | 留工具契约/权限/失败，删多平台接入；真实 MCP 不强制 |
| 09.1 / 09.2 / 09.3 / 09.4 | 15/20/40/15 | 10/10/15/5 | Harness 保留最小组合，删长过程重复展示 |
| 10.1 / 10.2 / 10.3 / 10.4 | 10/15/50/15 | 5/5/30/10 | 保留陌生任务和证据，减少历史拓展与重复解说 |

K07 四小节为 20/30/25/15；K08 为 15/15/45/15。两课仍有题、解析、演示与迁移。若内部试讲显示核心操作被挤掉，就保留 10 课，不以语速解决。课数选定后才重编号，当前主表仍以 L01–L10 为唯一工作基准。
