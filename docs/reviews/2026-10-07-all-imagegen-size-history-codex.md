## 导出与 Probe

原有 25 图导出合计 2,685,423 字节，比原 PNG 减少 95.15%。角色设定仍保留最长边 1280，以容纳三只猫和表情；三格条带保留 1920，即单格 640；这是独立试验的保存选择，不是正式视觉规范变更。加入一次新 Probe 与一个 1024 尺寸对照导出后，27 项素材合计 2,860,043 字节。

同一反馈图对照：1024×682 JPEG 为 141,356 字节，640×426 JPEG 为 68,452 字节。只做 sips 导出，没有生成两张不同场景。原尺寸 PNG 已逐文件校验后留在 Git 忽略目录，缩小导出、照片、完整 Prompt 与清单进入 Git。

原生分辨率 Probe 使用内置 image_gen，一只蓝猫、一张已确认卡通参考、短 Prompt，明确请求 exactly 640 x 480 和低细节快速草稿。实际返回 1448×1086 PNG，调用耗时 16.829 秒；工具没有返回模型、quality 或 Token 用量。没有调用独立 API，也没有添加工具接口不存在的 size 参数。结果仅说明本次遵循 4:3 比例，没有遵循原生像素尺寸；不与此前多角色复杂场景量化比较耗时。Probe 导出为 640×480 JPEG，33,264 字节。

官方 API 的 size、quality、output_format 是显式参数，当前内置工具没有开放这些字段。当前官方自定义尺寸指南要求最少 655,360 像素，640×480 为 307,200，不满足该指南的范围。指南建议 low 质量草稿，说明直接 JPEG 输出更快；不能把 API 参数写进自然语言就假定工具已应用。来源：[Image generation](https://developers.openai.com/api/docs/guides/image-generation)、[Generate image reference](https://developers.openai.com/api/reference/resources/images/methods/generate)，查阅于 2026-10-07。
