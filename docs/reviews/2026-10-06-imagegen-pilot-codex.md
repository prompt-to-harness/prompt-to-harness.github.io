## 已验证

- 使用 ego-browser 检查两页的实际渲染与截图；桌面实测浏览器视口为 1422×800，画布按原播放器规则缩放，正文底边按画布坐标核算。
- p20 两张图均加载成功；p03 三格人物、表情与台词均可见。p03 正文底边约 y612。
- 初始步骤的隐藏内容带 `inert` 和 `aria-hidden=true`；两页均可用方向键推进至下一步。
- 对照入口可切换现版与生图版：用实际 `.p-comic` / `.pilot-comic` 元素分别确认；逐步预览的“下一步”使 URL 从 step=0 进入 step=1。
- 两页均在 390px 阅读模式复核：页面 scrollWidth=390，没有整页横向溢出；漫画纵向排列。
- JavaScript 语法检查通过；`make check` 通过：34 HTML、141 scenes、1177 local references 无错误；第 1 章逐步检查通过；12 个正式课件页面展示检查无错误；22 个外部链接静态检查无错误。编辑检查为 0 errors、1 hint（既有 2.1 讲稿的“其实”）。
- `make check` 扫描正式课件；新增试验目录由上述浏览器检查单独覆盖，不能把正式课件检查当作试验逐页自动检查。

## 给后续制作

先比较漫画是否比文字头像更有讲述价值。主页对照需同时比较“审美差异更清楚”和“功能范围例证减少”的取舍。不要直接将完整生成图片替换整个页面；继续保持中文台词、编号和揭示步骤可编辑。
