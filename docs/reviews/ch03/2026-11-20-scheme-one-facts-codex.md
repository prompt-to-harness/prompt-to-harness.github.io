## 已核对的成立事实

- 原游戏画布占四列网格第一列，约99×74；修改后的游戏使用 .stage，实测760×475。
- 修改副本涉及正文、参考资料、模板；不修改旧游戏，验证用独立线程与新生成作品。
- 最终保留网格容器，并新增非网格场地；不是删除网格能力。
- 检查记录支持窄屏无横向溢出、受伤耗尽生命结算及重开；不能代替收集得分、人工试听或其他玩法的测试。
- 未证实不同模型、运行配置完全受控；属于一次实际迭代示例，不作为严密因果实验或稳定性统计。

## 建议讲述顺序

问题 → AI 排查 → 原 Skill 核对 → 筛选建议并明确验证条件 → 修改 → 同任务独立生成试玩 → 回看关键改动 → 总结与更多测试。沿用现有结果后回看 Skill 的顺序，修改后、试玩前的原文停留可缩短，避免重复。

测试扩展优先：同任务重复（波动）、换非网格玩法（迁移）、翻牌玩法（回归）。其他 AI 可帮助审阅；更换执行模型属于兼容性测试，不能与仅改 Skill 的对照混为一谈。
