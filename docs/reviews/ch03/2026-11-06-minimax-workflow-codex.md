## 翻牌全过程

1. 检查空目录、Node 与 Chrome，主动准备浏览器验证。
2. 选择原生 HTML/CSS/ES Modules；拆分纯规则状态、DOM 控制器、难度、图案、存储和音效。自行增加三档难度、最佳成绩、计时、键盘操作等。
3. 写规则测试。先后修正错误测试预期，并修复图案种类必须为偶数的实现错误；最终 23 项通过。
4. 自写 CDP 浏览器脚本。后台服务器退出后，改成测试脚本自行启动服务器。
5. 浏览器检查发现翻错时步数未刷新；同时纠正把已配对牌计入翻开数等测试预期。第一次 61 项通过后仍继续看截图。
6. 截图发现牌面正反朝向错误；修复动画 transform 覆盖翻转的问题，继续检查通关、焦点、窄屏与持久化。
7. 最终 69 项浏览器断言通过；确认 file:// 启动受限，说明需要 HTTP 服务。交付运行方法和未验证项。

测试边界：browser-smoke.mjs 从 window.memoryGame.state.pairIds 读取配对信息，通过页面内 element.click() 和合成事件操作。它验证真实页面的功能链路，但不等于只凭可见信息的玩家试玩，也未完整模拟物理指针命中与原生键盘激活。69 是脚本断言数，不是 69 个独立用户场景。

教学意义：普通对话已能自主模块化、写测试、操作浏览器、看截图并修复。最有价值的片段是“功能断言通过，截图仍发现正反面错误”，用于解释验证证据覆盖什么；不能倒推只有 Skill 才能做到这些。

## 躲避全过程

1. item_2 读取入口 game-studio；明确按 2D 默认路线选择 Phaser。
2. item_4 读取 foundations、Phaser、UI、playtest；item_7 读取引擎选择、架构、界面、试玩及素材参考；item_10 继续读取 sprite-pipeline。未读取全部 3D 专项指导。本轮是前期批量读取相关材料，不能包装成每到一阶段才精准加载一份。
3. 检查工具与依赖，采用 Phaser、TypeScript、Vite；没有图片生成工具，采用程序化几何纹理。
4. 按参考组织 simulation、input、assets、Phaser scenes/view/bridge 和 DOM UI；规则细分移动、生成、碰撞、计分。自行增加冲刺、连击、三类拾取、三类障碍、评级与难度曲线。
5. 类型检查发现拼写、类型、接口问题；修复后构建，并处理场景重启监听、输入状态等问题。
6. 独立规则检查 34 项通过；Playwright 初轮浏览器检查 23 通过、2 失败。开局时间断言忽略操作耗时，另有资源 404。
7. 查看截图后多次修改竞技场边界、物体可读性、手机状态栏和标题菜单；修复 CSS display 覆盖 hidden 导致按钮错误显示。
8. 多次尝试后台运行长测试，进程提前结束；最终前台运行获得完整结果。环境排障不能归为游戏规则或 Skill 专有收益。
9. 增补返回标题流程，最终 31 项浏览器断言通过；生产构建再执行同一套检查通过。交付时列出手机竖屏、真实触屏、跨浏览器和性能等限制。

测试边界：Playwright 使用真实键鼠操作，也读取内部状态、合成部分事件。时间结束用例每 50ms 补生命、无敌时间并固定位置，等待正常计时结束；这可验证计时与结算，不能证明正常难度下存活 60 秒。得分非负断言不能单独证明实际收集链路正确，收集规则另有模块检查。

## 建议的教学组织（不是已确认新节表）

3.1 让学员从翻牌的一次完整开发中辨认产品需求、模型自行作出的选择和验证证据。保留一处规则选择、一处真实修正、一处验收判断即可，不重讲所有代码和环境排障。结尾提出下一游戏的开发需要：持续移动、碰撞、场景及界面协同；拿现成流程判断它能提供哪些帮助。

3.2 沿用认识 Skill、认识 Plugin、安装调用三部分。主读入口的工作路径和一份有具体作用的架构参考；检查清单可以继续作为简短调用，但不承担全部采用理由。让学员判断哪些内容适合当前任务、还缺哪些玩法需求；真实安装调用另补。

3.3 用躲避的真实读取记录、架构参考与实现作一条完整联系：为什么采用、提供了什么、实际怎样执行。展示规则模块的直接验证便利，以及需要人控制的功能范围。批量读取照实讲，不编造渐进加载时序。不要求学员掌握全部 Phaser 架构。

3.4 回看已有验证与最终声明，区分规则检查、页面功能链路、截图和玩家体验。用翻牌隐藏配对信息与躲避保持存活的测试条件解释证据边界，补实际需要的试玩、集成、发布与插件管理核验。避免再演一遍相同的自动测试。

可验收的学习结果：拿到类似任务，学员能说明为什么选这份指导、哪条建议对应哪项实际行动、还有哪些产品决定需要自己作出，并根据证据判断能否交付。未试讲，不能称教学效果已验证。
