## 总体判断

第一章的 Diff 多指 Git 命令输出，也用于称呼课件中的两行欢迎语示意，以及概括包含新文件的全部修改。现已按对象明确叫法，并同步阅读说明和口播。VS Code 中打开留存输出的操作，明确称“留存的 git diff 输出”，不把保存的文本说成当前工作树状态。

| 对象 | 当前叫法与说明 | 典型页面 |
| --- | --- | --- |
| 命令及其真实输出 | git diff 是命令，git diff 输出是检查记录；查看完整记录时写“完整 git diff 输出” | 1.1 p05、p06；1.2 p11-judge、p12；1.3 p18-check；1.6 p33、p34 |
| 未暂存、暂存与未跟踪文件 | 普通 git diff 查看已跟踪文件中尚未暂存的修改；暂存修改另看 git diff --cached；未跟踪新文件从 git status --short 列表找到并单独打开 | 1.1 p05 阅读说明与实操提示；1.4 p23-done；1.5 p29-diff |
| 课件的前后文字对照 | 欢迎语变化示意，说明原文与目标文字的变化；正式检查还要看实际 git diff 输出、文件状态与页面 | 1.1 p05-diff；1.2 p10-diff |
| 整个任务的修改范围 | 改动检查或全部改动检查，覆盖 Git 输出与新文件内容 | 1.4 p23、p23-done；1.5 p29-diff、p31；1.6 p36、p36-recap |
