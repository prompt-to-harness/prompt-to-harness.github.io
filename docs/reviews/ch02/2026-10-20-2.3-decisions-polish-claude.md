## p41a 状态图逐项核对

| 图上元素 | Git 实际语义 | 结论 |
| --- | --- | --- |
| 节点：工作区、暂存区、本地提交、远端 | working tree、index、本地分支上的提交、远端仓库 | 一致 |
| `git add <路径>`：工作区 → 暂存区 | 把工作区的内容写进 index | 一致 |
| `git commit`：暂存区 → 本地提交 | 把 index 存成新提交 | 一致 |
| `git diff` 标在工作区与暂存区之间 | 无参数时比较工作区与 index | 一致 |
| `git diff --cached` 标在暂存区与本地提交之间 | 比较 index 与 HEAD | 一致 |
| `git status` 括住前三处 | 报告工作区与 index、index 与 HEAD 两组差异，以及未跟踪文件；不比较远端的文件 | 一致 |
| `git restore <路径>`：暂存区 → 工作区 | 默认用 index 覆盖工作区 | 一致，方向正确 |
| `git revert <哈希>` 挂在本地提交下 | 新增一个反向提交，不删除原提交（它也会更新工作区和 index，图上没画，不影响本节判断） | 一致 |
| `git push`：本地提交 → 远端，标“下一节” | 推送本地提交 | 一致 |
| `git restore --staged` 不上图 | 用 HEAD 覆盖 index；p40、p41 作为取消暂存的办法提到 | 与 STORYBOARD 一致 |

没有 pretty-mermaid 的 `.mmd` 源，图用页面零件拼成，已在 README 和核对记录里写明；本次没有补。
