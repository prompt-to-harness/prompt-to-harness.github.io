## 结果

样稿外层只有三个观察入口：看回答、找读取调用、看后续请求。内嵌 claude-tap 0.1.146 原生静态查看器，保留自行选择记录、搜索、完整 JSON。使用页面内放大，无需浏览器全屏权限；放大后文本为 20px，可按按钮或 Esc 收起。查看器约 0.47 MB。

trace.json 来自已核实的同一次真实运行，作明确教学删节。删除鉴权、模型推理、安装/会话标识、本机路径；系统说明全文和非核心输出有删节标记。核心 34 行代码返回与上一批已核实 evidence.json 完全相同。返回文本按真实 input_text 展开换行以便阅读，原结构保留在完整 JSON 中；没有改动原始数据来伪造结构。

构建源为 build-viewer.py、viewer-bridge.js、trace.json；生成 trace.html。使用固定 claude-tap==0.1.146 并保留 MIT License，适配点不散落修改进供应商源码。观察位置在构建时按源码读取调用、call_id、最终回复推导，不把记录序号抄入外层页面。适配仍依赖固定版本内部函数；推广或升级前需再核验。

父子页面通过 postMessage 通信，检查 source 窗口身份；file:// 下不依赖同源 DOM 访问或 fetch 外置数据。该设计实际验证了本地文件能力，不能据此承诺任意浏览器均可用。静态记录目录独立于正式课件，不在当前 build-site 发布范围。
