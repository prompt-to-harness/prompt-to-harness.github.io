# 内容依据：以哪份文档为准

备课方法与产物职责统一由 [course-prep](../../.agents/skills/course-prep/SKILL.md)规定。本文只定位课程内容及决定的来源；不另设制作阶段、分镜产物或确认流程。

> 从 `AGENTS.md` 拆出，按需阅读。2026-11-08 补充新旧决定与工作稿的处理。

课程设计在多台机器、多个 agent 和多位讲师之间协作。教学决定和偏好写回 Discussion、讲述页或 PPT 的对应内容。日常核验结果随本轮交付说明。

处理同一问题时，先看讲师当前明确反馈，再核对相关最新已确认决定和正在修改的稿件。旧摘要、旧 Skill 或旧样稿不能覆盖更新的明确要求；决定已清楚时同步对应源文件，无需再确认同一件事。文件修改时间或 agent 已生成页面本身不代表讲师认可，但续作应保留当前修改，不按旧稿恢复。无法从现有反馈判断、且会改变课程结构时，再提最少的关键问题。

- `docs/course-outline.md`：平台交付版，约束对外承诺（详情页、讲师信息、定价与宣传填写项），相对稳定。备课和录制期间先保证课件内容与录课一致，平台交付版不逐次同步，课程录完后统一刷一遍；需要记下的改法写成 `docs/outline/proposals/` 的提案（2026-10-25 讲师确认）。
- `docs/outline/course-outline-internal.md`：两位讲师共同维护的全课设计和各章教学细节（目标、演示、练习、产出、验收）。
- 第三章章级设计统一维护在 [`docs/outline/ch03-discussion.md`](../outline/ch03-discussion.md)：主线、知识范围、深度、教学安排与决策都在此更新。讲述页按讨论稿确定的结构组织，维护具体画面、操作与讲法，并按编号链接到 Discussion 原文。主线变更先把讲师决定同步到该文档，再同步下游；尚未同步的旧文字不能推翻后续明确要求（2026-11-05 确认，2026-11-08 补充）。内部大纲只保留摘要和链接，`courseware/ch03/README.md` 保留查阅入口及历史课件导航。
- 已迁移的第 2 章，`courseware/ch02/README.md` 承担 Discussion 的职责，维护讲透问题、各节要点、验收和全章约定。逐页安排、讲法、证据与素材定位归各节讲述线，改动时从当前讲述页定位源文件。旧 `STORYBOARD.md` 只读，确需沿用的独有信息按本次任务接入当前源。页面源沿用各节 `tools/build-lesson.py` 与 `script.json`。`courseware/ch02/LOG.md` 保留既有决策和实测记录供查阅。内部大纲对应的章只留摘要和链接。
- `docs/outline/proposals/`：未合并的讨论稿。确认后在同一次提交里并入章文件或内部大纲，然后删除提案，理由写进章文件的决策记录，原文靠 Git 历史追溯。
- 课次、知识点、演示、练习、产出与验收以两份大纲和章文件为准，不另起结构。两份大纲冲突时，按上述最新决定核对并修订；仍无法判断时先请讲师确定，再改课件。
- 每章有一位负责讲师（2026-10-21 讲师确认）。只涉及本章的故事线、讲述线、课件和章内安排，由负责讲师确认即可；章末一节若由另一位讲师讲，该节由讲它的讲师确认。跨章安排（概念在哪几章出现、章间交接）、全课原则和平台交付版仍需两位讲师确认。文档里写着“待两位讲师确认”、但只涉及单章的事项，按本条理解。
- 章节名、节标题不要求与大纲逐字一致：大方向和范围对得上即可，写故事线、讲述线和细化内容时可以微调措辞。审查时不把标题措辞差异报成问题，只有范围或顺序变了才提（2026-10-11 讲师确认）。
- `docs/design/` 是早期内部讨论与指引，不是第二份已确认基线；采纳前对照当前大纲重新评估。旧版方案与演示草稿已清理，需要追溯时查 Git 历史。
- 软件工程 0.5：`docs/software-engineering/software-engineering-thread.md` 是原则文档，`software-engineering-problem-pool.md` 是候选池；试点卡片不是正式课次。
- 每节 PPT 对应口播以该节目录下的 `courseware/**/script.json` 为准（按页面 id 存每页口播数组）；`lesson.js` 里的 `script` 是由它生成的，不要只改生成物。改口播可直接在支持编辑的讲述页里逐句改（运行 `sh tools/edit-courseware.sh` 起本地服务打开），或编辑 `script.json` 后运行 `courseware/tools/rebuild-lesson.py`。3.3 非 PPT 讲述稿以 `screen-plan.js` 为源，公共编辑器按 `screen/part` 坐标写回，不另存口播副本。
- 视觉参考以 `demos/visual-system/` 和 `docs/production/visual-design-system.md` 为准。
