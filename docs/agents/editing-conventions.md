# 编辑约定

> 本文保留仓库文档的编辑边界；备课方法与讲述顺序统一按 [course-prep](../../.agents/skills/course-prep/SKILL.md)。

- 区分**已确认的决定**、**工作假设**和**不得对外承诺的事项**；不要把讨论中的细节升级为承诺。状态横幅写明日期，并说明该文档*不是*什么（不是报名承诺，不是已验证的学习效果）。
- 保留 `discuss/` 下的讨论原文；决定写进 `docs/` 下的共识文档，不回写讨论记录。
- 优先小而可回退的文档改动，不重构结构；新增顶层文档前先确认没有现成入口，优先在 `README.md` 里链接已有文档。
- 按编号读取完整正文：从仓库根目录运行 `python3 tools/read-editorial-rules.py ED-编号 ...`；合并去重，已读且未变的不重读，缺号或截断时补取并核对结束标记。 文档措辞读 ED-002、ED-007、ED-010、ED-012；屏幕文字读 ED-001、ED-012、ED-014；内容分层补 ED-003，源生成补 ED-011，操作补 ED-013，教学同步补 ED-017，状态补 ED-015、ED-016，来源补 ED-018，运行事实补 ED-020。改变教学目标或深度时进入 course-prep 对应方法。讲义页、口播稿、准备/帮助页和录制备注保持一致；具体讲法按 course-prep 的内容设计与讲述方法选择。
- 不虚构 Codex 的功能、限制、命令或产品行为；不确定就说明并建议核实。区分 AI 建议、事实结论、设计假设和待验证内容。
- 示例、练习和代码必须可复现；涉及安全、隐私、版权、生产环境时写明风险与人工复核要求。每个练习明确输入、任务、产出和验收标准，避免“了解”“熟悉”这类无法验收的目标。
- 中文表达简洁、适合授课；必要的英文术语加一句解释。
