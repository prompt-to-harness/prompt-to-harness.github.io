# 学生独立使用材料：交接边界与待定事项

> 状态：2026-11-14，讲师已确认两阶段职责边界；学生交付的具体格式与流程待设计。本文是独立交接文档，不是新 Skill，不表示学生材料已经制作或发布。

## 教师备课完成的边界

备课阶段完成讲师授课所需的全部成果，同时保证授课画面和教学安排适合学生。包括有效教学设计与讲述线、实际授课画面、可用的录制讲稿及操作入口、必要材料和演示准备，以及实际检查结果和未完成项。录制视图可以复用讲述页，但不能把授课所需的讲稿入口推迟到学生材料制作阶段。

备课成果交讲师确认后，再启动学生独立使用材料的制作。确认前，学生交付不作为 course-prep 的默认后续动作。授课画面和口播面向学生，备课时就需要检查可理解性及制作状态的隔离。

## 后续学生交付的输入与输出

输入是讲师确认的教学内容、授课成果、可用于独立学习的材料及其来源、事实边界和已知缺口。Discussion、讲述线与口播可以供制作参考，不默认作为学生交付物。

后续需要根据独立学习用途明确：

- 学生需要什么背景、解释、练习、操作帮助和结果核对方式。
- 使用网页、文档或其他文件格式，如何组织阅读、导航和下载材料。
- 哪些内容可以发布，哪些只用于备课；如何保留必要来源和事实限制。
- 如何从有效源生成并核对学生产物，避免与已确认的教学内容矛盾。

不默认交出 Discussion、讲述线或完整口播，也不默认采用现有阅读模式。已有阅读模式、章首页和下载结构可以评估复用，但不据此提前锁定最终格式。本文尚未确定文件清单、目录模板、构建命令或发布流程。

## 编辑规则的职责

| 规则 | 教师备课阶段 | 学生交付阶段 |
| --- | --- | --- |
| ED-003 内容用途与分层 | 共用判断：区分授课画面、口播、操作和备课说明 | 根据独立学习用途重新组织，不直接公开全部备课内容 |
| ED-011 源与生成物一致 | 修改源并生成授课产物 | 沿用有效源，核对最终文件与生成结果 |
| ED-015 状态一致 | 维护有效设计与实际检查状态，替代旧 README 逐层同步机制 | 按实际交付范围报告完成状态，不搬运旧备课状态 |
| ED-016 制作状态隔离 | 授课画面和口播不出现作者制作状态；讲师备注按用途区分 | 检查最终页面、导航和下载文件；本条不规定 README、LOG 保存机制 |
| ED-017 教学内容一致 | 核对章级设计、讲述线与课件 | 核对学生材料与已确认教学内容 |

规则正文仍由[编辑规范](editorial-checklist.md)维护。需要长期沿用的教学决定和缺口写回有效内容源，日常自查随对话交付；旧 README、LOG 作为历史查阅。

## 下一步设计事项

先核对教师备课完成的实际产物，再确定学生交付的输入、输出及验收。根据流程规模与复用需求，决定用按需读取的 reference 还是独立 Skill 承载；本轮不新建 Skill，也不实施发布或批量改造现有学生页面。

历史制作手册和课程设计资料中默认使用阅读模式的表述，是既有实现背景，不作为新交付的格式决定。后续设计选定载体后再处理相关历史入口；本轮不改播放器、构建器和 PPT 第二层方法。

## 编辑规则的取得方式

学生材料制作时用 `python3 tools/read-editorial-rules.py ED-003 ED-011 ED-016 ED-017` 读取完整正文；写改屏幕文字补 ED-001、ED-012、ED-014，独立解释补 ED-002、ED-007、ED-010，练习补 ED-009、ED-021，来源补 ED-018，运行结论补 ED-020。合并去重，已读未变的不重读；缺号或输出截断时补取并核对结束标记。

现行入口直接列编号，统一使用[读取脚本](../../tools/read-editorial-rules.py)。AGENTS 经编辑约定进入，course-prep 四原则只提供关联编号；Discussion、讲述、口播、实现、材料、协调和录制核对各自给出本任务清单。PPT 的 ED 清单暂由 course-prep 主入口提供，不改 PPT 第二层。转写 Skill 直接列转写规则，课程设计原则列备稿规则。
