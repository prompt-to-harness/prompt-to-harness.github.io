# 课程生图使用提案：每章一幅主题场景，首尾复用

> 状态：2026-10-06，供讲师讨论的制作提案，尚未确认，不替代现有视觉规范，不作为教学效果已验证的结论。

## 建议先采用的安排

以“章”为单位安排图片，不扩展到每个小节。每章先准备一幅主题场景图，用在已有的章首问题页与章末收拢页；同图开头提出问题，结尾回收已经讲过的判断。小节地图、自检、代码与证据页继续按现有规范制作。首尾不另加过渡页。

| 位置 | 默认安排 | 图片承担什么 | 页面继续承担什么 |
| --- | --- | --- | --- |
| 每章首个问题页 | 一幅主题场景 | 呈现本章具体任务或冲突，建立位置感 | 当前任务、本章方向、小节地图 |
| 每章末个收拢页 | 复用章首同图 | 唤回开头问题，形成首尾呼应 | 关键判断、已有证据、下一章交接 |
| 中间的小节开篇 | 默认不新增生图 | 延续同一套字体和地图即可 | 小节问题与当前位置 |
| 中间的知识／证据页 | 默认不用生图；只有明确收益才例外 | 可观察的场景、姿态或审美对照 | 精确机制、条件、文字、数据、判断 |

试验期按每章“一幅图、两个固定位置”规划，不把它变为完成指标。某章主题没有合适画面时，可以复用前一章同项目的工作台场景；没有必要为了配额创造隐喻。章中例外先以每章最多一处作为制作上限，经过比较再调整。这些数量是限制试验范围的工作假设。

现有规范中的漫画开场是“每节最多一页”，表示上限，并不要求每节都有；本提案进一步收紧生图频率，待确认后再同步规范。

## 哪一页值得做

先判断位置，再判断图片带来的信息。章首／章末可以为定位与回忆使用图片；章中必须有具体的观察收益。

| 判断 | 可以进入试验的情况 | 退回文字、原生图示或真实证据的情况 |
| --- | --- | --- |
| 有明确对象 | 能用一句话说明“学员看图里的哪个对象，理解哪个问题” | 只能说“填空、好看、显得有 AI 感” |
| 图有职责 | 章首唤起任务，章末回收任务；章中展示表情／动作／外观差异 | 图片旁边已经有完整解释，删图后没有任何观察损失，且不在固定首尾位置 |
| 不误导事实 | 明确是场景插画或设计示意，判断证据由页面独立提供 | 图会被当成实际界面、真实成果、测试通过或执行记录 |
| 与讲述匹配 | 讲师能指认图中的一两个对象；不必额外讲解新隐喻 | 为理解图片要先学另一个故事、世界观或技术映射 |
| 能融入课程 | 固定角色、纸色、笔触、占位、字号与揭示方式；关键文字独立可编辑 | 单页更换为写实大片、赛博场景、整页烘焙文字，或破坏讲师／字幕区 |

不采用“文字多就生图”的规则。信息密集首先检查是否该拆页、删去次要信息或选择更准确的结构。代码、diff、终端、测试、评测结果继续使用真实来源；流程方向、条件和回路继续保留可编辑图示。

## 统一哪些东西

- **位置和尺寸**：图片固定在正文区的一侧，另一侧放当前页的关键问题或判断；不抢标题、讲师框、字幕与章节条。
- **角色和物件**：同一位开发者与同一张工作台；项目变化通过任务卡、页面、反馈、规格或检查记录表现。人用中性服装，避免把角色服装混入节点的语义色。
- **绘画方式**：沿用现有纸色 `#F4F2EB`、深色轮廓 `#243042`、轻手绘与少量柔和填色；细节以缩小后仍能识别为准。
- **文本与事实**：标题、台词、编号、流程线、判断、输出都留在 HTML/SVG；图里不生成需要精读的文字，也不生成代表验收成功的勾章。
- **首尾关系**：尽量复用同图，不为了结尾再生成庆祝图。变化发生在旁边的问题、结论与交接文字上。

统一的是画面语言和使用位置，场景仍要随本章具体任务变化。不能让九章都出现同一个抽象的“人对着电脑”，却无法指出当前任务。

## 参考观察与取舍

本轮查看了课程参考快照中的鱼皮 OpenSpec、Harness 文章，以及陈天公开课程站的图片说明、Skills 幻灯片和回顾幻灯片。只观察素材组织方式；没有据此推断整个课程的频率或教学效果，也没有将参考原图复制进我们的产物。

- **鱼皮**：所选文章用固定卡通角色表现概念或流程，再进入操作截图。可以借鉴“一个画面表现一个概念、人物语言稳定、与实操证据切换清楚”。长文章可以容纳较多配图，不宜把它的配图密度直接搬到录播画布。
- **陈天**：所看 Skills 与回顾幻灯片有连续的纸色、手绘笔触与鸭子角色，封面、比喻、流程与复习都沿用它们。网站还有一套单独的生成插画用于首页、讲师与工具卡。可以借鉴“整组内容有固定画面语言”；不从“幻灯片保存成 JPG”推断它们全部以相同方式生成。
- **我们的取舍**：优先借鉴一致性和职责分工，降低生图频率；保留现有精确图示与逐步揭示。全页图片中已经包含的密集文字，不作为我们当前的制作模板。

公开参考入口：[鱼皮 AI 指南](https://github.com/liyupi/ai-guide)、[陈天课程站](https://tyrchen.github.io/geektime-bootcamp-ai/)。鱼皮素材只作参考，不搬入课件。

## 本轮示例与下一步判断

在 `demos/imagegen-pilot/` 增加第 1、2 章首尾四个样式示例，每章一幅生成场景图，共两幅新图。正式内容与页面 id 不变，试验稿也不新增正式课次或交付承诺。

比较时按顺序看四页，判断：

1. 图片出现的位置是否可预期，首尾是否能互相回指
2. 能否说出每章的任务与判断，而不是只记住角色
3. 回到中间的代码与证据页时，是否仍感到属于同一门课
4. 章首是否抢先给出了需要学习后才能作出的结论，章末是否引入新知识

先确认这种节奏，再决定是否正式采用。不先给全课批量配图。
