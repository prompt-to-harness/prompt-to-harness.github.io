# 正式章节

每章一个重点文件加一个配套文档（`chNN-exp.md`），合起来是该章故事线、逐节范围、演示、练习、产出、验收、常见错误、退出门禁和决策记录的唯一来源；内部大纲对应的章只留摘要和链接，分镜只写页级内容。做法见[文档整合提案](../outline/proposals/2026-10-21-doc-structure-ch02-pilot.md)。

| --- | --- | --- |
| 第 2 章 | [ch02.md](ch02.md)（重点）＋ [ch02-exp.md](ch02-exp.md)（约定、各节细节、决策与实测记录） | 2026-10-21 起为唯一来源（试点） |

其他章仍以[内部大纲](../outline/course-outline-internal.md)为准，迁移时按同样做法建文件。已制作的课件在 [`courseware/`](../../courseware/README.md)。
