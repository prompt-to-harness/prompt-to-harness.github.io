# 课程文档入口

这里是 AI Coding 课程的工作文档。课程范围以[深蓝平台交付版大纲](course-outline.md)为外部交付基线，教学实施以[共同内部大纲](outline/course-outline-internal.md)补充；后续课程设计、逐课材料和制作资产都应同时检查这两份文件。

## 先读什么

1. [深蓝平台交付版大纲](course-outline.md)：深蓝讨论后的课程结构、章节目标、实践项目和课程详情页文案。
2. [共同内部大纲](outline/course-outline-internal.md)：两位讲师共同维护的教学目标、演示、练习、验收和风险细节。
3. [设计参考](design/README.md)：此前关于定位、录播、讲述和审校的内部讨论，采用前需重新核对。
4. 已迁移的章：只关于一章的文件放在 `courseware/chNN/`，目前是[第 2 章文件](../courseware/ch02/README.md)；其他章以内部大纲为准，课件在 [`courseware/`](../courseware/README.md)。
5. [大纲提案](outline/proposals/)：尚未并入内部大纲的个人补充与调整方案，需两位讲师确认。

## 文档分区

| 分区 | 内容 |
| --- | --- |
| [深蓝平台交付版大纲](course-outline.md) | 深蓝平台交付材料和课程承诺 |
| [共同内部大纲](outline/course-outline-internal.md) | 详细教学设计；章节实施调整先改这里 |
| [大纲目录说明](outline/README.md) | 大纲文件关系和提案规则 |
| [设计参考](design/) | 早期定位、项目约束、工具方法和制作建议，待重新确认 |

| [审查记录](reviews/README.md) | 正式课件审查按触发条件留档，按章存放，供后续审查与修改参考 |

| [调研](research/README.md) | 外部方案调研：最终报告在 `reports/`，原始笔记在 `notes/` |

## 使用规则

- 深蓝平台交付版决定对外课程承诺，共同内部大纲补充教学实施细节；其他文档补充设计、制作或研究，不另起一套课序。
- 后续正式章节以总纲为依据设计；已清理的旧草稿通过 Git 历史追溯。
- `discuss/` 保存讨论过程，第三方参考资料保存在私有仓库，不公开；它们提供依据，不是课程结构入口。
