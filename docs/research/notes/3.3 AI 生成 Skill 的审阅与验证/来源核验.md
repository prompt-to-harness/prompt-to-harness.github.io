# 3.3 AI 生成 Skill 的审阅与验证 · 来源核验

2026-11-11 打开以下一手材料并核对相关段落。公开课程只核对讲义，未以视频为依据。本轮未运行官方评估工具或修改课程 Skill。

| 来源 | 核实内容 | 采用边界 |
| --- | --- | --- |
| [OpenAI · Build skills](https://developers.openai.com/plugins/build/skills#define-the-workflow-boundary) | 已核实。按输入、动作、输出、不可推断的信息、提问或停止的条件和支持文件界定工作范围。审查含混、冲突和优先级。代表性测试覆盖直接、间接、缺输入、应不触发和边界请求，区分选用与产物质量。 | 这是 Plugin 开发指南。课程借用审阅原则，保留 3.2 对触发的讲解。 |
| [OpenAI · Testing Agent Skills Systematically with Evals](https://developers.openai.com/blog/eval-skills) | 已核实。沿 3.2 已采用的 setup-demo-app 先定义成功，手动调用暴露环境与执行假设，再从日志、文件和定性评价核对。原文分别列出结果、过程、风格、效率目标。 | 适合续接 3.2 的完成标准。课程采用少量可观察要求，自动评估脚本、效率指标和批量回归可留作备查。 |
| [Anthropic · skill-creator 原始文件](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md#improving-the-skill) | 已核实。初稿后用少量请求运行，把实际产物与评分交给用户审阅。结合反馈和轨迹修订，避免为单个样本添加僵硬规则，随后重跑同一组任务。已有 Skill 的基线可选原版或上一版。触发描述优化有独立流程。 | 是 Anthropic 公开的工具工作流。主课取人看产物、AI 按具体反馈修改、同题复验三步。 |
| [Agent Skills · Best practices](https://agentskills.io/skill-creation/best-practices) · [Evaluating skill output quality](https://agentskills.io/skill-creation/evaluating-skills) | 已核实。以真实任务、修正和既有资料提炼指导，按任务容易出错的程度决定具体度。评估先定义真实请求和期望结果，细化断言可在看过首轮输出后完成。每轮用独立上下文，同题无 Skill 或旧版作基线。可机械判断的项目适合用脚本，难量化的风格交给人看。 | 两条指南用于不同问题。工作范围和具体度指导文件审阅。基线与检查方法用于判断运行效果。 |
| [DeepLearning.AI · Creating Custom Skills 讲义](https://github.com/https-deeplearning-ai/sc-agent-skills-files/blob/main/L4/reading_material_4.md) | 已核实。讲义先讲元数据、正文、自由度和配套目录，再以生成练习题讲测试请求、输入文件、预期行为和用户反馈。例子检查学习目标、题型、模板和输出文件是否编译。 | 属于公开课程教学实例。3.3 复用测试设计的讲法，结构讲解留在 3.2。 |
