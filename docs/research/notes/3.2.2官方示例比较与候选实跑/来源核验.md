## 本轮补核：正文写法的共同实践

2026-11-10 再次打开以下官方原文，并对照相关正文，而非仅凭目录归类：

- [Agent Skills specification](https://agentskills.io/specification#body-content)：正文不限定格式，推荐内容与篇幅建议不等于固定模板。
- [Agent Skills best practices](https://agentskills.io/skill-creation/best-practices)：Calibrating control 与 Patterns for effective instructions，包含具体程度、默认、易错点、模板和检查循环。
- [Anthropic authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices#common-patterns)：模板、例子和条件工作流；其 Workflows and feedback loops 另有反馈循环示例。
- [OpenAI Build skills](https://developers.openai.com/plugins/build/skills#define-the-workflow-boundary)：输入、步骤、输出、事实边界、追问与停止条件。
