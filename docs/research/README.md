# 调研

为课程设计和制作流程做的外部调研。每次调研用同一个标题对应两处：

- `reports/<标题>.md`：最终报告，平时只看这里
- `notes/<标题>/`：报告的原始笔记，按方向分文件，每条发现附来源和“已核实 / 待实测”标记，用于追查结论出处

调研结论是选型依据，不是已确认的决定；采纳后把决定写进对应的设计或制作文档。
