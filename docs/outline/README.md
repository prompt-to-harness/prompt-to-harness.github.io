# 课程大纲目录

这里区分深蓝平台交付材料、两位讲师共同维护的教学设计，以及尚未合并的个人提案。

| 文件或目录 | 用途 | 维护规则 |
| --- | --- | --- |
| [`../course-outline.md`](../course-outline.md) | 深蓝课程平台交付版，包含课程详情页、讲师信息、价格和宣传填写项 | 相对稳定；影响平台承诺或宣传信息时再修改 |
| [`course-outline-internal.md`](course-outline-internal.md) | 两位讲师共同维护的详细教学大纲 | 持续补充演示、练习、验收、风险和待核验事项 |
| [`TODO.md`](TODO.md) | 内部待办、决策跟踪和录制前核验门禁 | 只记录仍有效的工作项；过时内容标明历史状态 |
| [`proposals/`](proposals/) | 单个讲师尚未合并的补充内容或冲突方案 | 讨论通过后合并到共同内部大纲 |
| [`archive/`](archive/) | 被替代的大纲版本 | 只作追溯，不作为当前课程依据 |

修改流程是：先在提案中提出个人补充或冲突方案，由 Coding Agent 对比共同内部大纲并列出影响；两位讲师确认后更新共同内部大纲，再判断是否需要同步深蓝平台交付版。提案不能单独改变正式课序或课程承诺。

课件和讲稿继续放在 [`../../courseware/`](../../courseware/)，讨论原记录放在 [`../../discuss/`](../../discuss/)。外部参考资料保存在私有仓库，不公开。这些目录补充大纲，不另起课程结构。
