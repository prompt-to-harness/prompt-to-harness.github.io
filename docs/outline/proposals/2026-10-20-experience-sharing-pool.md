## 一、按建议章节分组

### 第 1 章（最后一节 1.6 不改；以下作为补充材料或后续章节候选，位置待定）

第 1 章主题是第一次让 Agent 完成小任务、Agent 循环、工具与权限、Prompt 四要素、检查结果。适合新手的候选：

- 其他工具形态的展示：Cursor、Codex App 与 CLI 并排看（只展示和对比，不要求安装）
- 怎样选模型：看 benchmark、模态、价格、推理档位（0921、0923 两位讲师都同意加，现在没有）
- 国内模型和 token plan 怎么选（和 0.2 的模型接入对应）
- 新手权限路线：先用默认的人工批准，git 管得好后再逐步放权
- 读官方 Prompt 指南：把四段式写法和官方建议对照（官方链接已在大纲 13.1，但 1.4 没引用）
- 需求澄清单独开一个会话，再带着结果去做任务
- “读不到网页却编造内容”的反面演示（讲师说难复现，需要先找到稳定触发的例子）
- 语音输入法：降低打字门槛
- 把截图、文件、报告交给 AI 看的几种方式（体检报告、邮箱整理一类的生活场景，门槛低）
- Python 环境：uv、pip、conda 与国内源（如果学员要在本机跑脚本）
- 一份“AI 编程词典”式的术语小抄，对应 1.2 的术语（可参考社区公开的词典，用自己的话写）
- 不要把密钥、隐私交给 AI 的几个检查习惯（对应 1.5 的 checkpoint）

### 讲师日常用的小技巧（来自 10-19 讨论，位置待定）

这类内容讲师觉得“习以为常”，但新手可能完全不知道，适合当作各章最后一节里的小条目：

- 让 agent 长时间运行：不依赖自己电脑开机，放到服务器或后台运行；tmux 一类的工具
- 手机连回自己的电脑，远程调用上面的 agent（社区有工具，也有产品内置的类似功能，需要核实当前状态）
- 新机器的常用配置：终端工具、换源（pip、apt、Homebrew）
- 用 GitHub CLI（`gh`）登录和发布，代替手动生成和上传公钥（第 2 章 2.4 已经在用 `gh`）
- 语音输入法（已列在第 3 章）

收集方式：想到就先记下，先攒到较多的量（讨论里提到可能接近 100 条），再用 AI 帮忙和各章对应，每组三四条，彼此递进或并列。
