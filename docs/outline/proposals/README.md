# 大纲提案

这里保存尚未合并到共同内部大纲的个人补充、备选讲法和冲突方案。

文件名建议使用 `YYYY-MM-DD-author-topic.md`。提案应写明提出人、针对的小节、变更理由、影响范围和待确认问题。确认后，在同一次提交里把采用的内容并入 [`../course-outline-internal.md`](../course-outline-internal.md) 或已迁移章的章文件（[`../../chapters/`](../../chapters/README.md)），然后删除提案；理由写进章文件的决策记录，原文靠 Git 历史追溯。

全课主线与跨章交接的讨论入口：[全课递进表（2026-10-21）](2026-10-21-codex-course-progression-table.md)，列出各章核心问题、主知识点、项目产出、下一章承接、概念重访与待定项。它是讨论稿，不替代当前大纲。
