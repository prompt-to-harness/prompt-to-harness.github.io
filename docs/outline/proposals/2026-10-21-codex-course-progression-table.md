## 四层能力如何衔接

Prompt 让人把当前任务表达清楚；Vibe Coding 用运行结果推动下一轮修改；SDD 把需要长期一致的行为和验收写成可追踪契约；Harness 让这些方法在新会话和新任务中可重复执行，并用证据判断维护价值。

早期使用 AGENTS.md 或 Skill 不会提前“完成 Harness”：一条项目约定、一段可复用步骤，只解决当前局部问题。后期新增的是多项约束的组合、技术检查、失败处理以及效果评测。三个仓库只迁移这些方法，项目事实始终重新核验。
