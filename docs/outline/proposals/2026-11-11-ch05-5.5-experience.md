## 变更理由与影响范围

原 5.5 计划用本章 JSON Diff 的数据流讲解耦合、模块和信息隐藏，与 5.1–5.4 强耦合，也接近「问题→术语→判断」的短讲模板。讲师希望各章工程经验先有趣、再实用，并围着 Vibe Coding 分享 plugin、skill，以及 Codex CLI、ChatGPT 应用里的小技巧。

影响范围：只改 5.5 的主题、连贯内容和演示对象；不改 5.1–5.4 的任务划分，不新增学员必做练习，也不提前占用第 7–9 章的 Worktree、Hook、`codex exec` 和自行封装 Skill。第三方 Skill / Plugin 若出现，只作预先审查后的展示，不要求学员安装。

为避免和其他章最后一节冲突：`/side` 虽曾出现在经验分享候选池的第 2 章条目中，但 2.5 实际未采用，2026-11-12 起改记到 5.5；截图的生活场景入门用法仍留第 1 章，本节只讲「做到一半、按画面改界面」。

## 本节要分享什么

**一句话**：前四节已经把功能往前推完，这一节把课程主线里还没展开、但马上能用的 Vibe Coding 招数拿出来看一眼，做着做着就能带走。

时长按工程经验预算 15 分钟，允许在 10–15 分钟内试讲调整。看懂即可，不新增练习和自检题，不改 JSON Diff 的代码。

全节分成两段：先看两个不必额外安装的官方技巧，加上一个「按画面改」的入口；再只深看一个官方插件。官方依据见 [Slash commands](https://learn.chatgpt.com/docs/reference/slash-commands)、[Developer commands](https://learn.chatgpt.com/docs/developer-commands)、[Plugins](https://learn.chatgpt.com/docs/plugins)。

### 两个官方技巧，外加一个按画面改的入口

1. **侧聊，不冲乱正在做的事**  
   使用 `/side`（CLI 里也写作 `/btw`）。主会话正在实现时，把一句报错或某个 API 问到侧聊里，主记录保持连续。这是本节最实用的机关，也最先演示。

2. **想换一种做法，把对话分出去**  
   使用 `/fork`，把当前对话复制到新会话（或新的工作副本入口）里试另一种实现，原来的记录还在。用来回答「不如换个写法看看」，不要在这里展开 Worktree 的隔离实验，那是第 7 章的正课。

3. **把界面截图贴进对话，让它按画面改**
   这是第三个技巧。讲的是实现做到一半时怎么用：对着当前界面截一张图，让它按画面修改，而不是把截图、文件交给 AI 看的入门用法。那个门槛更低的讲法留给第 1 章。

`/review` 不作为第三个演示项。5.4 后半已经是整体验收与 Review；本节只在口播里提一句：产品自带的 `/review`（需要看具体文件改动时再配 `/diff`）可以检查未提交改动，官方说明是聚焦行为变化和缺测，并且不改工作区。要讲清它不能代替本章验收，也不重讲 5.4 的规格回环。

在这三个技巧之后，若录制版本的 ChatGPT 桌面版或 CLI 已核验，可用很短一句补上语音口述，或从 CLI 用 `/app` 把当前会话接到桌面版。未核验的 App 能力只留官方说明，不现场猜测，也不占用第三个技巧的位置。桌面版的 `/pet` 如需出现，只作约 10 秒的趣味收尾，不占正片。课程规定 Codex App 为可选入口，项目操作与模型接入须单独核验；对学员应使用「Codex App」这一名称。

### 一个好玩的官方插件：Remotion

技巧讲完后，用 `/plugins` 打开官方目录，只深看一个插件：[Remotion 的官方 Codex 插件](https://www.remotion.dev/docs/ai/codex-plugin)。用代码做视频，和前面做网页、改开源仓库的感觉都不同，负责本节的「有趣」。演示预先审查过的官方示例或短片段，说明它提供了哪些 Skill 或工作流；用 `$技能名` 显式调用即可，点到为止。

不要求学员安装，也不在课上新建 Remotion 项目。若录制时该插件在教学账号中不可用，改用 [openai/plugins](https://github.com/openai/plugins) 里的 Build Web Apps 作为备选：只展示它在界面设计上的指导，避开第 4.6 节已经提过的浏览器测试类能力。Figma 官方插件需要额外账号，不作为本节首选。
