## 变更理由与影响范围

原 5.5 计划用本章 JSON Diff 的数据流讲解耦合、模块和信息隐藏，与 5.1–5.4 强耦合，也接近「问题→术语→判断」的短讲模板。讲师希望各章工程经验先有趣、再实用，并围着 Vibe Coding 分享 plugin、skill，以及 Codex CLI、ChatGPT 应用里的小技巧。

## 本节要分享什么

**一句话**：还是用 Codex 和 ChatGPT，把课程主线里还没展开、但马上能用的 Vibe Coding 招数拿出来看一眼。

时长按工程经验预算 15 分钟，允许在 10–15 分钟内试讲调整。看懂即可，不新增练习和自检题，不改 JSON Diff 的代码。

全节分成两段：先用三个官方技巧（不必额外安装），再只深看一个官方插件。官方依据见 [Slash commands](https://learn.chatgpt.com/docs/reference/slash-commands)、[Developer commands](https://learn.chatgpt.com/docs/developer-commands)、[Plugins](https://learn.chatgpt.com/docs/plugins)。

### 三个官方技巧

1. **侧聊，不冲乱正在做的事**  
   使用 `/side`（CLI 里也写作 `/btw`）。主会话正在实现时，把一句报错或某个 API 问到侧聊里，主记录保持连续。这是本节最实用的机关，也最先演示。

2. **想换一种做法，把对话分出去**  
   使用 `/fork`，把当前对话复制到新会话（或新的工作副本入口）里试另一种实现，原来的记录还在。用来回答「不如换个写法看看」，不要在这里展开 Worktree 的隔离实验，那是第 7 章的正课。

3. **做完一轮，用产品自带的审查看一眼**  
   使用 `/review` 审查未提交改动，或对比某个基础分支；需要看具体文件改动时再配 `/diff`。官方说明是聚焦行为变化和缺测，并且不改工作区。本节只展示这个入口和它能看到什么，不重讲 5.4 的规格回环，也不把 `/review` 的结论写成已经通过本章验收。

在这三个技巧之后，用很短的一段补一个「好看也好用」的入口：把界面截图贴进对话，让它按画面改。若录制版本的 ChatGPT 桌面版已核验，可演示语音口述任务，或从 CLI 用 `/app` 把当前会话接到桌面版；CLI 若提供 `/voice`，按核验结果选用。未核验的 App 能力只留官方说明，不现场猜测。桌面版的 `/pet` 如需出现，只作约 10 秒的趣味收尾，不占正片。

### 一个好玩的官方插件：Remotion

技巧讲完后，用 `/plugins` 打开官方目录，只深看一个插件：[Remotion 的官方 Codex 插件](https://www.remotion.dev/docs/ai/codex-plugin)。用代码做视频，和前面做网页、改开源仓库的感觉都不同，负责本节的「有趣」。演示预先审查过的官方示例或短片段，说明它提供了哪些 Skill 或工作流；用 `$技能名` 显式调用即可，点到为止。

不要求学员安装，也不在课上新建 Remotion 项目。若录制时该插件在教学账号中不可用，改用 [openai/plugins](https://github.com/openai/plugins) 里的 Build Web Apps 作为备选：只展示它在界面设计上的指导，避开第 4.6 节已经提过的浏览器测试类能力。Figma 官方插件需要额外账号，不作为本节首选。

- 不把 Context7、Playwright 当作新推荐（已在 4.6 清单中）。
- 不展开 Worktree、Hook、`codex exec`，也不教如何自己封装 Skill（第 7–9 章正课）。
- 不安装或展开 Superpowers、Spec Kit 等社区方法论插件，避免和本章正在使用的 SDD 抢戏。
- 不为了对比而讲解 JSON Diff 的模块划分，也不回头总结 5.1–5.4 的实现结构。

## 建议节奏

| 段落 | 大约时长 | 学员看见什么 |
| --- | --- | --- |
| 开场：本节和前四节不同，是一组能带走的 Vibe Coding 招数 | 1 分钟 | 本节问题或短标题 |
| `/side`（或 `/btw`） | 4 分钟 | 主会话仍在，侧聊回答了一个局部问题 |
| `/fork` | 3 分钟 | 一条对话分成两条，原记录还在 |
| `/review`，必要时配 `/diff` | 3 分钟 | 产品自带的审查结果；不改工作区 |
| 截图或语音（按核验结果选用） | 1 分钟 | 一种更轻松的下达任务方式 |
| Remotion 官方插件（或备选 Build Web Apps） | 3 分钟 | 预先审查过的示例；`$技能名` 点到为止 |
| 收尾：这些招数可带走，不必今天装插件 | 约 0–1 分钟 | 可选 `/pet` 不作必做 |

时长由试讲或剪辑调整，不按上表删减内容。现场不跟做安装；演示以课前准备的短片段或截图为主，避免把时间花在下载和登录上。
