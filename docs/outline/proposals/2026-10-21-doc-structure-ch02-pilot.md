> 状态：草稿（2026-10-21），按讲师要求整理，待讲师确认。本文只提出结构和迁移步骤，**没有改动大纲正文、课件或其他提案**。它不是课程承诺，也不改变任何课次、时长或验收。

改完之后还有两处漏了（见 2026-10-21 的设计一致性检查）。原因有三个：

1. **同一件事在几层都写得一样细。**提案、内部大纲、章 README、分镜都写了一遍本章故事线和各节范围，没有哪一份声明“以我为准、别处只链接”。
2. **提案合并后仍和大纲并存。**`proposals/README.md` 规定“提案本身保留作决策追溯”，于是第 2 章有三份提案（10-02 故事线、10-02 分镜、10-19 Context 主线）和大纲一起描述同一章，读者要自己判断哪段已被取代。
3. **决策日志写进正文。**“（2026-10-20 讲师确认）”“原为……”散在每段里，改一个决定时正文和日期都要改，旧说法也留在原句里。

## 二、原则

- **每类事实只有一个家。**其他文档需要时只写一句并链接过去，不复述细节。
- **正文只写现在的样子。**为什么这样定、什么时候定的，写进本章文件末尾的决策记录；更早的过程靠 Git 历史。
- **提案是工作稿。**确认后在同一次提交里并入正式文件，然后删除提案；理由留在决策记录里。
- **能机器检查的就交给 `make check`。**废弃说法、断链、生成物不同步，由检查报出来，不靠人记得改哪几处。

说明：

- 选 `docs/chapters/` 而不是 `courseware/ch02/`：这个目录已经存在，用途就是“已确认进入课程制作的正式章节材料”；它不随 Pages 发布，和讲义分开。
- 跨章表（§6.1、§6.3、§6.4，以及 2026-10-21 新增的全课递进表讨论稿）每行只写“哪一章、什么角度”，一行一句，细节链接章文件。试点阶段只改第 2 章那几行，不合并这几张表。
- 平台版仍然手工维护，不从章文件生成。它变得少，手工改的成本低；生成工具反而要维护格式。

## 五、迁移步骤

每一步单独提交，可以单独回退。

1. **讲师确认本提案**，以及第七节的待定问题。
2. **建章文件，只加不删。**按第三节的骨架写 `docs/chapters/ch02.md`，内容逐段取自内部大纲第 2 章和 10-19 提案，取两者的现行说法；两者有冲突时列进“待定”，不自行裁决。这一步原文件都不动，只能新增内容。
3. **讲师通读章文件**，确认没有丢内容、没有改变含义。这是唯一要人工逐段核对的一步。
4. **切换唯一来源。**内部大纲第 2 章缩成链接；§6.1、§6.3、§6.4 的第 2 章行缩短；更新第四节表里的说明文档。
5. **删除已并入的三份第 2 章提案**，修复 `make check` 报出的断链。
6. **精简课件说明。**改 `courseware/ch02/README.md` 和五节的 `README.md`、`STORYBOARD.md`，只删复述、改链接，不改页面内容；重新生成后 `lesson.js` 不应有变化。
7. **加废弃说法检查。**在 `docs/production/terminology.md` 的“不要用”列里，把明确作废的说法（如“同一份请求记录”“回退点”“CH02_VIBE_ITERATIONS”）标出来，由 `courseware/tools/check-editorial.py` 在 `docs/` 和 `courseware/` 里查找；允许在决策记录和审查记录里出现。这一步要改检查脚本，单独评估。
8. **用一个真实决定验收。**拿下一个待定的第 2 章决定（例如项目 `AGENTS.md` 放在哪一节）走一遍新流程，记下实际改了几个文件。

## 六、怎样判断试点成功

- 一个只影响本章的节级决定：改章文件，加上受影响页面的分镜和 `build-lesson.py`；涉及对外要点时再改平台版。不再需要改大纲、提案或章 README。
- 新加入的 agent 或讲师只读章文件，就能答出第 2 章每节的范围、演示和验收，不需要比对多份提案。
- `make check` 通过，且没有新增“已取代”“原为”这类正文内说明。

满足这几条后，再按同样做法迁移第 3 章（已有故事线提案和分镜），以及概念地图、全课递进表这类跨章材料。不满足就整体回退，回到现行结构。

## 八、风险

- **迁移时丢内容或改变含义。**第 2 步只加不删，第 3 步由讲师通读，可以降低风险。
- **与其他人同时在改。**另有 agent 在改概念地图和全课递进表等跨章文件。迁移第 2 章时，先确认没有人正在改第 2 章的大纲、提案或分镜，再在一次提交里切换。
- **旧链接失效。**审查记录里的历史链接会指向已删除的提案。审查记录是当时的快照，链接改成指向章文件；必要时附上提交哈希。
- **规则没人遵守，又长回去。**第 7 步的检查和 `sources-of-truth.md` 的分工说明是防线；agent 读 `AGENTS.md` 时会先读 `sources-of-truth.md`。
