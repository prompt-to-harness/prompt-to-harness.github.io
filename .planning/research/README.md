# Research index

`.planning/research/` 保存课程相关调研的 brief / evidence / report。状态各不相同，引用时以各目录 `report.md` 为准，不自动升格为课程必选内容。

| 主题 | 目录 | 主要用途 |
| --- | --- | --- |
| 软件工程拾遗 | [software-engineering-archaeology/](software-engineering-archaeology/) | SE 0.5 线史料与选题 |
| 极客时间项目结构 | [geektime-project-structure/](geektime-project-structure/) | 单项目递进 vs 多项目并列 |
| AI Coding 项目候选 | [ai-coding-project-candidates/](ai-coding-project-candidates/) | Project 题目池 |
| 作业与评价 | [ai-coding-assignment-evaluation/](ai-coding-assignment-evaluation/) | 验收与评价方式参考 |
| 讲稿自然度与口播审校 | [course-script-naturalness/](course-script-naturalness/) | 社区脚本/教学视频方法、1.4–1.6 定点诊断与改稿门 |

## 使用约定

- 每个主题通常含 `brief.md`、`evidence.md`、`report.md`；缺失文件不必补齐空壳。
- 调研结论进入总设计前，需对照[当前课程总纲](../../docs/course-outline.md)，并在实际采用该结论的设计文档中登记使用方式与限制；旧 10 课方案的来源表仅作历史记录。
- 涉及合作平台内部信息的两项调研（深蓝课程结构、作业时长）保存在私有仓库，未在此公开。
