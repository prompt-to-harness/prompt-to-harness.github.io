# Research Brief：让课程讲稿自然、可口播，并落实已有原则

- 研究日期：2026-09-22。
- 问题：已有讲述原则基本获认可，为什么新增课程材料仍出现生硬、制作说明混入口播和流程宣读？社区有哪些可落地的写作、审校与验证办法？
- 决策用途：为下一轮第一章 1.4–1.6 改稿及后续章节制作提出有证据的工作方式；本轮调研不直接覆盖课程内容或修改已确认规范。
- 包含：教学视频/电教脚本、广播口语写作、AI 辅助写作的示例与审校、对当前材料的定点诊断。
- 不包含：绕过 AI 检测器、批量同义词替换、工具商业排名、未经试讲的学习效果承诺。
- 时间范围：截至研究日可访问的公开来源；保留较早但有方法依据的教学和口播研究；区分近期工具实践与长期教学原则。
- 受众：课程作者与协作 Agent；输出中文报告、证据账本、改稿示例和小规模验证建议。
- 完成标准：覆盖下列五个问题；重要建议有相邻来源；区分作者经验、研究结论和本课程推断；有反证/限制、有本地原句、有可验证的下一步。

## 子问题与优先来源

1. 适合听的脚本与适合读的说明文有何不同？优先广播编辑、课程制作从业者原文。
2. 如何减少无关解释和重复，又保留初学者所需支持？优先教学视频研究与教学设计者方法。
3. 风格规范如何进入 AI 写作与审校，而不只成为长提示词？优先有示例的实践流程和评估方法。
4. 当前 1.4–1.6 的偏离发生在哪里？读内容源、导出逐字稿、录制说明和验证记录，避免推断未发生的生成过程。
5. 哪些常见建议可能适得其反？检索口语化、冗余、完整脚本、AI 自评的适用限制。

## 方法与访问限制

- HTTP 获取公开原文，搜索页只用于发现；不以搜索摘要支撑核心结论。
- Google 初次搜索返回 HTTP 429 验证页，后续尝试其他公开检索与直接原始来源；记录不可访问项。
- 未获得讲师实录音频和新手学习实验；中文自然度与教学效果只能提出待验证假设。
